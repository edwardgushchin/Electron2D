# EQ conformance fixture

Last updated: 2026-10-02

`reference.json` contains three 256-frame stereo PCM cases for six, ten and twenty-one bands, generated by compiling the unmodified pinned `eq_filter.cpp`/`.h` with minimal standalone Vector/Math/error shims. The small [oracle.cpp](oracle.cpp) driver supplies deterministic distinct input channels, +6 DB on the first band and -9 DB on the last, then sums the C++ band outputs as the pinned effect does. Runtime tests compare all 1,536 channel samples after an arbitrary split; the maximum observed absolute error was `1.758337E-06`. No production C# implementation generates this fixture.

The authoritative revision is `ed1daf0bf001b61586d9930840f2f1394092c079`: [source](https://github.com/godotengine/godot/blob/ed1daf0bf001b61586d9930840f2f1394092c079/servers/audio/effects/eq_filter.cpp), [header](https://github.com/godotengine/godot/blob/ed1daf0bf001b61586d9930840f2f1394092c079/servers/audio/effects/eq_filter.h) and [effect resource](https://github.com/godotengine/godot/blob/ed1daf0bf001b61586d9930840f2f1394092c079/servers/audio/effects/audio_effect_eq.cpp).
