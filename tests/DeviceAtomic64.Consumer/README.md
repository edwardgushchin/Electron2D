# Native wide atomic consumer

This executable uses only the public Electron2D API and the existing device shader imports. Run the `all` profile in a Vulkan display session with enabled shaderInt64 and Vulkan 1.2 buffer/shared Int64 atomic features. GLSL checks signed/unsigned operations, native atomic load/store, high words, rollover, failed/successful CAS, copied specialization/push snapshots and 64 simultaneous nonduplicated counter returns. Raw SPIR-V variants exercise increment/decrement/subtract and implicit Int64. HLSL checks contention and CAS with the existing pinned shader profile. A mixed kernel requires both storage features.

Build with `dotnet build tests/DeviceAtomic64.Consumer -c Release -r linux-x64`. Use the ordinary native-consumer library properties when the shared native prerequisites are not already built. `buffer` and `shared` select the respective positive profiles. `unavailable-buffer`, `unavailable-shared`, `unavailable-both` and `unavailable-api` require the test-only tools/render-native/test_atomic64_mask.c SDL3_DYNAMIC_API shim and ELECTRON2D_TEST_MASK_ATOMIC64=buffer/shared/both/api respectively. Remaining atomic storage must execute; unsupported shader and binary publication must reject. Do not ship this shim.

Publish with `dotnet publish tests/DeviceAtomic64.Consumer -c Release -r linux-x64 -p:PublishAot=true -p:PublishTrimmed=true -p:TrimMode=full -p:IlcTreatWarningsAsErrors=true -p:ILLinkTreatWarningsAsErrors=true -o tests/DeviceAtomic64.Consumer/bin/aot` and run the same profiles. Prepared dispatch/readback intervals check zero owner-thread managed bytes. Native allocations, throughput, other hardware/platforms and human acceptance require separate verification.
