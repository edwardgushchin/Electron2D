# Native byte shader consumer

Public-API-only Release/NativeAOT fixture. Run managed, compute, source, graphics, canvas or profiles; canvas executes two complete retained renderer lifecycles. ShaderImport produces GLSL device modules during the build. Source compiles the same data shader through RDShaderSource and checks the pinned HLSL int8_t diagnostic. The byte GLSL profile uses Vulkan 1.2/SPIR-V 1.5; other profiles keep their existing settings.

Checks cover all 256 signed/unsigned nullable metadata patterns, scalar limits and wraparound, valid signed division/positive remainder, shifts/bitwise/comparison operations, compact SSBO/UBO, a direct byte specialization array extent, mixed byte/Int16/Half data, every push-word byte lane and the last byte at offset 127, nested helpers/dynamic byte indices, snapshots, exact native pixels and zero warmed owner-thread managed bytes. Native work does not promise allocation-free shader/pipeline construction.

Refusal modes unavailable-arithmetic/buffer/uniform/push/int16/float16/all/api use tools/render-native/test_shader8_mask.c with matching ELECTRON2D_TEST_MASK_SHADER8. Storage-only buffers/uniforms survive byte arithmetic refusal; 16-bit siblings survive byte feature refusal. Mixed modules fail when any required feature is absent. Direct/frozen/translated SPIR-V is validated against Vulkan 1.2. Native byte stage IO, native vertex/color format adapters, HLSL native8 syntax, other GPU/platform execution, native/driver allocations, throughput and human acceptance remain separate. See [the owning component](../../docs/components/local-compute.md#native-int8-and-uint8-arithmetic-and-packed-data).
