# Native Half consumer

This executable uses public Electron2D APIs and existing device shader imports. `managed` checks all 65,536 Half bit patterns through nullable typed metadata. `compute` checks GLSL/HLSL arithmetic, packed SSBO/UBO data, two-byte push strides, GLSL matrix layouts, nested/helper data, original 128-byte snapshots, specialization and width conversions. `graphics` checks both languages' actual float-target pixels using internal Half data with 32-bit stage transfer. `canvas` checks two sequential retained renderer lifecycles. Prepared work/readback intervals check owner-thread managed allocations.

Build with `dotnet build tests/DeviceFP16.Consumer -c Release -r linux-x64` and the ordinary native-consumer library properties when shared native prerequisites are not built. HLSL native types may come from includes; explicit native16 tokens select shader model 6.2. The `legacy` fixture checks that comments, inactive branches and line directives preserve the established 32-bit HLSL half behavior. Pinned DXC rejects direct Half specialization: HLSL specializes float then converts, while GLSL/SPIR-V checks typed Half overrides.

`profiles` checks independent arithmetic, storage-only buffer/uniform data, a two-byte push block and legacy HLSL. `unavailable-arithmetic`, `unavailable-buffer`, `unavailable-uniform`, `unavailable-push`, `unavailable-all` and `unavailable-api` require the test-only tools/render-native/test_shader16_mask.c SDL3_DYNAMIC_API shim; set ELECTRON2D_TEST_MASK_SHADER16 to the suffix. Buffer refusal also disables Uniform16, whose capability implies Buffer16. Supported sibling profiles must execute; unsupported shader/binary publication must reject. Exact Half push reconstruction additionally requires Float16 arithmetic. `unavailable-io` expects absent storageInputOutput16 or its test mask; it checks original Half stage module rejection. Do not ship the shim.

Publish with `dotnet publish tests/DeviceFP16.Consumer -c Release -r linux-x64 -p:PublishAot=true -p:PublishTrimmed=true -p:TrimMode=full -p:IlcTreatWarningsAsErrors=true -p:ILLinkTreatWarningsAsErrors=true -o tests/DeviceFP16.Consumer/bin/aot` and run the same profiles. Other hardware/platforms, native allocations, throughput and human acceptance require separate verification. Raw bit tests do not promise NaN payload preservation through arithmetic.
