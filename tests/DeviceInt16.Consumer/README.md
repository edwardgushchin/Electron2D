# Native Int16/UInt16 device consumer

Public-API-only Release/NativeAOT fixture for packed integer compute and graphics on Linux/Wayland/Vulkan. Run `managed`, `compute`, `source`, `graphics`, `canvas` or `profiles`; `canvas` checks two complete retained renderer lifecycles. `source` compiles both data programs through RDShaderSource before execution. ShaderImport produces GLSL/HLSL device modules during the build. HLSL specializes int/uint then converts to native16; GLSL uses direct short/ushort constants.

The fixture checks every 65,536 signed/unsigned nullable metadata pattern; limits, wraparound, division, positive remainder, shifts, bitwise/comparison results; compact SSBO/UBO; 128-byte push with packed pairs, arrays, nested helper values and dynamic narrow indices; copied specialization/push data; exact native pixels; and zero warmed owner-thread managed bytes. Signed negative remainder/modulo constant semantics are tested separately in the runtime suite; source-language undefined percent inputs are excluded.

`unavailable-integer`, `unavailable-arithmetic`, `unavailable-buffer`, `unavailable-uniform`, `unavailable-push`, `unavailable-all` and `unavailable-api` use the test-only SDL dynamic API shim in `tools/render-native/test_shader16_mask.c`, with matching ELECTRON2D_TEST_MASK_SHADER16. Storage-only values survive arithmetic refusal; Half survives integer arithmetic refusal. Shader and binary publication reject missing prerequisites. GPU stage16 IO needs its actual feature; this consumer uses 32-bit transfer. Other GPUs/platforms, native allocations, throughput and human acceptance remain separate. See [the owning component](../../docs/components/local-compute.md#native-int16-and-uint16-arithmetic-and-packed-data).
