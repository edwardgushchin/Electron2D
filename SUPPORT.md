# Getting help with Electron2D

Start with the [quick start](README.md#quick-start), [API Wiki](https://github.com/edwardgushchin/Electron2D/wiki) and [documentation index](docs/README.md). Check the [platform report](docs/platform-verification.md) when a question concerns native libraries, rendering or a device.

| You need | Where to go |
| --- | --- |
| Installation, public API usage or troubleshooting | [Q&A](https://github.com/edwardgushchin/Electron2D/discussions/categories/q-a) |
| A possible feature or architecture direction | [Ideas](https://github.com/edwardgushchin/Electron2D/discussions/categories/ideas) |
| A reproducible defect or measured performance regression | [Issue forms](https://github.com/edwardgushchin/Electron2D/issues/new/choose) |
| A missing or incorrect documentation page | [Documentation form](https://github.com/edwardgushchin/Electron2D/issues/new?template=03-documentation.yml) |
| A security concern | [Private vulnerability report](https://github.com/edwardgushchin/Electron2D/security/advisories/new) and [security policy](SECURITY.md) |
| Tutorials and examples from the community | [Guides and tutorials](https://github.com/edwardgushchin/Electron2D/discussions/categories/guides-and-tutorials) |
| Share a project | [Show and tell](https://github.com/edwardgushchin/Electron2D/discussions/categories/show-and-tell) |

Include the engine commit or version, OS and architecture, .NET SDK, renderer and the smallest example that reproduces your problem. Paste exact commands and relevant logs as text. Redact credentials, private paths and personal data. Mark a helpful Q&A reply as the answer so other developers can find it.

Electron2D is under active development. The [roadmap](docs/coverage/index.md) and platform report describe current gaps and verification limits. Community help is best effort; no support SLA, paid support service or delivery date is implied.
