# Text-to-speech decisions

Last updated: 2026-11-06

<a id="adr-0118"></a>
## ADR 0118: Display-owned typed native speech synthesis

### Status

Accepted under the complete applicable public API objective and ADRs 0004, 0040, 0047 and 0095. This decision supplies the speech-domain prerequisite in the display coverage register; it does not qualify the full ADR 0021 platform matrix.

### Decision

Keep the nondeprecated TTS family on the static DisplayServer facade. A display lifetime owns the speech producer, request queue and callbacks on its opening thread. Sample ProjectSettings.AudioGeneralTextToSpeech (`audio/general/text_to_speech`, initially false) when the display opens and mark it restart-required in the typed settings registry. Do not activate a native synthesizer when disabled. Feature.TextToSpeech reports an actually available producer. Voice queries return empty snapshots when disabled or absent; speaking/paused queries report false. Unsupported execution controls fail explicitly. Callback registration belongs to the display session even before native initialization; it does not make an unsupported producer available.

TTSVoice is an immutable typed projection of the voice dictionary's ID, Name and Language. Native voice identifiers remain strings and may persist between sessions. Language codes retain the native ISO language/variant form, such as en_US. Filtering is an ordinal prefix match, preserving provider order; an empty prefix selects every voice. Return independent snapshot arrays, not mutable producer storage. Do not expose COM, SAPI or audio handles.

TTSUtteranceEvent retains Started=0, Ended=1, Canceled=2 and Boundary=3. Two TTSSetUtteranceCallback overloads express the existing callback arities: Action receiving a long utterance ID for the first three events; Action receiving an int character position and long ID for Boundary. Reject an enum/arity mismatch before replacing the previous callback. Null clears the selected callback. These are ordinary borrowed typed delegates, not dynamic invocation or a second event framework. Application IDs are opaque signed 64-bit values, including zero, duplicates and negative values; they are not native stream identities.

TTSSpeak queues immutable text/voice/settings and defaults volume=50, pitch=1, rate=1, utteranceID=0 and interrupt=false. Reject null/NUL and nonfinite pitch/rate before changing existing work. Clamp volume to 0..100, pitch to 0..2 and rate to 0.1..10. Validate a nonempty utterance's voice before publication. Interrupt cancels the active request and all pending requests before the new request. Empty text schedules Canceled without starting native output; interrupt still clears old work. Nonempty speech resumes a paused producer, including when a previous request is queued. Pause/resume are idempotent and may apply while idle. Native pause occurs at a provider boundary after buffered output, so already queued word notices may still arrive. Stop retires active/pending work and resets pause after native purge; each canceled request receives one Canceled notice, including duplicate application IDs.

Use the Windows system SAPI provider through private blittable COM vtables and System32 imports, following the existing Windows COM ownership pattern. No managed COM runtime dependency or additional shipped DLL is required. Balance CoInitializeEx only when this producer acquired a COM reference; an existing incompatible apartment is borrowed. Enumerate real tokens and language attributes, select each queued request's exact live token, retain its native stream identity and release every returned COM pointer/string. Native speech uses the system speech output independently of engine audio buses, as an OS accessibility producer; engine movie/audio-bus capture does not implicitly include it.

Windows preserves native SAPI text/SSML-fragment interpretation and a generated pitch wrapper. Native volume/rate/pitch commands affect the actual synthesizer. Map requested rate logarithmically to the provider's supported -10..10 rate range, saturating before calling SAPI rather than silently ignoring a failed out-of-range native setter. Actual voice timbre, rate capacity and SSML support are native provider observations; this mapping is not calibrated cross-host rate equivalence. The missing adapters and acoustic/platform qualification remain explicit completion gaps under ADR 0021.

Boundary positions use Unicode-scalar indices in the original submitted source, matching the engine text coordinate convention. Convert native UTF16 positions, remove the generated pitch prefix and account for decoded predefined/numeric XML entities without treating a surrogate pair as two characters. Preserve markup semantics, canonicalize numeric character references to native-supported literals/predefined entities, and leave comments/CDATA intact; a provider's supported markup and word granularity remain observations of that provider. Preserve original source coordinates when an entity changes the parser's effective text length.

Native synthesis and playback run through the provider; ProcessEvents polls native speech events and starts queued work on the owner. No user callback runs on a SAPI thread or crosses an unmanaged boundary. Deliver a bounded snapshot of accepted notices using the delegate captured at acceptance, preserving order across later callback replacement. Continue other required callbacks/requests after errors and aggregate failures. Speech notices are not input and survive ForceProcessAndDropEvents. Native start failure cancels the failed request, reports the error and leaves later queued work eligible. A callback may enqueue, pause, resume or stop speech; native owner disposal/event-pump reentry still follows the display guard.

Display retirement attempts native purge and releases the producer/COM ownership even on failure, clears pending notices and delegates, and never dispatches into a later display session. Speech does not reserve a modal dialog lifetime or prevent an ordinary close. No public constructor, native pointer or independent scheduler is introduced for the private producer.

### Verification

Exercise the complete public family through source/root, a fresh candidate package and strict full-trim NativeAOT. Independently enumerate native metadata and capture only the tested process tree's real audio through Windows process loopback; prove signal and silence controls (at most one PCM16 conversion LSB for zero output), queue ordering, settings, boundaries, pause/resume/stop/interrupt, duplicate IDs, callback arity/replacement/failure/reentry and session retirement. Keep provider refusal, absent/disabled output and source-coordinate controls separate. Do not infer speech audio from callbacks alone or capture unrelated applications' audio. Physical listening, voice quality, exact cross-provider acoustic equivalence and foreign package/host acceptance remain separate receipts.
