## ADR 0092: Typed 2D mesh surfaces on the retained canvas

### Status

Accepted. Refines the typed resource projection in [ADR 0001](product.md#adr-0001) and the backend contract in [ADR 0028](rendering.md#adr-0028).

### Decision

Mesh : Resource supplies the applicable surface-query/material callbacks. ArrayMesh stores copied two-dimensional vertices, vertex colors, primary/secondary UVs and optional indices through MeshSurfaceData; named fields replace the heterogeneous array-of-arrays without Variant/object dispatch. MeshInstance : Entity projects the MeshInstance2D scene role, preserving borrowed Mesh/Texture, texture_changed and inherited canvas behavior. CanvasItem.DrawMesh and logical RID drawing feed the same retained canvas submission; all five primitive topologies execute through native GPU and compatibility triangles. Points and lines keep one-framebuffer-pixel width after transforms, with no antialias fringe. Per-surface materials override the drawing item's material; unsupported shaders fail through the existing fallback gate.

The native/backend-neutral surface arrays preserve the exercised pinned channel packing: positions are little-endian float X/Y pairs; colors clamp/truncate to RGBA8 UNORM on import; primary UV remains two little-endian float components. Vertex stride is eight bytes. Attribute stride is four bytes for color plus eight bytes per present primary/secondary UV channel, in that order. Region updates use byte offsets, including partial records, validate affected finite values before publishing and preserve untouched bytes. UseDynamicUpdate remains a policy hint and does not make other surfaces inert. Resource queries return independent channel copies; successful repeated updates and replay reuse prepared storage. This is not a public SDL buffer or GPU-device pointer.

Resource Mesh.GetRID is a stable weak borrowed logical identity until disposal, independent of an active renderer. RenderingServer owns caller-created mesh identities until FreeRID/shutdown; owned and resource-owned identities are distinguished before mutation/free. Retained draws observe current ArrayMesh buffers without requiring a fresh command. Custom Mesh callbacks publish Changed after edits and provide copied typed channels; their prepared replay snapshots are refreshed on that revision. Custom callbacks must keep the resource revision stable while preparing a snapshot; changing it rejects the mixed result and permits retry. Repeated replay uses the captured surface count without calling user callbacks. Custom callback allocation is separate from the runtime preparation measurement. MeshInstance uses the ordinary scene owner/capture mutation guards and local Resource graph duplication.

This profile does not redefine unsupported source capabilities as irrelevant. Morph targets/weights and LOD storage/selection require the first typed 2D deformation or scale-selection producer/consumer slice. Mesh skin/bones/weights now use typed MeshSurfaceData/packed-region channels and actual owned/scene palettes, as specified below. Attribute compression requires its encoder/decoder and visible precision verification. Those inputs and flags reject or remain absent, with exact member-specific coverage triggers; no inert setter or nominal data-only support is reported as complete. GetFaces extracts copied local Vector2 triangle faces, expanding indexed and sequential triangles and alternating-winding strips; point and line surfaces contribute nothing. The returned TriangleMesh resource and lightmap-size hint remain excluded as 3D intersection/lightmap capabilities. Shadow mesh requires the first 2D light/shadow geometry consumer; placeholder meshes require the missing-asset placeholder producer. 3D-only triangle-mesh/collision/lightmap operations retain their accepted product exclusions, not an invented 3D runtime type.

ImmediateMesh : Mesh builds one invisible draft through SurfaceBegin, current Color/UV/UV2 and SurfaceAddVertex2D, then SurfaceEnd publishes sequential ArrayMesh-backed storage. First attribute activation backfills earlier vertices with the assigned value; later assignments affect only future vertices. Empty/incomplete topology rejects without losing the draft. ClearSurfaces cancels the draft and removes completed surfaces. End, clear and inherited material edits publish Changed after commit and outside the storage gate, keeping Electron2D resource/canvas invalidation consistent even where the pinned immediate builder does not notify on clear/material edits. Duplication copies completed geometry and material graphs, never transient draft state. Methods serialize individual operations; callers synchronize whole construction sequences shared across threads. Structural authoring is a cold allocation boundary; replay and repeated material/transform updates use prepared storage. Secondary UV now follows the same first-call backfill, future-vertex assignment, reset and commit/copy rules through SurfaceSetUV2. MeshSurfaceData.UV2s and ArrayFormat.TexUV2 carry independent finite coordinate pairs. Packed updates validate both UV channels before any write. ArrayMesh archives write AMS2 with the secondary channel and read legacy AMS1 without it; invalid data preserves prior storage. Retained mesh/custom/skin/instance drawing preserves secondary coordinates, with zero defaults on other geometry. The GPU vertex layout uses a separate float2 at location seven and forwards it to fragment float2 location four, preserving instance custom data at location two and the internal lighting index at three. Compatibility drawing retains ordinary primary-UV sampling and rejects programmable shaders as before. SurfaceTool uses this completed secondary storage/consumer in its typed mesh-authoring profile below.

### Ownership, errors and verification

Meshes own channel storage and borrow materials; nodes and drawing commands borrow meshes/textures. Owned server meshes close with the renderer. Invalid geometry, nonfinite inputs, out-of-range indices and regions fail before mutation. Resource Changed runs after committed edits; callback failure does not roll back valid geometry. Warmed successful paths are checked under [ADR 0014](resources.md#adr-0014). Exact managed/native pixel and platform limits are recorded in the [mesh component](../components/meshes.md); builds do not establish rendered or human acceptance.

### Repeated mesh instances and 2D visibility

MultiMesh owns a fixed 2D schema: eight transform floats followed by optional four-float instance color and raw shader data. The 2D/3D format selector is implicit and absent. Channels must be configured at zero capacity. Resizing clears current/previous records; equal capacity preserves them and shrinking clamps the visible prefix. Packed and legacy-array queries copy storage. Ordinary writes outside a physics tick reset the edited previous record; SetBufferInterpolated supplies a copied explicit pair. Fast interpolates components; High decomposes compatible nonsingular 2D bases into rotation/scale/skew and falls back to components for singular, reflected-sign changes or unrepresentable decomposition. Widened component blending preserves finite cancellation. This corrects the pinned High implementation's use of a 12-float 3D record against an eight-float 2D stride; that unsafe read is not preserved.

SceneTree captures prepared registered resources before physics callbacks and closes capture even when the setting changes during the tick. MultiMeshInstance refreshes the shared resource policy on entry and policy/reset notifications. Shared instances use the resource's most recently assigned effective policy; node-specific disabled presentation uses current poses. Reset copies current values into previous records. Resource duplication resets transient snapshots and renderer binding; copying stored state into an existing resource retains its active binding. Mesh/texture remain borrowed, and resource Changed callbacks invalidate attached canvas state safely from worker threads.

Mesh.GetAABB/OnGetAABB and MultiMesh bounds are applicable 2D visibility operations projected to Rect2, including XY bounds for every stored vertex/topology. No public 3D AABB is added. Automatic instance bounds merge the visible prefix's transformed mesh rectangles; presentation culling uses interpolated poses. CustomAABB overrides the resource-local rectangle, with the zero rectangle selecting automatic computation. The native viewport and managed scissor checks exercise culling. Custom geometry callbacks must retain stable resource revisions during bounds and surface preparation; recursive preparation, disposal and mixed snapshots reject before submission and permit retry.

DrawMultiMesh, MultiMeshInstance and server-owned logical identities preserve surface-then-instance draw order. The GPU backend may submit unskinned ArrayMesh/ImmediateMesh triangle surfaces through a retained hardware instance stream when pixel snapping, screen-notifier geometry and canvas compositing do not require expanded vertices. Each frame captures finite presentation poses, colors and custom data into renderer-owned storage before submission. Other cases retain CPU geometry expansion into reusable triangles. This does not expose writable GPU buffers or device identities. Both current native backends consume poses, colors, UVs, material overrides and inherited canvas policies. Custom data is preserved as raw float32 components on all backends and reaches an optional GPU fragment float4 at location two, independently of tint. Compatibility rejects custom shaders explicitly. Shader vertex programs remain their separately recorded dependency.

RenderingServer owns created MultiMesh storage and borrows its Mesh identity; resource-owned identities remain weak and cannot be mutated/freed through owned APIs. MeshCreate now records its canonical RID in the owned resource so linked mesh queries return that same identity. MultiMeshAllocateData executes the ordinary typed allocation atomically; useIndirect=true rejects before mutation. Indirect commands and the two RenderingDevice buffer RID getters remain blocked until actual writable instance/command buffers, device identity, synchronization and a draw consumer exist in the first writable device-buffer slice. No synthetic device RID is returned.

### Skeletal scene palettes and weighted polygons

Skeleton : Entity and Bone : Entity preserve the applicable scene/canvas inheritance and dimensionless family mapping under ADRs 0004/0008. Direct Bone chains form child-order DFS palettes, retaining inverse rest and authored versus temporary poses. Singular/unset rest remains authorable with identity deformation. BoneSetupChanged runs after commitment; structural changes during modifier execution reject before mixed application. A stable weak borrowed logical RID connects retained Polygon commands to the live rig independently of native startup; server FreeRID rejects scene ownership. Caller-owned palettes and transient canvas attachment now supply an actual Mesh/MultiMesh consumer, as specified below.

Polygon stores copied bone paths/weights and prepares four strongest positive influences, retaining equal-weight order and original contour source indices. It normalizes with widened arithmetic, maps actual interpolated Polygon/Skeleton coordinate bases and uses pose multiplied by inverse rest. TopLevel follows actual presentation pose. Missing/count-mismatched/zero-weight bindings preserve original vertices; inversion ignores skin. One viewport/CanvasLayer is required. Triangulation, UV/color/materials remain ordinary retained triangles shared by GPU/compatibility. Mesh skin arrays, packed regions and all four/eight weights now execute through the same canvas output; Polygon keeps its own normalized strongest-four policy.

SkeletonModification/Stack/LookAt use typed resource callbacks, scene-owner guards, ordered nullable borrowed slots and exclusive live scene binding. Shared ProcessPhase projects semantic source Process/Physics modes explicitly (Idle=1/Physics=0); no duplicate enum is introduced. Physics stages overrides and restores authoring; Idle restores authored animation, executes, blends and consumes transient overrides. Persistent=true retains requests, including without a stack, correcting the pinned source's inverted consumption condition to its documented API. LookAt submits transient requests to keep disable/reset behavior, uses actual endpoint/target/constraint rotation and normalizes multi-turn angles beyond the pinned one-turn adjustment. ConstraintInLocalSpace is the typed stored coordinate policy; editor gizmos require the actual editor owner.

PackedScene force-copies a rig's stack/modification graph through the existing duplication session regardless of ordinary shallow resource policy, retaining graph aliases and instance-owned cleanup. Rest/endpoints, concrete settings and bounded versioned Polygon records persist; setup, weak scene targets, palette identities and overrides do not. Callback failures retain committed structure, attempt all pose restoration, release guards and permit explicit setup retry. Warm successful pose, ordinary redraw and replay reuse prepared storage under ADR 0014. Actual managed/native/fresh-process checks and limits are recorded in [skeletal animation](../components/skeletal-animation.md); other IK/physics/editor capabilities retain precise triggers.

Three concrete resources project the complete applicable TwoBoneIK/CCDIK/FABRIK family to SkeletonModificationTwoBoneIK, SkeletonModificationCCDIK and SkeletonModificationFABRIK, with fully uppercase acronyms across selectors/accessors. They retain semantic phase/strength and transient override ownership rather than a new solver/rendering interface. Relative indexed joint authoring is typed, bounded and copied; actual stored CCD constraint_in_localspace is available through explicit typed indexed methods. Bound index selections also author paths, retaining identity through hierarchy changes. Missing/degenerate selections skip undefined solves.

TwoBoneIK applies conservative scaled lengths and finite inner/outer/coincident reach handling. CCD preserves its single authored-order pass; FABRIK keeps ten iterations and .01 pixel tolerance, measures scratch convergence, uses finite coincident direction fallback and positive reflected length. Final target rotation and non-root world magnets participate in its actual solve. Nonuniform/skewed bases keep the source minimum-scale length policy with no exact anisotropic reach guarantee. The existing scene transaction now restores pre-pass requests as well as authored poses on failure, using reusable setup buffers, so partial IK results cannot escape a failed pass. Joint configuration persists through existing exact resource schemas/independent stack copies; weak caches and scratch do not. Actual headless/fresh-process/native evidence and remaining physics/editor/mesh limits are recorded in the component.

Jiggle and StackHolder retain the same typed resource/pose profile as SkeletonModificationJiggle and SkeletonModificationStackHolder. Jiggle configuration/default propagation and transient finite force/velocity history are distinct from scene Bone nodes. Reset seeds every valid origin including index zero; positive mass prevents undefined zero division. Current global defaults seed new slots. Collider mode uses the existing world-scoped body ray in Physics; Idle collider use rejects explicitly instead of an inert collision setting. The query protects a dynamic point, not the whole bone/mesh. Individual successful joint state commits remain observable after a later failure, while scene poses and prior requests retain the established transaction restoration.

Held stacks borrow the same skeleton, keep independent strength and phase selection, and release weak incoming-holder leases only after their final holder disappears (with direct-root binding tracked separately). Copies always duplicate child graphs through the shared alias-preserving resource session. Setter/setup/execution cycle/depth guards and pre-transition active disposal/reset guards bound failure; assignment commits before setup and failed child setup invalidates the parent for retry. Explicit child execution starts a transaction for that child rather than entering unrelated root siblings. These refinements preserve actual applicable resource ownership and do not introduce a public generic solver/backend interface. Exact storage, native/headless checks and limits are documented in the component.

### Typed surface authoring and indexed geometry

SurfaceTool : ElectronObject projects the generic mesh authoring role onto two-dimensional MeshSurfaceData. AddVertex uses Vector2, AppendFrom uses Transform and GetAABB uses Rect2, consistently with Mesh bounds and surface storage; no 3D scene, transform, AABB or geometry type is added. AddTriangleFan projects supported positions/color/primary and secondary UVs; optional numerical normal/tangent arguments share the completed channel pipeline. These coordinate-role adaptations supersede blanket signature-based exclusions for these mesh authoring operations only. Native drawing consumes committed surfaces through the existing mesh path and indexed RenderingDevice buffers.

Begin replaces prior authoring; channel activation precedes the first vertex and later setters change subsequent values. CommitToArrays returns independent current arrays, including incomplete drafts. Commit validates complete topology/indices, appends copied geometry and borrowed material atomically before one Changed, and preserves authoring for repeated commits. Empty Commit returns the existing/new empty mesh. Listener errors retain published target data. Imported geometry permits structural editing and commit; new incremental authoring requires Begin. Source callbacks must retain stable mesh revisions and cannot mutate/dispose their receiving builder.

Four/eight skin width is a real selection retained across Begin, reset by Clear and inferred from imported data. It may change before the first vertex, preventing mixed captured schemas and correcting the unusable eight-slot selection in the pinned begin/clear sequence. Bones and weights enable as a pair; short lists pad zero, overfull lists stably retain strongest influences and normalize with a finite double sum, while ordinary four/eight lists preserve authored weights before mesh UNORM16 packing. Exact indexing includes every captured attribute and smooth-group identity; deindex preflights all references before publishing expanded records.

Append validates source topology and skin compatibility, preserves drawing across mixed indexed/sequential inputs, fills missing ordinary channels with their actual white/zero defaults and transforms finite copied positions before replacing state. Triangle fans preserve already indexed geometry when appending new triangles. Numeric Vector3 normals and Vector4 tangent/handedness values are shader data under ADR 0004, not 3D scene/Plane types. Their authoring/generation and the matching optional fan payloads execute through the normal/tangent pipeline below. Four custom channels execute through the shared codec/consumer contract below; morph authoring retains its precise prerequisite. Deprecated GenerateLOD remains Excluded using pinned metadata; it is not an implementation trigger. Index-cache reordering must execute against actual indexed output and preserve triangle winding/data; any native-cache speed claim needs separate measurement.

### Numerical normal and tangent channels

MeshSurfaceData.Normals contains optional finite Vector3 directions, and Tangents contains optional finite Vector4 XYZ directions with W handedness. These are mesh-local shader data and add no spatial scene domain. ArrayFormat.Normal=2/Tangent=4 share one enum family with RenderingServer. Ordinary surfaces retain two-float positions in the first contiguous block; interleaved normal/tangent records follow that block, four bytes per present channel. Each direction uses octahedral UNORM16 with float32 clamp/truncate. Tangent encoding preserves the sign bit with the pinned bias and reserved-code sanitation. Exact words are retained internally, so partial updates, archives and tangent regeneration do not drift untouched bits. Zero directions have deterministic positive-Z storage instead of undefined NaN conversion; finite extreme encoding uses widened normalization. Normal-only input produces the actual arbitrary fallback tangent and tangent flag. Attribute color/UV strides and skin records remain separate.

ImmediateMesh captures/backfills both channels through SurfaceSetNormal/SurfaceSetTangent. SurfaceTool enables them before the first vertex, imports/appends/indexes every captured field, accepts optional fan values, and generates clockwise-front planar normals with flat minus-one or shared position/group smoothing. Indexed normal generation expands and reindexes seams; opposite unit face contributions cancel, and degenerate faces contribute zero. MeshDataTool.GetFaceNormal follows that same clockwise-front convention, correcting its previously reversed sign. Append applies inverse-transpose XY normal data, basis-transformed tangent data and reflected handedness; normal-bearing singular transforms reject before replacement. MeshDataTool readers/writers use the shared channels. Tangent generation uses the internal vendored MikkTSpaceSharp under ADR 0012, validates before publication, calibrates extreme position/UV spans and releases all temporary unmanaged blocks on errors. Indexed shared vertices retain the last face-corner output, matching the producer contract. ArrayMesh.RegenNormalMaps prepares every surface before one atomic publication, retains exact normal words, names/materials/policy flags, and preserves old storage after any generation error.

The retained CanvasVertex adds float3 normal at byte 56 and float4 tangent at 68 (84-byte stride). GPU inputs use locations eight/nine and forward to optional fragment float3 location five and float4 location six. Ordinary, custom, points/lines/strips, hardware instances, palettes and canvas groups preserve these mesh-local values. Canvas transforms and skin deform positions; they do not reinterpret this numerical payload as world-space shading. Missing channels on other geometry forward zero. Compatibility retains ordinary texture/color output and its existing shader rejection. ArrayMesh archives write AMS3 with exact words and still read AMS1/AMS2; malformed input preserves prior geometry. Structural generation/import/copies may allocate; warmed packed edits and completed replay reuse storage. Native GLSL/HLSL indexed/retained pixels, compatibility pixels, fresh-process output, 100 C-reference fixtures and temporary allocation balance are checked on Linux/Wayland; full native allocation totals, broad performance and other platforms remain separate limits.

### Owned server palettes and mesh skin channels

RenderingServer.SkeletonCreate/AllocateData/GetBoneCount, SkeletonBoneGetTransform2D/SetTransform2D and SkeletonSetBaseTransform2D preserve the two-dimensional member identities and use dimensionless Transform/RID types. All storage is 2D; no inert dimensional selector is exposed. Owned palettes live until FreeRID or renderer shutdown. Resize clears transforms to zero, equal capacity preserves data and the base transform is retained. Finite singular/reflected matrices remain authorable. Scene Skeleton.GetSkeleton palettes are weak/borrowed, readable as actual pose-times-inverse-rest transforms and protected from owned writes/free.

CanvasItem.GetCanvasItem supplies a stable weak scene identity independent of native startup. CanvasItemAttachSkeleton attaches one borrowed owned/scene palette to that item; the identity cannot be freed by the server. The connection is transient, not inherited or serialized. Scene palettes share actual viewport/canvas-layer ownership with their consumer. Missing/freed/detached/empty palettes or singular item/base coordinates preserve original geometry; valid attached palettes drive Mesh, custom Mesh and MultiMesh commands without rerecording. General caller-owned canvas creation/command authoring remains its own exact dependency; this bridge does not synthesize those objects.

MeshSurfaceData adds copied flattened Bones/Weights. A vertex has four slots or eight under Use8BoneWeights. Bone indices validate in 0..65535 before import; finite float weights clamp/truncate with the pinned float32 multiplication to UNORM16 without normalizing their sum. Matching explicit channel bits are accepted and absent requested channels reject. Skin bytes contain per-vertex uint16 indices followed by uint16 weights, with 16/32-byte stride; partial byte updates retain untouched values. Skin stride queries and the ArrayWeightsSize=4 constant use the same format family shared between Mesh and RenderingServer under ADR 0051. Numeric heterogeneous-array selectors remain excluded under ADR 0001; actual channel capabilities remain independently accounted.

Replay conjugates the palette through item/base canvas matrices, sums weighted deformation with homogeneous translation scaled by the weight sum, then applies the ordinary command-local mesh and presentation transforms. Zero weights collapse the position to local zero under a valid palette, unlike Polygon's separate normalized fallback. Every authored index must resolve before emission, including zero-weight slots. Mesh bounds queries remain authored/rest bounds. Attached skinned MultiMesh replay conservatively bypasses rest-bound culling to avoid removing geometry moved into view. This is prepared CPU deformation feeding ordinary GPU/compatibility triangles, not a hardware skin/compute buffer claim. All eight influences execute on both backends; this corrects the pinned RD two-dimensional skeleton shader's omission of its second four-weight group.

Owned palette replay holds a bounded reader count through custom mesh/material callbacks and releases it in finally. Palette write/resize/free reentry rejects before modifying a captured view; owner/submission/capture gates remain enforced. Packed-region arithmetic uses widened byte offsets across vertex/attribute/skin siblings. Invalid updates and malformed archives preserve prior data; Changed observer errors retain committed edits.

ArrayMesh now has exact built-in file registration, bounded versioned geometry/channel/name storage (4096 surfaces, 65536 name code units, 64 MiB) and a separate typed borrowed material array preserving resource graph aliases. Geometry validates fully before replacement. Material/mesh identity, live palette attachment and renderer bindings remain transient; fresh .e2dscene processes load and execute actual skin geometry. Structural imports, archives, copies, resize and first preparation may allocate; prepared replay and byte/pose updates use retained storage. Native/headless verification and remaining attributes/morph/compression/general owned canvas/platform limits are recorded in the component.

### Four numerical custom channels

MeshCustomFormat is one namespace-level value contract shared by Mesh, SurfaceTool and RenderingServer under ADR 0051. MeshCustomData supplies a typed format and copied little-endian byte records; MeshSurfaceData.Custom0 through Custom3 name the four independent payloads. This projects the existing channel schema without a heterogeneous array or dynamic object dispatcher. Eight formats carry RGBA8 UNORM/SNORM, RG/RGBA half and R/RG/RGB/RGBA float data; Max disables an unactivated authoring channel and is never valid storage. SurfaceTool selection/capture, exact import/index/append, ArrayMesh attribute-region updates and archives use the same formats. Shader consumers receive four optional mesh-local float4 values independently of instance custom data. Missing components use zero RGB/one alpha; absent channels forward zero. Array-format presence flags use bits 6 through 9; three-bit format selectors start at 13, 16, 19 and 22. The attribute buffer orders color, primary UV, secondary UV then each present custom record. AMS4 preserves exact schemas/bytes and reads AMS1/AMS2/AMS3. Imported structural edits retain raw words, including half subnormals. Authoring normalized codecs clamp/truncate, half conversion truncates and flushes tiny values; values that would encode half infinity reject. Shader signed normalization clamps the minimum code to minus one.

SurfaceTool append selects each present incoming custom format and preflights existing-value reencoding before publication. It does not combine format-selector bits with bitwise OR: such a combination would silently select another codec. Missing channels fill zero RGB/one alpha. Captured channels may change format after successful captured/current-value preflight but cannot be disabled. Capture preflights the current value after append changes its selected schema. Exact indexing compares canonical selected-format records independently of capture origin while retaining distinct raw signed-zero words. GPU vertex locations 10 through 13 carry mesh custom float4 values to fragment locations 7 through 10; instance custom data remains independent at location 2. Current Linux GLSL/HLSL retained pixels exercise all eight formats, ordinary/authoring/custom meshes, hardware instances, eight-slot skin, strips, points, lines and groups; 64 active and 64 idle frames allocate zero managed bytes. Wider platforms and complete native allocation totals remain unverified.
