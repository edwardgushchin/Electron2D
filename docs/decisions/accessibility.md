# Native accessibility and semantic scene output

Last updated: 2026-10-26

<a id="adr-0114"></a>
## ADR 0114: Typed accessibility elements with a native assistive-technology bridge

### Status

Accepted. This implements the current service ownership required by [ADR 0041](display.md#adr-0041), without reviving its retired DisplayServer API. Public operations follow [ADR 0095](singleton-services.md#adr-0095); scene ownership, compiled callbacks and allocation rules retain ADRs 0006, 0010, 0011 and 0014.

### Decision

AccessibilityServer is a static public service backed by a permanent internal ElectronObject. It owns session-unique element RIDs, typed roles/flags, parent/child relationships and registered compiled actions. RIDs are distinct from rendering/physics resources and never reused. Window roots are owned by the native window; ordinary elements by their producer, while sub-elements retire with their semantic parent. Stale/wrong-kind identities, foreign windows, cycles, incompatible action signatures and nonfinite geometry fail explicitly. Native failure must not publish an apparently supported service.

The first executable profile connects the core element tree, names/descriptions, bounds, checked/disabled/hidden state, focus and no-argument activation to Linux AT-SPI through the system GIO/GLib ABI. It exports the actual Accessible, Application, Component, Action and Cache protocols, registers with the session accessibility registry and emits topology/property/state/focus changes. The adapter owns its connection and private main context. Native requests run on the display owner during the existing event pump; application callbacks never run on a bus worker thread or cross an unmanaged exception boundary. Callback failures follow the display pump's aggregated exception policy. Retiring a window removes its tree and retiring the display releases all native registrations and connection/context ownership.

The runtime keeps one managed assembly. This Linux adapter uses the host's optional native GIO/GLib libraries and accessibility bus; missing libraries, absent bus and other targets report unavailable without a simulated native bridge. No desktop settings are changed. Native support, actual application registration, semantic output and a real assistive-client request remain distinct verification gates.

Automatic scene output uses Node element identity and queued accessibility-update notifications. Control adds stored, translatable accessible name/description. A visible Label uses its displayed text; a Button uses its displayed caption unless an explicit accessible name overrides it. An icon-only action needs an authored name, not an implementation identifier. Hidden/detached/disposed controls cannot be focused or activated. Existing keyboard focus and button activation paths own behavior; accessibility requests reuse them. Accessibility-only focus becomes eligible while the accessibility runtime is active. Scene copying/files retain authored metadata, never process-local element RIDs or callbacks.

The typed project policy supports automatic activation from the host's accessibility-enabled setting, explicit always-on output and disabled output. Tests use their own application's policy and never enable a desktop screen reader globally. Cold registration, topology changes and native queries may allocate; unchanged warmed frame work must preserve the existing zero-managed-allocation boundary. Native allocator totals remain a separate measurement.

Only behavior with a complete native consumer is exposed in each connected slice. The remaining color payload actions and descriptive metadata retain exact follow-up dependencies. Their declarations must not become inert setters, invented generic value containers or unsupported callbacks. The complete applicable reference family remains the target; a partial first profile does not redefine that target.

Numeric producers expose double values, finite ordered bounds and finite nonnegative step/jump through the native Value interface. Value itself preserves IEEE values already accepted by Range; native writes require a finite double and a compiled Action<double> registered for SetValue. No-argument callbacks accept Click/Focus/Blur/Collapse/Expand/Decrement/Increment, sequential scrolling and ShowTooltip/HideTooltip/ShowContextMenu. A callback owns mutation; a request never fabricates a published result. Read-only, hidden, disabled, detached or retired producers reject native writes and numeric actions. Callback failures retain the owner-pump aggregation policy.

Range descendants automatically publish their numeric state: Slider, ScrollBar, SpinBox and read-only ProgressBar/TextureProgressBar use distinct native roles. Increment/decrement use positive Step or one, following the semantic range action policy. SetValue reuses Value, including rounding, page caps, sharing, protected hooks and signals. Native reads preserve MinValue/MaxValue as authored; Page is a large step, not a replacement bound. Non-editable Slider/SpinBox and progress displays are read-only. SpinBox native focus targets its owned field; that field selects the parent numeric element for semantic focus so the current value remains attached to the focused identity. The native Value protocol has no page-step property, so a positive numeric jump with a SetValue callback creates actual page-decrement/page-increment Action entries. Their requests pass current published value plus/minus jump through that same callback. Value text is formatted only on a native query; unchanged warmed frames do not format strings or create delegates. Scene overrides run after automatic defaults and remain until their source field changes.

Semantic relations are non-owning, typed element links within one native window. The six related-element add methods preserve insertion order and deduplicate targets. MemberOf, ErrorMessage and InPageLinkTarget replace one target; an empty RID clears them. ActiveDescendant also accepts empty to clear and otherwise requires a strict semantic descendant. It emits the native active-descendant event and selects that descendant when its owner has semantic focus. Reparenting invalidates an active target that no longer descends from its owner. Ordinary non-hierarchical relation cycles do not change ownership or recurse.

Accessible.GetRelationSet publishes direct and protocol-defined reciprocal links. Radio peers use MemberOf; the source excludes itself and detached, retiring, non-toggle or foreign-window group members. ErrorMessage supplies the error relationship and invalid-entry state. A link exposes one real Hyperlink anchor while it has an internal target or nonempty external URL. GetObject preserves the internal target when present and otherwise returns the source accessible for an external anchor. GetURI returns the independent external URL, or empty for an internal-only anchor. Neither query opens a resource or probes network reachability. Without an originating Hypertext range, indices remain unknown (-1). Clearing either endpoint preserves the other; retiring an internal target does not erase an external URL. The interface is advertised only while an anchor exists. Native target retirement removes incoming/outgoing links before freeing registration, including focus/error/anchor changes. Retirement attempts all cleanup even after native notification failures.

Control stores four caller-owned string path arrays for controls, described-by, labelled-by and flow-to. Arrays are copied in and out, preserve authored paths through scenes/duplication and resolve against the current tree. Empty/missing paths are ignored until resolvable; cross-window targets are ignored by automatic output and reject explicit service mutations. Automatic links and manual producer links have separate provenance so source reconciliation never removes a manual link. Native forward targets follow current authored source order, then additional manual targets in their insertion order; a pure reorder emits a relation change. Topology, element identity, path-property and radio-group changes reconcile the graph. Unchanged warmed frames reuse prepared relations and allocate no managed storage. A valid authored label suppresses the existing unnamed-action warning without duplicating that label into Name.

Text producers publish actual Unicode scalar content through native Text and EditableText. CreateSubTextEditElements snapshots a borrowed shaped buffer into a parent-owned line with copied scalar rectangles and actual run font/language/direction metadata; later buffer/font retirement cannot leave native pointers behind. The line keeps an optional trailing newline and minimum cross-axis height. Text runs remain distinct from generic names and descriptions. UpdateSetValue supplies a textual value, while shaped/source lines provide the text tree. Text alignment, orientation, decorations, foreground/background, language and placeholder have native text-attribute consumers. Non-owning previous/next-on-line links join adjacent fragments for native visual-line queries; literal newlines remain boundaries, and target retirement clears links. Native font size uses points at the protocol's nominal 96 logical pixels per inch; physical DPI calibration is not inferred from this metadata.

Text selection uses directed descendant-line RIDs and scalar offsets. Native caret/selection requests use a compiled four-argument callback; replacement uses a string callback. Generic producers own mutation and publication. Automatic LineEdit/TextEdit/CodeEdit producers reuse their ordinary editing/history/signals/length and read-only rules. TextEdit exposes existing multiple selections through native indexed operations. Disabling user selection rejects selection requests but does not make an otherwise editable field read-only. Password fields publish only their displayed mask and reject native copying/cutting. IME composition is not committed text; character geometry accounts for its displayed insertion.

Native queries cover scalar text, ICU word/sentence boundaries, visual lines/paragraphs, actual character/range geometry, point hits, bounded ranges, inherited/run attributes and selection state. Unknown selectors and out-of-range offsets return wire argument errors. Unknown screen origins preserve the established unavailable screen-coordinate sentinel. Text scrolling reuses source scroll state without moving selection; generic producers lacking a scroll consumer return false. Cold native queries, shaping snapshots and content edits may allocate. Unchanged source publication and warmed caret changes reuse prepared state. Text source retirement and reparenting clear invalid selections before unregistering identities; native callback failures retain owner-pump aggregation.

Scroll publication uses finite local offsets and optional finite ordered ranges. It is distinct from numeric Value; setting metadata never clamps or mutates content. Compiled unit/hint/vector callbacks consume native directions, edge/point placement and absolute offsets. Producers own mutation/publication and may retire themselves during a request. Native Component traverses scrollable ancestors and projects coordinate spaces; unknown screen origins and noninvertible projections cannot fabricate success. The [service contract](../classes/AccessibilityServer.md#native-scrolling) owns exact selectors, units, guards and source adaptation.

Automatic scrolling covers the existing eight source families, including text row/pixel conversion, RTL and tab quantization, and unbounded graph panning. Source scrolling reuses ordinary control behavior without changing selection/focus. Visible and showing are distinct; clipping does not disable off-viewport interaction. Native clipping/hits reuse actual rendered clip geometry, while empty semantic groups retain their descendants. Retirement disconnects parentage before visibility events; removed text lines cannot query absent source geometry. Queries retain cold allocation boundaries, and prepared source publication retains the warmed frame boundary.

Collection output exports native Selection/Table/TableCell through typed publication and actual source records. ItemList items, Tree cells/headers and TabBar tabs own transient identities keyed by their source objects, independent of scene storage. Same-window transfer reconciliation completes before stale records retire. Tree cells stay direct table children for native child-index navigation; separate non-owning parent/child relations retain hierarchy. Ordinary public source selection, activation and Collapsed behavior own mutations. Generic selection requests reuse compiled Focus/Blur callbacks and producers publish their resulting state. The [service reference](../classes/AccessibilityServer.md#native-collections) owns exact index, span, preflight, response-capacity and lifetime contracts. Prepared source selection changes retain the warmed managed-frame boundary; native queries and topology/layout work retain their cold boundary.

Live regions publish typed Off/Polite/Assertive policy and emit the native Object.Announcement event after source reconciliation or the owner pump. Changes coalesce to the latest content; an explicit Off region stops inheritance. Hidden, protected or retired producers do not announce. Actual displayed captions remain distinct from authored accessible names. Popup kind and tooltip text have native attributes/states; typed no-argument actions invoke real tooltip or context-menu presentation. Control stores its live policy; source changes replace automatic defaults while explicit service overrides persist until that source field changes.

PopupMenu owns semantic item identities independently of its internal rendered item canvas. Native popup surfaces own separate roots; embedded popups retain their containing native root. Selection changes focus without activation; Click uses ordinary menu callbacks and explicit check/radio state. OptionButton opens its owned list; text controls open their owned menus and preserve caller customization. LineEdit creates a stable borrowed menu lazily and stores ContextMenuEnabled. The shared typed text command enum includes the two real submenu IDs; count sentinels remain excluded. Exact publication, source and lifetime behavior belongs to [the live and popup service contract](../classes/AccessibilityServer.md#native-live-and-popups).

Custom actions publish signed integer IDs and descriptions through native Action ordinals and use one compiled integer callback. Equal-ID publication updates its description without moving its ordinal; empty descriptions do not add an action. Missing callbacks return false. Requests retain hidden/disabled/lifetime guards and owner-pump failure/reentry handling. ExtraInfo remains separate from the base name and appends context to the native label/cache/name event. Source drag feedback uses this name context, while explicit grab announcements use assertive native output. Changed native name composition uses stack/native UTF-8 storage, preserving the managed frame allocation boundary; native allocation totals remain separate.

Contextual Control hooks publish native HelpText and parent-provided container position in the accessible name. A parent forwards the immediate child at each Control boundary; non-Control parents stop inheritance. Queued source updates, ancestor context generations, topology and locale changes refresh retained fragments before publication; unchanged frames do not invoke contextual hooks. Native name composition includes the retained fragment without managed concatenation. Shortcut publication uses the standard Action keybinding triple; real button/menu bindings are formatted only on cold native queries and reflect borrowed event edits. Explicit overrides persist until their source text changes. Role descriptions and class names use native Accessible attributes without changing role taxonomy.

Hyperlink NAnchors uses the native signed 32-bit ABI: both pinned libatspi and its ATK adapter exchange int32, despite the pinned XML incorrectly spelling int16. Introspection and returned values must agree with the executable client/provider ABI; raw XML validation alone did not establish the earlier anchor count.

External URLs publish through the existing native Hyperlink interface without changing role, Click behavior or related-node ownership. LinkButton supplies its actual stored URI; unchanged source values preserve explicit service overrides until the URI changes. Empty clears only the URL. Native UTF-8 normalization follows existing metadata rules; authored strings remain unchanged. A URI is published as supplied, without installing a handler, resolving a path or launching an application.

### Verification

Require a separately launched AT-SPI client to discover the application and controls, read names/roles/states and window-relative bounds, request focus and activate an ordinary button through the native bus. Exercise native Value reads/writes, small and page actions, read-only/editability transitions, nonfinite input, shared ranges and visible slider-to-progress updates. Exercise live property/topology updates, borrowed/stale/wrong-kind RIDs, sub-element ownership, invalid geometry/cycles, callback failure/reentry, window/display retirement and fresh reopening. Exercise native scrolling with nested/affine ancestors, RTL, finite extremes, oversized targets, source focus/selection preservation, callback failure/reentry and source retirement. Exercise native text/selection/replace, Unicode and password boundaries, shaped snapshots, multiple carets, font/attribute and geometry reads, and source retirement. Verify authored metadata through duplication and a fresh-process scene archive. Exercise native selection/table/cell navigation, merged spans, headers, folding, offscreen items, source signal policy, stable reorder/transfer, retired cells and callback failure/reopening. Exercise live priority/coalescing, inherited/Off regions, password/hidden/retired suppression, explicit tooltips, context edits, preserved custom menu entries, menu selection/submenus and separate native popup roots/retirement. Exercise both current canvas backends and warmed active/idle intervals; report software-native, physical-device, foreign-platform and human screen-reader acceptance separately.

### Rejected alternatives

AccessKit C 0.23.1 was evaluated against its pinned C/Unix adapter sources. Its Unix backend follows the desktop accessibility-enabled state and the C API exposes no per-application force-enable option. The current host has that desktop state disabled. Changing global desktop preferences or adding an ineffective always-on project switch is not an acceptable implementation of the application policy. The direct GIO adapter can publish this application's tree without changing that preference; native discovery and actions must be verified independently.
