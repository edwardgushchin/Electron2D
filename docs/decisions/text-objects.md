# Standalone text objects

Last updated: 2026-10-20

## ADR 0107: Typed retained line and paragraph buffers

- Status: Accepted
- Scope: retained TextLine/TextParagraph, shared inline keys/metadata, TextServer shaped-buffer ownership retained provider discovery and stateless Unicode text utilities

### Decision

Expose every applicable pinned TextLine member through the current FreeType/HarfBuzz/TextLayout backend. Draw/DrawOutline receive a recording CanvasItem, following Font's accepted typed canvas substitution. Font resources remain borrowed; segments retain their exact font/size/language and typed metadata. AddString has the ordinary no-metadata overload and an inferred generic metadata overload; TryGetSpanMetadata and SpanCount make retained values usable without Variant/reflection. TextObjectKey is a caller-owned reference-identity token for every add/resize/has/rect/list position, including duplicate copies. No universal key/value dispatch is introduced.

GetRID is a stable borrowed identity of the owned full shaped-buffer and display-policy pair, registered weakly in the internal text owner; actual drawing resolves that identity. Disposal unregisters it and retires only this object's layout/neutral-font state. TextServer buffer operations use this same owner and the existing native shaping/raster foundation. TextServerManager is the permanent static service under ADR 0095; its retained TextServer interface is an explicit implementation object, with instance operations rather than a second process service or public Instance accessor. Standalone buffers created by that interface are strongly retained until FreeRID; borrowed text-object identities cannot be freed through the interface. Access remains bound to each buffer's creating thread. Typed Font lists and copied OpenType features project font-source parameters without exposing native font handles. The interface's font-cache and extension/provider registry families retain their separate executable ownership prerequisites.

Preserve defaults, concatenated multi-size/language segments, all inline alignment/length/baseline policies, BIDI overrides, tabs, inferred direction, metrics, hit positions, trimming/ellipsis/justification and horizontal/vertical rendering. Size and width use the source's ceiled trimmed metrics; ascent/descent remain fractional. Inline rectangles and caret geometry refer to the complete shaped buffer, with the same display alignment offset. Keep full and display layouts independently retained to preserve that distinction. An empty buffer has zero natural geometry; explicitly authored buffer top/bottom spacing contributes signed cross-axis metrics. Inline-only buffers use an internal zero-source Font owner instead of inventing an external font requirement. Multiple replacement scalars occupy one logical object and one advance.

The creating thread owns all access. Mutation/disposal/reentry is rejected while native/layout work is active. Font generations and retained multi-font read scopes invalidate/retry coherent shape state; disposed borrowed fonts fail explicitly. Authoring/settings/output arrays are cold; prepared metrics/hit/draw reuse workspaces. Text and object expansion are bounded to 1,048,576 Unicode scalars and 64 MiB UTF-16 text. Invalid missing glyph display and control display are independent real policies. Add/resize returns false only for duplicate/missing keys; an empty string is a successful no-op, while invalid typed inputs throw before publication. Explicit BIDI ranges must cover the current buffer contiguously; clear them before appending further content.

Duplicate copies every policy and authored span/object metadata, shares borrowed fonts/keys/payload values and owns a separate buffer/RID/workspace. Clear removes authored content/objects/BIDI contexts and keeps line policies/tabs. Typed descriptors expose live nonstored line settings; the transient layout/delegates are not serialized. Scene/file authoring consumers store their source data/font resources and reconstruct runtime text objects. Existing Label/Font/RichText consumers retain their defaults; backend additions are opt-in. TextParagraph owns an authored full buffer, an independent dropcap buffer and full/display multiline workspaces using the same typed span builder and native backend. Full/dropcap RIDs remain stable; each prepared line has a borrowed generation-bound sub-buffer RID resolved by actual line drawing. Reflow invalidates prior line RIDs. Line ranges are Unicode scalar half-open ranges, including mandatory separators unless trimmed. Count and indexed queries include hidden lines; MaxLinesVisible controls paragraph size/drawing and wrapped final-line overrun. DrawLine uses a line-local origin, without paragraph alignment/dropcap offsets. Paragraph Draw/DrawOutline apply alignment, dropcap flow and line spacing. CustomPunctuation replaces default punctuation classification for justification. Finite signed spacing and margins are retained. Inline rectangles use full geometry and paragraph coordinates; individual line size and width are ceiled while ascent/descent retain fractional metrics.

Correct the observed source coordinate defects when projecting these operations: dropcap flow advances beyond the cap instead of placing text at a negative cap offset; vertical hit testing advances its cross axis, and negative-cross hits return the range start. Full and isolated dropcap draws use the same leading margin origin instead of the source full-draw path ignoring the horizontal leading margin and mixing trailing vertical margins. Keep those fixes explicit in coverage and executable boundary cases. Line-local advance coordinates for HitTest retain the source contract independently of paragraph alignment. Clear also clears dropcap content while retaining policies and margins, matching the distinct ClearDropcap operation that resets margins. Duplicate shares borrowed fonts/tokens/metadata, owns independent buffers and copies every paragraph setting. Prepared metrics, hits and drawing reuse storage; authoring, returned snapshots and reflow may allocate. ADRs 0001/0003/0004/0005/0014/0021/0046/0051/0090 apply; native visual, independent package/NativeAOT, foreign-platform/native-allocation/performance/owner acceptance each require evidence.

Public buffer creation and mutation share the existing retained builder, including copied ordered Font sources and span-level feature selectors. Duplicates retain independent leases on internal source adapters; authored sources and native faces remain borrowed. Authoring queries do not force layout. The low-level width/size contract is ceiled while baseline metrics retain fractions, and draw positions are baseline origins with independently optional leading/trailing advance bounds. Direct buffer direction rejects Inherited; consumer TextLine policies retain their inherited automatic behavior. TextParagraph full/dropcap aliases invalidate the owning paragraph. Prepared line views retain a private line-local override on successful formatting or authoring, retain their scalar origin until Clear, update the real line consumer and retire on the next paragraph reflow. Failed first mutations publish no replacement. Apply a consistent slice-local span index across text/object/metadata getters, explicitly correcting the pinned source's inconsistent parent-span offset access. Keep native font-cache RID authoring, complete run/glyph snapshots and external provider registration/dispatch under their exact remaining coverage dependencies; existing native libraries alone do not implement them.

Ordered source metrics preserve the attempted font prefix through the selected fallback; an unused later source cannot inflate the baseline or underline. Source-specific spacing and feature overrides remain attached to the actual selected native face. Baseline/underline values are captured under the coherent font read scopes, so prepared metadata queries do not reenter virtual font access or read retired faces. Line views retain their surrounding underlying source for global scalar coordinates and BIDI context; typed span indexes are local to the intersecting authored spans. Mutation/clear retains or resets that source context explicitly. Low-level scalar hits interpolate within shaped ligatures; high-level text-object grapheme policies retain their separate contract.

Shaped-buffer editing projects the caret dictionary as the immutable TextCaretInfo result with baseline-relative LeadingRect/TrailingRect and independent directions. Preserve signed per-scalar advance, split BIDI half-height shapes, logical selection ordering, shaping-cluster navigation and separate Unicode composite-character boundaries. Character boundaries merge adjacent equal-language spans and retain span-language cuts; closest-character ties choose the preceding boundary. Glyph hit returns the visual record index and half-open advance containment. Selection and cluster bounds aggregate repeated glyph advances coherently. Correct the pinned vertical RTL after-cluster caret path to advance along the vertical axis rather than shifting its cross axis. Empty/outside queries preserve the source result/sentinel policies, and borrowed paragraph views keep their global scalar origin while geometry remains line-local. Prepared scalar/value queries reuse storage; returned arrays are cold snapshots.

Selection interval adjacency uses an absolute .001 logical-pixel tolerance, including the shared editor helper; advancing the line origin cannot make a real gap disappear. Full-cluster interval edges retain the complete advance without round-trip interpolation.

Retain actual resolved run direction per glyph, including line whitespace resets and virtual justification inheritance. Query geometry and rich callback flags use that retained value independently of later paragraph/context resolution.

Explicit ShapedTextSubstr buffers copy only complete original shaped clusters, including whole inline objects; a cut through a ligature or object retains its scalar source range without inventing replacement glyphs. Reorder the selected clusters in their original full-source BIDI context, reset trailing whitespace to the paragraph direction and reveal a final soft hyphen. Parent discovery returns the original root RID, including the full paragraph parent of an unedited borrowed line. Nested slices address that original root range. Retained shared source-version snapshots and font-adapter leases make owned substrings usable after parent FreeRID/disposal/reflow; the RID remains informational and may be retired. First successful authoring mutation removes that parent relation and reshapes the independent authored slice; invalid/no-op mutations retain it. Fitting, trimming and custom ellipsis configuration preserve the parent and original shaping context. Duplicate owns independent authored content with no parent relation. Clear resets source origin. Sharing one source snapshot across sibling slices avoids copying a complete paragraph for each output line.

Single-width and successive-width line breaking use original logical shaped-cluster advances, native language-specific line opportunities, mandatory separators, word/grapheme/adaptive policies, capped indentation and independent edge trimming. Returned arrays alternate global scalar starts/ends. Nonpositive widths disable width wrapping; advanced once stops at a width cycle or mandatory separator, otherwise columns repeat and mandatory separators reset the column. Both entry points honor the same flags: correct the pinned advanced implementation's missing Adaptive handling and its GraphemeBound restriction after a word opportunity. Preserve CRLF as one separator. Clamp out-of-range start positions instead of returning reversed ranges; empty sliced buffers retain their own scalar origin. Trim policies never produce reversed ranges. Width lists are consumed synchronously during the cold query and bounded to 4096 finite entries. Prepared substring metrics/draw reuse storage; source snapshots, reflow and returned range arrays may allocate.

Edge trimming removes whitespace/separators and permitted soft hyphens, never a visible dictionary character at a virtual break opportunity. Preserve mandatory blank lines as valid empty ranges after complete edge trimming instead of retaining a stray separator or dropping the line.

Cluster-preserving slicing includes virtual justification glyphs and repeat counts inside the selected original range, so prepared Arabic elongation/spacing survives complete substring drawing and measurement.

Explicit shaped-buffer fitting changes retained raw advances, including repeated Arabic elongation and virtual word opportunities, so carets, selection and subsequent wrapping/substrings consume the same geometry. Repeated fitting uses actual font sizes and current repeat counts. AfterLastTab restricts adjustment to the directional suffix; TrimEdgeSpaces zeros edge advances without deleting original records. ConstrainEllipsis operates on the retained visible range and preserves its ellipsis payload. Explicit trimming retains complete raw clusters and independent display geometry; its boundaries are buffer-local visual glyph-record indices, with -1 sentinels. TrimWordOnly preserves the short-result cluster fallback; default ellipsis requires six retained records unless short/forced policy permits otherwise. JustificationAware waits for an unmet fit width. Widths must be finite; undefined bits/categories and invalid Unicode scalars throw. Empty/nonpositive trim resets display.

Extra integer glyph/space/top/bottom spacing belongs to the shared source owner, survives clear/duplicate and invalidates shaping when changed. Nonzero total space spacing overrides glyph spacing at spaces. Paragraph CustomPunctuation and service punctuation use one source value; nonempty punctuation replaces default classification. Custom ellipsis defaults to U+2026 and affects subsequent explicit trims; unsupported scalars use three periods when available. Formatting publishes reusable raw/display workspaces only after coherent font reads succeed; failure/reentry cannot publish partial geometry. Source authoring or font-generation rebuild retires imperative formatting. Fit/trim/ellipsis configuration preserves substring parent relations; changed spacing/punctuation detaches authoring. Borrowed paragraph line formatting updates actual line drawing/display metrics without rewriting full source; reflow retires overrides. Correct inferred RTL and vertical ellipsis-axis handling, per-size/repeated Kashida adjustment and stale borrowed-line display width in the shared implementation.

Borrowed paragraph line ellipsis queries and first overrides retain the paragraph line symbol independently of the full source buffer. Current-value no-op comparisons use that effective line setting, so resetting an inherited custom symbol to U+2026 remains a real mutation. Explicit owned substring construction retains its independent default ellipsis setting.

Stateless TextServer Unicode utilities share the pinned Unicode 17 policy and private ICU process owner, independently of shaped-buffer thread affinity. Reuse the managed full-uppercase transform; execute lowercase/titlecase, NFKD decomposition, character/word iteration and identifier properties through the existing bounded ICU common closure. Standalone strings have the 64 MiB UTF-16 input/output budget, without the shaped-buffer scalar cap. Returned arrays are independent scalar-coordinate snapshots. Positive character-width word queries return scalar-limited line ranges; hard separators are excluded and soft edges trim whitespace. Preserve embedded NUL and malformed UTF-16 in transformations. Correct the pinned source's NUL truncation, dropped penultimate dictionary boundary and single-character hard-line losses rather than carrying them into the public API.

Identifier validity requires NFC, true XID_Start/XID_Continue (with initial underscore), recommended scripts and [Unicode 17 UTS #39 limited join-control contexts](https://www.unicode.org/reports/tr39/tr39-32.html#Limited_Use_of_Joiners). Mixed scripts remain allowed generally; each permitted join-control context must have one script after ignoring Common/Inherited. Use nonspacing marks in virama contexts and require the complete right context for ZWNJ; terminal virama-ZWJ remains valid under the negative dependent-vowel condition. This corrects category approximations and incomplete joiner checks; it does not implement confusable detection. Required Indic syllabic properties must fail explicitly when missing. Keep the seven-language RTL fallback policy, accepting managed hyphen separators. OpenType tags use the actual unsigned 32-bit role; registered aliases and numbered variants resolve through the shared font helper, with canonical reverse names and Latin-1 custom bytes. These are executable text authoring utilities, not new font-cache/provider/security ownership.

Span font replacement preserves text, language, typed metadata, object identity and global scalar origin while copying ordered Font sources/size/features under the existing authoring bounds. Every successful replacement is authoring and detaches an owned substring; invalid input leaves its relation and a borrowed paragraph consumer unchanged. Inline object geometry has no font role, so valid replacement retains its explicit dimensions. Rebuild the current font-dependency set and release unused adapter leases without disposing caller fonts or invalidating shared source snapshots/duplicates. A retired old font can be replaced before preparing the new shape.

Shaped word queries accept the complete typed TextGraphemeFlags family and return logical complete-cluster ranges in global scalar units. Prepare zero-advance native word/Kashida opportunities with retained buffer shaping under its existing coherent read scopes instead of depending on a prior fit call. Querying a virtual opportunity treats it as a source boundary, correcting the pinned overlapping virtual-record character loss when Virtual is not suppressed. No selected delimiters retains the whole shaped range; a partial cluster with no retained glyphs has no word records. Share pinned/custom punctuation, distinct underscores, mandatory/soft separators, resolved direction, native joining and valid inline classification with rich callbacks. CRLF separators are excluded together under mandatory delimiter policy. Keep array allocation cold and native/font retirement, rendered consumers and platform/allocator/package/owner gates distinct.

The standalone hexadecimal replacement helpers reuse TextMissingGlyph and the normal recording CanvasItem role. Their index is a valid Unicode scalar; invalid negative, surrogate and out-of-range values fail before recording instead of displaying a truncated code. Preserve two/four/six digits, rounded minimum-one pixel scale for every signed font-size value, one trailing advance unit and a truncated baseline offset. Zero retains measurement but emits no geometry after ordinary canvas/geometry/color validation. No font source or native text startup is required. Canvas transforms, clipping, modulation and renderer ownership remain unchanged.
