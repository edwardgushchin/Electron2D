# DirAccess enumeration audit

The reference pin is `ed1daf0bf001b61586d9930840f2f1394092c079`. This audit covers 13 rows of the [DirAccess class table](classes/DirAccess.md). The owning decisions are [ADR 0022](../decisions/core-data-io.md#adr-0022) and [ADR 0020](../decisions/core-data-io.md#adr-0020). The class XML has no deprecation marker on the audited declarations.

| Rows | Pinned contract | Electron2D contract |
| --- | --- | --- |
| `ListDirBegin`, `GetNext`, `CurrentIsDir`, `ListDirEnd` | [Bindings and cursor](https://github.com/godotengine/godot/blob/ed1daf0bf001b61586d9930840f2f1394092c079/core/io/dir_access.cpp#L555-L608) expose an unsorted cursor with live filters, bare names, the current kind and empty EOF. The [Windows backend](https://github.com/godotengine/godot/blob/ed1daf0bf001b61586d9930840f2f1394092c079/drivers/windows/dir_access_windows.cpp#L85-L128) closes native search at exhaustion and can retain the last kind. The [Unix backend](https://github.com/godotengine/godot/blob/ed1daf0bf001b61586d9930840f2f1394092c079/drivers/unix/dir_access_unix.cpp#L141-L189) clears it. | `void` plus standard exceptions replaces the begin error code. The managed cursor captures names and kinds at begin and clears its last kind on EOF or closure, independent of backend. Begin replaces the cursor on success and preserves it on failure. |
| `IncludeHidden`, `IncludeNavigational` | Both [default false](https://github.com/godotengine/godot/blob/ed1daf0bf001b61586d9930840f2f1394092c079/core/io/dir_access.h#L54-L57). The Windows backend checks the Hidden attribute. The [pack cursor](https://github.com/godotengine/godot/blob/ed1daf0bf001b61586d9930840f2f1394092c079/core/io/file_access_pack.cpp#L547-L587) yields packed names without hidden attributes or navigation candidates. | Both properties default false. The merged virtual namespace filters dot-prefixed mounted names and provides the same navigation candidates as the physical cursor. |
| `GetFiles`, `GetDirectories`, `GetFilesAt`, `GetDirectoriesAt` | [Class XML](https://github.com/godotengine/godot/blob/ed1daf0bf001b61586d9930840f2f1394092c079/doc/classes/DirAccess.xml#L162-L224) describes filtered and sorted packed string arrays. [Snapshot code](https://github.com/godotengine/godot/blob/ed1daf0bf001b61586d9930840f2f1394092c079/core/io/dir_access.cpp#L536-L568) uses the live cursor and empty-array failure for static calls. | ADR 0022 uses detached, ordinally sorted, immutable `IReadOnlyList<string>` snapshots. The static methods enforce the documented absolute/virtual path requirement and surface standard exceptions. |
| `Open`, `GetCurrentDir`, `ChangeDir` | [Class XML](https://github.com/godotengine/godot/blob/ed1daf0bf001b61586d9930840f2f1394092c079/doc/classes/DirAccess.xml) exposes a nullable factory and a numeric change result. `include_drive` defaults to true and the [Windows backend](https://github.com/godotengine/godot/blob/ed1daf0bf001b61586d9930840f2f1394092c079/drivers/windows/dir_access_windows.cpp#L238-L259) omits the drive prefix on request. | Non-null disposable owner and `void` change with exceptions. Physical paths use native spelling. Windows can omit a drive letter including on extended drive paths. Virtual output retains its captured scope, failed changes preserve state, and successful changes retire the cursor. |

ADR 0022 excludes the thread-local last-open error slot. The non-null factory reports open failures through standard exceptions.

Public Windows x64 regression coverage uses the physical directory listing and resource-pack profiles in `tests/Electron2D.Tests`. They exercise the normal runtime entry points, including PCK and ZIP in the same physical/resource directory, both file/directory collision directions, explicit empty ZIP directories, virtual-root escape, reconfigured project and user roots, snapshots, lifecycle and concurrent cursor advances. The 13 rows describe the audited declaration family. Other directory operations, foreign hosts, NativeAOT and release packages retain their own verification requirements.
