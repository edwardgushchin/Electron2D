# Portable compressed textures

Last updated: 2026-10-18

[PortableCompressedTexture](../classes/PortableCompressedTexture.md) connects runtime image encoding to the existing ordinary Texture canvas, sprite, atlas, style, RID, resource archive and scene-local paths. ADR 0039 owns the portable envelope and approved encoder closure; ADRs 0004/0045 own public naming, ADR 0012 owns texture sampling, and ADR 0095 owns static process-wide retention access.

Creation is a cold operation. It snapshots the source, encodes all mips, decodes/prepares sampling storage, then publishes one replacement and notifies outside the resource lock. The stable logical RID is independent of renderer-owned storage. Native borrowed storage follows the existing texture replacement/session lifetime. Original dimensions and block bytes remain available through GetImage; rendering overrides affect source-region and repeated sampling dimensions without altering source metadata or pixels.

The private EPT1 envelope contains mode, source dimensions/format, complete mip count and length-delimited payloads. PNG/WebP carries individual levels, Basis carries one complete UASTC KTX2 chain, and native block families carry exact complete raw blocks. Parsing validates version, dimensions, family, mip counts, lengths, trailing bytes and decoded shape before publication. Input/source/output and codec work retain the bounded Image profile. No arbitrary reflected type or executable is loaded.

The existing pinned KTX dependency supplies BasisU and scalar astcenc. The private ABI adds e2d_image_encode/e2d_image_encoded_free to the decoder's five exports. Encoding runs in process with one worker per operation; initialization is shared and synchronized with the decoder. Basis numeric transfer metadata preserves supplied channel values. ETC1/ETC2/EAC use BasisU's encoder/transcoder, including R/green channel ordering; ASTC uses 4×4/8×8 LDR/HDR. Image.Compress and CompressFromChannels now execute all five supported families, retaining atomic mutation and complete mips. HDR encoders reject nonfinite input. Basis HDR stores RGB, while ASTC HDR preserves alpha within codec precision.

Retention governs the actual encoded envelope independently of sampled pixels. Global retention affects future creation/load only. Per-resource false discards the current envelope even if the global flag is true; enabling retention later cannot recover it. A populated resource without an envelope cannot be archived. Duplication still copies independent pixels, policy and compressor settings. Typed archives and scene-local graphs reconstruct through the compiled resource factory.

## Verification

PortableTextureTests covers all seven public modes, ragged complete mip chains, a constant-color oracle, HDR, all explicit Image channel roles, all nine HDR source formats (including RGBE9995) through Basis/ASTC/BPTC, 1×1 inputs, encoder/source failure atomicity, retained/discarded/global buffer semantics, typed compressed big-endian archives, fresh-process loading, independent duplicates and scene-local copies. Native rendering profiles exercise ordinary/source-region draws for every mode, capture actual pixels and measure 64 warmed redraw frames. Native Electron2DEncodeCheck covers encoded block sizes, independent ETC decoding, Basis/ASTC LDR/HDR, malformed dimensions/lengths/counts/settings, nonfinite input and concurrent initialization/use. Native package checks require all seven exports on every platform producer; fresh consumers exercise every portable mode without native compilers.

On 2026-10-18 all three PortableTextureTests profiles passed: managed, Linux Wayland GPU on software Vulkan (lavapipe), and Compatibility. Both renderers matched the seven-mode color checks and distinct two-color override/tiling checks; GPU readback matched every complete native or decoded mip payload. Each backend measured 64 warmed redraw frames at zero managed bytes. Empty resources remain nondrawing even with a size override; opaque RGB Basis retains its original alpha flag through copies and archives. ETC1 and DXT5 RA-as-RG precompressed inputs preserve their accepted family and exact bytes. Malformed complete-mip metadata and post-publication observer failures are checked. The 16384×1 PNG fallback and four existing Image BC/block/KTX/imported-texture managed regressions also passed. A fresh Linux platform package passed project, NuGet, default-host and published consumer checks with native compilers blocked. Shared and independent single-archive native checks passed, including ASan/UBSan on the adapter (the reused codec archive was not sanitizer-instrumented). Evidence is retained locally under bin/portable-textures/2026-10-18; generated packages, images and caches are not engine source. Other unchanged native bridges in the package candidate came from existing verified build outputs. Cross-platform runtime execution, hardware performance and native allocation totals require their corresponding hosts and profilers. Compiler success alone does not establish those gates.
