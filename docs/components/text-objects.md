# Retained standalone text objects

Last updated: 2026-10-15

TextLine exposes the complete single-line contract over the existing FreeType/HarfBuzz/TextLayout owner. Text spans borrow Font resources with their own size/language and exact typed metadata; a generic AddString overload and TryGetSpanMetadata make metadata observable. TextObjectKey supplies reference identity in every inline parameter/result position without universal value dispatch.

A line owns separate full and display workspaces. Full geometry supplies caret/object positions; display trimming/ellipsis supplies ceiled width and size. Both use the same shape styles, BIDI contexts, tabs, flags and orientation. Multi-scalar inline objects form one cluster/advance; their two-axis geometry uses global font metrics and explicit signed baseline offsets. Inline-only text uses an owned internal zero-source Font. Missing-glyph and control policies execute independently. Ellipsis selection uses its authored span font/size instead of the neutral owner. Source font generation/read scopes retain coherent borrowed native faces during preparation/drawing.

The creating thread owns access. Active native work rejects mutation/disposal/reentry. A stable borrowed RID points to the owned full/display pair and actual drawing resolves it through a weak internal registry; Dispose unregisters it, and cold registration periodically removes dead owners at intervals scaled to the live table, keeping multi-line reflow from repeatedly scanning every line identity. Canvas drawing follows the same typed CanvasItem recording rules as Font. Advance-axis clipping, alignment, vertical drawing, glyph outline and automatic/explicit raster oversampling reuse the existing kernel. Scalar hits use the proper advance axis and bounded edge coordinates. Prepared queries/draw reuse storage; authoring/settings, independent returned arrays and captures are cold.

Line settings have live nonstored typed descriptors; a transient TextLine is not serialized. Scene/file consumers store source strings/font resources and reconstruct runtime lines through public API. Duplicate copies all source/object/BIDI/tab/policy state and shares only borrowed fonts/keys/payloads. Clear preserves policies/tabs/RID and releases prior content references. TextParagraph shares that authored span builder and owns full/display multiline workspaces plus an independent dropcap buffer. It exposes wrapping, every indexed metric/range/object query, real paragraph/line/dropcap drawing, signed spacing/margins, visibility and custom punctuation. Full/dropcap RIDs remain stable; prepared line RIDs resolve owner/index and retire on reflow. Hidden lines retain queries and independent drawing. An empty paragraph has one zero-sized line. Line ranges include mandatory separators unless trimmed; size/width are ceiled while baseline metrics remain fractional. Inline rectangles use full geometry and paragraph offsets; DrawLine remains line-local. HitTest retains line-local advance and paragraph cross coordinates, including hidden lines, and uses the correct vertical cross axis. Flow is placed beyond the dropcap; full and isolated cap draws share the leading-margin origin. Custom punctuation replaces default justification classification.

Paragraph preparation takes sorted read scopes over the union of source/dropcap fonts. Every borrowed font generation is checked before publication, with a bounded retry after cross-font replacement. The new regression observed an old inline advance of 20 rather than the replacement font's 27 pixels; whole-workspace retry prevents mixed generations. TextLine's shared builder uses the same all-read-current check. Failed font callbacks and owner query/mutation/disposal reentry leave the paragraph usable. The retired combined edge-space flag has been removed from the public enum and mappings under ADR 0004; consumers use the separate start/end flags, and rich/tree/paragraph authoring rejects retired bits.

Managed verification exercises typed values, native shape equivalence, both axes, scalar coordinates, object length/baseline/resize/alignment, full versus trimmed geometry, BIDI/tabs/control/missing, duplicates, owner/lifetime and font-generation invalidation. The extreme-coordinate caret regression was observed before correction; prepared 128-cycle metrics/carets pass zero managed-byte checks. TextLineRenderingTests passes real mixed-font pixels, multi-scalar inline resize, ellipsis/alignment/direction, vertical text, outline/raster oversampling and advance clipping on current Linux GPU/compatibility hosts. Each backend passes 64 warmed full redraw/query frames with zero managed bytes from ProcessFrameStarted through FramePostDraw. Input setup, captures/readback and native allocations are outside that interval.

The independent public-only NuGet/NativeAOT consumer passes with reflection-disabled JSON and zero IL warnings. Separate author/render processes save and freshly load source text/font resources in a compressed big-endian scene, reconstruct the runtime line and verify actual glyphs/metadata/inline/ellipsis drawing on both backends from /tmp with LD_LIBRARY_PATH unset. Transient buffers are deliberately reconstructed rather than serialized.

The complete related Font and RichText groups pass. Two existing scene-copy tests in LabelSettings/Label incorrectly expected non-local fonts to be cloned; the same LabelSettings failure was reproduced with the baseline assembly. Expectations now retain the non-local source, and an additional explicitly local shared-font case verifies one scene copy and disposal. Runtime resource-copy rules remain under ADRs 0013/0023. Foreign platforms, native allocations, large-input performance and human owner acceptance remain separate gates. [ADR 0107](../decisions/text-objects.md#adr-0107) owns the full contract.

TextParagraphTests and TextParagraphRenderingTests cover full typed authoring/query families, CRLF/supplementary ranges, empty/hidden lines, wrapping/visibility/spacing, inline length/resize and full geometry, dropcap/duplicates, BIDI/both axes, generation replacement and failure/reentry. Native gates exercise paragraph, hidden independent lines, isolated cap, outline/raster scale, overflow clipping and live RTL/reflow with an explicit 64 warmed full-frame allocation interval. Package/fresh-process authoring and foreign/native-allocation/performance/owner acceptance remain separately evidenced.
