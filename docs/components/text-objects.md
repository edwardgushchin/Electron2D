# Retained standalone text objects

Last updated: 2026-10-15

TextLine exposes the complete single-line contract over the existing FreeType/HarfBuzz/TextLayout owner. Text spans borrow Font resources with their own size/language and exact typed metadata; a generic AddString overload and TryGetSpanMetadata make metadata observable. TextObjectKey supplies reference identity in every inline parameter/result position without universal value dispatch.

A line owns separate full and display workspaces. Full geometry supplies caret/object positions; display trimming/ellipsis supplies ceiled width and size. Both use the same shape styles, BIDI contexts, tabs, flags and orientation. Multi-scalar inline objects form one cluster/advance; their two-axis geometry uses global font metrics and explicit signed baseline offsets. Inline-only text uses an owned internal zero-source Font. Missing-glyph and control policies execute independently. Ellipsis selection uses its authored span font/size instead of the neutral owner. Source font generation/read scopes retain coherent borrowed native faces during preparation/drawing.

The creating thread owns access. Active native work rejects mutation/disposal/reentry. A stable borrowed RID points to the owned full/display pair and actual drawing resolves it through a weak internal registry; Dispose unregisters it, and cold registration periodically removes dead owners. Canvas drawing follows the same typed CanvasItem recording rules as Font. Advance-axis clipping, alignment, vertical drawing, glyph outline and automatic/explicit raster oversampling reuse the existing kernel. Scalar hits use the proper advance axis and bounded edge coordinates. Prepared queries/draw reuse storage; authoring/settings, independent returned arrays and captures are cold.

Line settings have live nonstored typed descriptors; a transient TextLine is not serialized. Scene/file consumers store source strings/font resources and reconstruct runtime lines through public API. Duplicate copies all source/object/BIDI/tab/policy state and shares only borrowed fonts/keys/payloads. Clear preserves policies/tabs/RID and releases prior content references. TextParagraph remains separately blocked on wrapping/sliced line identities, dropcap and paragraph/line consumers.

Managed verification exercises typed values, native shape equivalence, both axes, scalar coordinates, object length/baseline/resize/alignment, full versus trimmed geometry, BIDI/tabs/control/missing, duplicates, owner/lifetime and font-generation invalidation. The extreme-coordinate caret regression was observed before correction; prepared 128-cycle metrics/carets pass zero managed-byte checks. TextLineRenderingTests passes real mixed-font pixels, multi-scalar inline resize, ellipsis/alignment/direction, vertical text, outline/raster oversampling and advance clipping on current Linux GPU/compatibility hosts. Each backend passes 64 warmed full redraw/query frames with zero managed bytes from ProcessFrameStarted through FramePostDraw. Input setup, captures/readback and native allocations are outside that interval.

The independent public-only NuGet/NativeAOT consumer passes with reflection-disabled JSON and zero IL warnings. Separate author/render processes save and freshly load source text/font resources in a compressed big-endian scene, reconstruct the runtime line and verify actual glyphs/metadata/inline/ellipsis drawing on both backends from /tmp with LD_LIBRARY_PATH unset. Transient buffers are deliberately reconstructed rather than serialized.

The complete related Font and RichText groups pass. Two existing scene-copy tests in LabelSettings/Label incorrectly expected non-local fonts to be cloned; the same LabelSettings failure was reproduced with the baseline assembly. Expectations now retain the non-local source, and an additional explicitly local shared-font case verifies one scene copy and disposal. Runtime resource-copy rules remain under ADRs 0013/0023. Foreign platforms, native allocations, large-input performance and human owner acceptance remain separate gates. [ADR 0107](../decisions/text-objects.md#adr-0107) owns the full contract.
