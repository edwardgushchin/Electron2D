# Graph authoring

Last updated: 2026-10-07

GraphElement, GraphNode, GraphFrame and GraphEdit connect the existing Control/Container, themed fonts, retained canvas, input, embedded popup and typed scene-file backends. GraphConnection projects a directed connection dictionary into an immutable value; GraphSlotMetadata retains exact generic borrowed runtime payloads. GridPatternMode and PanningSchemeMode remain distinct owner-specific domains under ADR 0051. The applicable property names remain GridPattern and PanningScheme.

## Model, layout and ownership

PositionOffset is unscaled graph placement. GraphEdit projects it through Zoom and ScrollOffset; it owns graph stacking while an element is attached and restores the previous ZIndex on removal. GraphElement overlays eligible direct controls. GraphNode arranges visible rows after its owned titlebar; enabled input and output ports have independent compressed indices. Slot configuration may precede rows. Row layout uses themed panel/slot margins, separation and bounded weighted min/max redistribution. Hidden rows do not expose ports. GraphNode default focus and slot focus are Accessibility; All provides ordinary keyboard row navigation and wiring.

Textures and metadata remain borrowed. Exact payload type, including typed null, is preserved by GraphSlotMetadata.TryGet. Negative port types still render but do not start interactive wiring. Type bypass applies to the hovered target node; programmatic ConnectNode remains independent of interactive type policy. Slot icons are watched for changes/disposal; replaced and cleared references detach their subscriptions. Titlebars/title labels, graph menu and graph drawing layers cannot be disposed independently. Scene disposal retires subscriptions and owned children. Source callback hooks can customize port drawing, connection geometry and hotzones/hover validation. Own graph state cannot mutate or dispose during active drawing; canvas command recording remains valid.

Graph connections contain from/to names, compressed port indices and KeepAlive. Interactive wiring emits requests; an application explicitly calls ConnectNode/DisconnectNode or assigns Connections. ConnectNode is idempotent and uses typed exceptions instead of an Error integer. Activity blends toward the theme activity color and remains runtime state. Missing endpoint/port records are omitted from geometry; ordinary records are pruned during attached rendering, while KeepAlive records remain. Connection snapshots and geometry queries allocate explicit caller-owned results. The default line is a sampled cubic; the custom virtual geometry hook may return arbitrary finite polylines.

Frame attachments are logical and do not reparent scene nodes. Cycles and self-attachment reject. Automatic bounds include descendants, padding and titlebar height; manual frames expand to contain attachments without shrinking their existing rectangle. Moving a frame, including nested frames, moves attached elements once. Detaching/removing an element updates the logical relation. Name changes remap stored connection and attachment identities, including detached nodes on their next graph query.

## Interaction and storage

Pointer input supports typed wiring/empty release/disconnect requests, selection, box selection, snapped movement, request-driven resizing, wheel zoom/pan, middle/Space panning, popup requests, minimap navigation and menu controls. Port hits respect clickable child controls. ResizeRequest asks the owner to assign Size; the resize cursor and ResizeEnd report the actual result. Keyboard All focus navigates rows and starts/ends port wiring, follows existing links and focuses row controls. Graph commands consume remappable ui_graph_duplicate/delete/follow_left/follow_right and shared copy/cut/paste/cancel actions. Follow defaults use Alt on macOS and CommandOrControl elsewhere, retaining the existing feature override protocol.

Deletion and frame-link name events expose ReadOnlyMemory<string> borrowed only for callback duration. They reuse capacity prepared when graph elements are added; callers copy explicitly if retaining names. Deletion preserves the original names across immediate application removal of selected children. Arrangement is an explicit cold authoring operation: stable name order and bounded directed layers position selected nodes, or all nodes when none are selected; cycles settle into bounded layers.

ScalingMenus projects descendant PopupMenu content through its viewport CanvasTransform. Physical bounds, shadows, submenus and routed pointer coordinates use the same scale. Ordinary popup menus retain scale one. The retained ProjectSettings service is created after all static typed definitions, avoiding dependence on partial-file field initialization order.

Registered factories cover all four controls. Slot count precedes indexed stored slot descriptors on fresh nodes. GraphConnection arrays and typed integer-to-name maps have bounded archive codecs. Stored source/configuration and scene-owned row controls are distinct from runtime selection gestures, metadata, activity, transient attachment relationships and drawing caches. User controls intended for PackedScene must have the appropriate Owner, following the existing scene contract.

## Verification and limits

GraphTests exercises compressed ports, exact metadata, idempotent/copy-isolated connections, logical nested attachment/cycle rejection, frame movement, rename/detach, selection eligibility, finite/index validation, owned disposal, routed pointer wiring/empty release, Bézier/rectangle hit queries, snapped and keyboard movement, directed arrangement, request-driven resize/cursor, immediate deletion callbacks, remapped graph commands, keyboard port wiring and scaled popup hit coordinates. Registered configuration and typed codecs execute in PackedScene, files and a fresh process with real row layout.

Native current Linux Wayland GPU and compatibility hosts assert colored ports and gradient connection pixels and render graph nodes, a tinted frame, grid, toolbar and minimap. Prepared allocation checks warm for 64 frames and measure 64 owner-thread movement/activity/selection/render intervals. A separate prepared SDL click/motion producer drives an active connection preview: 64 actual graph-handler samples and 64 render intervals measure zero managed bytes on each tested backend. This measurement does not include the complete native input/frame phase. That broader phase measures 145408 managed bytes over 64 intervals on both tested backends; native InputEvent construction and transformed GUI event ownership remain the existing ADR 0038/0014 dependency, rather than a zero-allocation native-producer claim. Visually inspected captures `/tmp/e2d-graph-gpu-final.png` and `/tmp/e2d-graph-compat-final.png` have matching SHA-256 `f06417cf1938a0a481f6bea56d9b7a4a908e82286aecf6e96137289b11fbb464`. These remain unpublished local verification artifacts. Cold connection/node/slot authoring, zoom-label text rebuilding, archive snapshots/loading, native/external allocations, physical devices, native independent popup windows, foreign platforms and user acceptance remain separate.

Slot storage is bounded to 65536 configured indices. Grid drawing reduces excessive pixel density and bounds each axis to 2048 displayed subdivisions. Default connection geometry uses 65 prepared points; virtual caller geometry is validated. Weighted row redistribution and explicit cold arrangement use simple scans; indexed solvers are the upgrade if large-graph profiling requires them.

Native event construction and transformed-event dispatch require a complete scoped borrowed-event lifetime/preparation layer before the shared native input pipeline can satisfy ADR 0014. Existing source events currently construct/dispose their resource objects in DisplayServer; graph handlers and retained drawing do not own that layer. The default Accessibility focus policy and semantic port/type/action nodes remain dependent on the Control accessibility-session gate and AccessibilityServer graph providers. Concrete editor graph-resource authoring requires ADR 0090 operations; providing runtime graph controls does not implement that editor workflow. Current native/profile evidence does not imply foreign or physical acceptance.
