## Public contract

Input adds HasJoyMotionSensors, GetJoyMotionSensorsRate, IsJoyMotionSensorsEnabled, SetJoyMotionSensorsEnabled, GetJoyAccelerometer, GetJoyGravity, GetJoyGyroscope, StartJoyMotionSensorsCalibration, StopJoyMotionSensorsCalibration, ClearJoyMotionSensorsCalibration, GetJoyMotionSensorsCalibration, SetJoyMotionSensorsCalibration, IsJoyMotionSensorsCalibrated and IsJoyMotionSensorsCalibrating. These remain static service operations under ADR 0095.

Vector3 carries three numeric sensor channels under ADR 0033. Acceleration includes gravity in metres per second squared. Held in front of the player, positive acceleration axes point left, down and away; the SDL adapter negates its acceleration channels. Gyroscope channels are pitch, yaw and roll in radians per second. The estimated gravity direction has standard magnitude 9.80665 metres per second squared when a direction has been observed. A gyroscope-only controller supplies angular rates without fabricated acceleration or gravity; an accelerometer-only controller supplies its actual acceleration. HasJoyMotionSensors means at least one available channel. Rate is the native advertised accelerometer frequency, falling back to the gyroscope frequency when that is the only available channel; unknown frequency is zero. It remains observable while disabled.

JoyMotionCalibration is an immutable typed gyroscope-offset record. GetJoyMotionSensorsCalibration returns null for an absent or not-yet-calibrated controller, otherwise an independent value in radians per second. Default data means zero bias. Set rejects non-finite or unrepresentably large bias before changing state; data can be restored while sensors are disabled. The resource and scene storage APIs are not changed by this value record.

## Sampling, calibration and ownership

Available sensors start disabled. The display owner enables actual SDL channels before publishing enabled state. A failure preserves the published state and attempts to restore an already changed first channel; rollback failure is reported with the original error. Equal requests still reach the backend and retain the preceding sample clock when the enabled state is unchanged. Cleanup disables available channels before closing their native handle.

After each native event pump the adapter samples each enabled mapped controller once, using the current paired SDL values. Raw sensor events do not create a new public input-event type. Ordinary Engine/SceneTree callbacks query the completed snapshots. Sampling and reading use prepared value fields and the Input lock; reads can run on other threads, while mutation requires the live display owner. Negative IDs throw. Unsupported or disconnected IDs return absent/zero values and mutations do not construct a display or native device.

A regression measures the actual interval between two native gravity samples, repeats an already-enabled request, and requires the expected integrated rotation within the observed call-time bounds. It reproduced lost angular time before the timestamp repair.

Manual calibration starts only with enabled sensors and no active calibration. Start clears prior bias and marks completion false. Stop requires enabled sensors and an active calibration, retaining the stationary sample mean and marking completion true, including a zero-sample interval. Clear resets accumulated samples while retaining both flags, so it can restart collection inside an active interval; clearing completed calibration retains a completed zero-bias record. Set rejects active calibration. Calibration changes affect angular readings on the next sample. While collection is active, its running bias mean is already applied to angular snapshots, while the completed calibration record remains absent. Double-precision accumulators retain the sample mean without a bounded integer sample counter.

Gravity filtering follows the manual-mode gravity path of GamepadMotionHelpers v9. It rotates retained gravity/smoothed acceleration by calibrated angular velocity, bounds acceleration correction by measured shakiness and angular speed, and returns the normalized gravity estimate. Automatic stillness calibration, orientation objects and a second scene domain are not exposed. The adaptation retains its [MIT notice](../../licence/GamepadMotionHelpers-LICENSE.txt). All-zero packets retain the preceding sample; invalid native numeric packets are discarded before they can poison state.

Disabled and focus-suppressed readings return zero. Focus suppression also prevents calibration sample collection and prevents ignored time from becoming a later rotation interval. The display's drop-input pump suppresses its sample; the next ordinary pump resumes delivery. Mapping replacement, disconnection and display retirement remove the prior motion/calibration state before ID reuse. Native channel-specific read or enable failures are explicit errors; physical driver loss and rollback behavior require target-device checks.
