## Runtime and invariants

Adding a surface copies typed vertex/color/primary-UV/secondary-UV/index arrays and validates topology, counts, finite values and indices before commit. Colors use the pinned RGBA8 UNORM clamp/truncate boundary; positions use float pairs; UVs use float pairs unless CompressAttributes is selected. Indexed and nonindexed points, independent lines, line strip, triangles and triangle strip append actual framebuffer geometry on both native backends. Points/lines stay one pixel wide after transforms by default; [canvas point programs](canvas-points.md) can author the native GPU point diameter. ArrayMesh records borrow live storage, while custom Mesh callback snapshots refresh on Changed; current per-surface materials and node material fallback are resolved for actual submission. Shader materials retain the existing GPU/fallback capability gates.

MeshSurfaceData is the typed replacement of the existing array-of-arrays concept: Vertices, Normals, Tangents, Colors, UVs, UV2s, Indices, Bones and Weights. No generic Get/Set/Call is exposed. Region updates retain the pinned exercised channel byte layout and accept partial records with two-pass finite validation before writing. Metadata/name/material/copy/free operations retain explicit ownership and error rules. Render replay and updates use prepared storage; loading, structural edits, duplicate/query copies and property discovery are cold operations. Structural growth is not claimed allocation-free.

RenderingMeshRegistry owns logical RID lookup only: resource entries remain weak/borrowed; renderer-created ArrayMesh entries stay owned until FreeRID or shutdown. Mesh disposal invalidates its resource RID. Renderer teardown attempts owned mesh cleanup separately from owned texture and backend cleanup. MeshInstance does not dispose its borrowed resources. Retained ArrayMesh geometry remains live after a Changed listener failure even if a later node redraw listener was not reached.

ImmediateMesh adds invisible begin/append/end drafts, finite attribute/vertex validation, first-use attribute backfill, incomplete-primitive retry and clear/cancel. It owns private ArrayMesh storage, so committed data, material edits and clear are visible to already recorded commands without allocating new custom callback snapshots. Draft growth and structural commit/copy remain cold operations; repeated playback and prepared material/pose changes are hot. Duplication copies only completed surfaces and preserves borrowed/deep/local resource ownership. Clear and material edits emit Changed after commit under the shared resource invalidation contract.

## Compressed attributes

[MeshCompression](../classes/MeshCompression.md) owns canonical four-byte UV/UV2 UNORM16 pairs and six-byte normal/tangent frames plus shared Vector4 UV scale. Color/custom/skin/index layouts retain their ordinary contracts; compressed attribute records order color (four), UV (four), UV2 (four), then selected custom records. Normal-only input synthesizes a tangent and tangent-only compression rejects. Nonorthogonal/zero input projects to a numerical frame and is not magnitude preserving. Encoding divides by that scale and adds 0.5; decoding subtracts 0.5 and multiplies. Canonical bytes, including partial frame/UV patches, survive duplication, AMS8, fresh scenes and morph source refresh. Older AMS1–7 remain readable; archive preflight includes scale/count/format validation.
