# Authored navigation maps and regions

Last updated: 2026-10-10

The initial NavigationServer backend consumes authored convex polygon geometry and publishes immutable planar map iterations. Maps/regions are real RID owners; NavigationRegion : Entity and World.NavigationMap use the same storage. Gameplay can query a route around missing walkable areas and follow it using existing scene/physics APIs. No renderer-specific navigation mesh or native backend identity enters public APIs.

## Publication and ownership

NavigationServer is a permanent retained ElectronObject with static operations and Engine named-service lookup. User-created MapCreate/RegionCreate/LinkCreate identities require FreeRID; map deletion detaches staged region memberships. World lazily creates an active borrowed map whose lifetime matches its canvas/physics runtime. Scene region RIDs are stable before attachment and remain until node disposal; exit removes map membership. FreeRID rejects world maps and scene region ownership.

Configuration/geometry edits stage under the service gate. Getters for those properties report staged values, while path/projection/bounds read the latest committed iteration. Synchronize first builds every dirty region/map; a failed build preserves all previous iterations for retry. It then publishes dirty snapshots, increments nonzero iteration IDs and then delivers MapChanged outside the gate. The scene physics lane calls the same synchronization before user callbacks. Edits during callbacks affect later publications; recursive synchronization rejects. Callback failures aggregate after committed iterations. A batch host uses Synchronize directly; deprecated force-update APIs are excluded.

Geometry arrays are copied and published as immutable resource versions. Scene nodes and server regions borrow a NavigationPolygon and observe Changed/disposal; editing the resource stages a new version, while published paths remain stable until sync. Empty/disabled/inactive topology produces empty paths and zero/empty projection identities. Layer-zero queries traverse no geometry. Source scene properties and server configuration remain separate; source setters republish their matching setting, and world/transform changes stage current map/geometry placement.

## Geometry and routes

NavigationPolygon supplies finite local vertices and consistently wound convex polygon index arrays. At least three distinct indices and nonzero area are required. Public getters return copies; replacement validates retained polygons before commit. Resource copies share immutable versions safely. Polygon replacement and edits deliver NavigationPolygonChanged after geometry staging. Detached/disabled region bounds and projections retain their own committed geometry independently of active map membership. The typed archive stores a bounded versioned byte payload; load validates all lengths, geometry and trailing data before publication. NavigationPolygon/NavigationRegion factories are registered for fresh-process loading. Region settings and borrowed resource graphs are stored; server RIDs/iterations are live runtime identity.

Two stages group raster keys: first inside each region, then across external region edges. Keys floor world coordinates by CellSize × MergeRasterizerCellScale. CellSize starts one and finite assignments clamp to at least 0.0001; scale starts 0.1 and clamps to 0.0001–0.1. Getters report staged settings; changing either rebuilds attached region versions and the map on synchronization. Default effective dimensions are initialized immediately, correcting the pinned stale constructor dimensions. Ordinary float raster arithmetic matches; wider keys retain finite large coordinates without int32 conversion aliasing.

Each raster key retains its first two owners in committed region/polygon/edge order. Paired intra-region edges form internal portals; paired external edges connect regions independently of optional margin flags. Additional owners are ignored. Unpaired edges enter the margin pass only when their map and region flags allow it. The pass publishes directed overlap pathways and complete counts. RegionGetConnectionsCount/PathwayStart/PathwayEnd enumerate only these margin pathways; shared raster pairs and synthetic links are excluded. Staged reparenting/geometry/settings leave these arrays intact until the complete replacement is committed. Detached or destroyed maps have no pathways; invalid indices throw. Raw EdgeCentered paths use the entered polygon's physical edge midpoint, while funnel routing uses the actual published pathway.

ProcessInfo exposes ten integer counters from the last successful synchronization: active maps and their region/agent/link/obstacle memberships; authored polygon counts, distinct regional edge keys, internal pairs, interregion raster pairs plus directed margin connections, and eligible free edges before margin matching. Disabled regions retain authored topology/counts but path traversal and sampling exclude them. Membership-only edits refresh counters without forcing a map version or event. Builds and counter checks precede publication, so failures preserve old geometry, pathways, versions and metrics. Region IDs wrap through the nonzero 32-bit range and are returned as ulong. MapChanged callbacks observe committed values. Attached resource edits from another thread stage geometry under the service gate and deliver NavigationPolygonChanged through the scene owner queue.

MapGetRandomPoint and RegionGetRandomPoint consume committed nonempty enabled surfaces and navigation-layer masks. Uniform mode weights regions, polygons and triangles by area; nonuniform mode chooses each level uniformly. Both sample inside a triangle using prepared surface groups and double area/interpolation arithmetic. Detached regions remain sampleable; no eligible surface returns zero. Filtered region indexing corrects the pinned unfiltered-index/layer defect. Random streams are not guaranteed identical across runtimes. Topology construction and copied queries allocate; warmed unchanged synchronization, counters, pathways and prepared sampling reuse storage.

The remaining query profile is explicit: broad weighted search/cost/tie/budget/fallback equivalence and overlapping projection ownership beyond fixed oracle corridors remain Partial. Margin matching still compares eligible free edges quadratically; large-map performance and native allocator totals are unverified. Source parsing, outline/clearance baking, async workers, debug/editor producers and global simulation activation retain exact separate coverage triggers. Deprecated outline generation, force-update and region-RID aliases remain excluded.

[NavigationTopologyTests](../../tests/Electron2D.Tests/NavigationTopologyTests.cs) compares twelve independently executed official pinned-runtime fixtures for raster/negative keys, first-two ownership, internal merges, margin eligibility, disabled/layer/inactive states, raw/funnel routes, pathways and all counters. Additional checks cover transactional failures, region versions, membership refresh, area/nonuniform statistics, filtered/disabled/detached/extreme sampling, worker resource delivery and warmed allocations. [Rendered topology checks](../../tests/Electron2D.Tests/NavigationTopologyRenderingTests.cs) move a real actor across a quantized gap with margin connections disabled, verify scene-lane metrics and goal pixels, and clean up the borrowed map on GPU/compatibility. Oracle generation is [a development-only script](../../tools/navigation/topology_reference.gd); source geometry archives and fresh-process navigation checks remain the existing NavigationTests contract.

## Links across separated surfaces

NavigationLink : Entity and caller-owned server link RIDs connect nearest enabled convex polygon surfaces through the same map iteration. Default connection radius is four world units. Each endpoint independently chooses the nearest polygon strictly inside that radius, in existing region/cell order; exact boundary distance and radius zero do not attach. Layer filtering applies afterward to both attached regions and the link. Links do not become walkable surfaces, closest-point owners or region bounds.

Synthetic link cells carry enablement, direction, layers and entry/travel costs. Forward portals connect the projected start and end; bidirectional links also permit reverse travel. The same corridor search and raw/funnel output execute across them. Collinear optimized paths now preserve link entry/exit portal markers; raw paths retain search entry points or edge centers. A route supplies geometric travel; game code decides jump/teleport/other actions, and typed per-point metadata identifies transition primitives and their owners.

Source endpoints are local. Detached global getter/setter methods preserve that local role; attachment and Entity transforms publish finite world endpoints. Source properties cache independently of direct server edits. World replacement preserves the node RID and transfers membership; empty overrides restore the current World map. Configuration warnings use the existing Node tooling API for coincident endpoints. Typed source properties and factories load in a fresh process; live RID/map overrides are not serialized.

A link counter remains zero before attached synchronization, increments for changed link settings after successful map publication and wraps from uint.MaxValue to one. Map-only radius/topology rebuilds do not increment unchanged link counters. Failed map builds preserve every prior link version and map snapshot. Scene links are held weakly and swept at the same boundary; node/world disposal or caller FreeRID supplies normal deterministic cleanup. Two thousand warmed idle identity/unchanged setting/synchronization cycles and two thousand changing scene endpoint staging/global lookup cycles allocate no managed bytes; the latter excludes topology builds. changed topology and returned paths allocate by their explicit profile.

## Typed query objects and transition metadata

NavigationPathQueryParameters/Result are reusable caller-owned ElectronObject types with complete typed property discovery. Algorithm/PostProcessing avoid nested enum/property name collisions; PathMetadataFlags and PathSegmentType retain numeric identities. Settings snapshot scalar data and copied filter versions under one gate. QueryPath captures one committed map and publishes all result arrays/length before the optional zero-argument calling-thread Action callback. Invalid required identities/disposed objects preserve the old result; callback exceptions occur after publication. Callback changes and nested queries are permitted after this boundary.

Region include/exclude filters affect start/goal projection and corridor expansion; exclusion wins and both link endpoint regions must be included. A-star searches respect positive polygon-count and projected-start-to-entry distance limits, returning a closest processed region when constrained. Nonpositive search counts disable that limit. Finite float limits and simplification epsilon clamp negative input to zero. CorridorFunnel preserves corners/crossed-edge provenance and link markers; EdgeCentered uses portal midpoints, None uses search entries. Optional iterative RDP selects the same indices across all arrays; it may deliberately remove transition points, so game transition consumers should leave simplification disabled.

Metadata flags select parallel PathTypes, PathRIDs and PathOwnerIDs arrays, or empty arrays when disabled. Link entry points carry Link type, link RID and its logical owner; the following point reaches its destination region. Cells snapshot logical owner IDs, so later owner edits require synchronization. Result arrays are copied both ways and independently assignable by callers; query publication remains complete. Separate getter calls may observe different complete versions under concurrent result writes, so consumers coordinate multi-property reads. Reset clears all arrays and length, correcting a stale-length source implementation defect. Include-only link filtering checks the two included endpoint regions, correcting the pinned erroneous excluded-end check. Collinear link markers also remain explicit so games can execute transitions.

Length and circle-radius clips interpolate the first exceeded segment and trim metadata in parallel while retaining the original endpoint provenance. PathLength is computed after optional simplification and clipping; as a float statistic it may overflow to infinity for a route beyond the single-precision length range, while positions remain validated finite. Standalone SimplifyPath returns copied points, supports empty/singleton input and uses an explicit stack to avoid recursive depth failure. Queries, returned array copies and topology builds allocate by this profile; two thousand changing scalar setting/result-reset cycles allocate zero managed bytes after warmup.

NavigationQueryTests exercises masks/filter precedence, all flags/modes, budgets, clipping, RDP boundary and a 4000-point depth case, arrays/reset/lifetime and callback failure/nesting. Its hardware host reads link and instance metadata to teleport exactly once across a gap and reach real goal pixels. This distinguishes a rendered metadata consumer from authoring/headless checks. Exact quantized raster/nonmanifold/search cost/tie/fallback equivalence remains Partial on QueryPath and map query rows; parameters have no inert settings.

## Agent path following

NavigationAgent : Node follows its direct attached Entity parent through the shared query kernel. It owns a borrowed stable server RID and retained query result; server AgentCreate/SetMap/GetMap/IsMapChanged and MapGetAgents supply real map membership, consuming committed version observations and teardown. The same identities now participate in the shared ORCA avoidance kernel. World replacement rebinds nonspatial agents alongside canvas items, including nested viewport boundaries; exit detaches and reentry keeps the node RID.

Submitting TargetPosition, including the same value again, resets the request. Advancing getters query/advance an active request; the caller moves its parent, normally once per physics tick after GetNextPathPosition. Layer/map changes repath active requests; all other query settings apply to the next query. Finite signed thresholds retain the pinned semantics: strict waypoint/target distances, inclusive target reachability and off-segment reload. Empty paths remain unfinished. Final-waypoint completion for an unreachable target emits only NavigationFinished. Double intermediates keep finite large-coordinate distance/segment comparisons valid.

NavigationWaypoint replaces a dictionary with nullable Type/RID/OwnerID/live scene Owner and directional link endpoints. Metadata absence stays explicit; arbitrary custom IDs resolve null owners. WaypointReached precedes LinkReached, and TargetReached precedes NavigationFinished. Consumers may move the parent to a link's exit. Agent mutation/disposal and recursive updating getters reject during delivery; every subscriber is attempted and failures aggregate after progression. Lifecycle or World rebinding during delivery aborts stale progression and invalidates after the outer update. Public result arrays are copied; replacing the borrowed result's path triggers a fresh query and mismatched metadata is safe. Consumer result disposal rejects while the agent is alive.

Typed descriptors now store twenty-five source settings, including the target; indexes, maps, results and RIDs remain runtime-only. NavigationAgentTests checks fresh-process PackedScene loading, strict/inclusive thresholds, unreachable/empty paths, off-path/map-version reload, callback ordering/failure/reentry, copied/edited results, map/World lifetime, forward/reverse link endpoints and two thousand warmed following/length reads with zero managed bytes. Queries, event failure lists, public copies and cold owner scans/topology remain separate allocation boundaries.

The native agent host selected with ELECTRON2D_TEST_NAVIGATION_AGENT_HOST=1 uses GetNextPathPosition and LinkReached to teleport across a real gap, then verifies target/navigation completion, goal pixels and teardown. Both local hardware hosts reached target pixels after exactly one link transition in fifteen GPU frames and fourteen compatibility frames in the final runs; their PNG captures have identical SHA-256 `77fa4bd3a7bf1eea37bd065ba67af102bd7849f0b200f9c6097503a9f0e9a433`. GPU and hardware compatibility results establish only the tested local Linux backends. The following avoidance slice supplies the shared agent/obstacle ORCA kernel and velocity dispatch; debug still needs the canvas producer and retained default server draw settings. The remaining own coverage rows name these exact prerequisites.

## Reciprocal agent and obstacle avoidance

NavigationServer agent/obstacle state now drives an internal managed RVO2 ORCA adaptation, licensed under Apache-2.0 and compiled into Electron2D.dll. Existing public math/enum/identity types are reused; no second native or managed runtime assembly is introduced. Desired and forced simulation velocity remain distinct. Radius, speed, neighbor count/distance, horizons, mask/layers, priorities and pause have actual solver consumers. Agents select distance-sorted neighbors with stable RID ties and ignore lower priorities when their own priority is higher. The initial scan is quadratic; reusable lists and line-program buffers avoid warmed allocation. Spatial indexing remains a measured scaling follow-up.

Moving disc obstacles consume Radius and Velocity; their contours consume static oriented half-plane/convex-leg constraints, independent of Velocity. Two vertices create a two-sided wall; larger simple convex/concave contours preserve winding. Local source vertices are copied, validated for finite values/duplicates/area/intersections and transformed by the node basis, with translation stored separately. Radius uses the largest absolute global scale axis clamped to .001. Geometry updates publish complete obstacle state; unchanged transforms reuse the version. Changed contours are a cold allocation/rebuild boundary. Empty-contour moving disc updates avoid temporary arrays.

SceneTree's positive physics boundary prepares scene sources, solves every selected participant from one pre-step state, publishes all outputs, dispatches callbacks and then runs physics calculations. Topology publication/observer errors are collected independently, so they do not skip the avoidance lane. Static Step(double) synchronizes and executes unbound caller maps with the same kernel; bound World/caller-override maps have one scene owner and foreign tree assignment rejects before mutation. Pause notifications immediately mark agents paused and detach scene obstacle runtime membership; resume restores the previous map while source World/override selection remains separate. Paused parents/obstacles leave simulation. Node Velocity submissions and forced resets are applied to an active submitted target on the next boundary; path completion resets desired/current velocity. Source node properties stay independent of direct server edits.

VelocityComputed and typed Action callbacks run on the stepping thread after publication. Handlers may move parents and stage the next step; recursive Step/Synchronize reject. Failures aggregate after all deliveries, and later callback recipients are checked for free/disable/map reassignment. Weak scene callback indirection avoids retaining enabled detached nodes. Node disposal during its velocity event rejects. Nonfinite/negative radius, speed, horizons/distance and out-of-range priority reject; nonpositive max-neighbor counts disable agent neighbors. Float-representable step durations reject underflow/overflow. Zero duration only synchronizes. Zero horizons use one step for reciprocal predictions, and coincident stationary discs get opposing deterministic normals rather than NaN. Double intermediates and output clamping keep publication finite.

NavigationAvoidanceTests checks analytic head-on/wall constraints, directed masks/priorities, neighbor boundaries, moving discs, pause/speed/coincident/zero/numeric inputs, simultaneous callback publication/failure/reentry/free recipients, World ownership/transforms, weak lifetime and fresh-process scene archives. The optional independent oracle is built with python3 -B tools/navigation/build_oracle.py and selected by ELECTRON2D_AVOIDANCE_ORACLE; 144 velocities across 24 pair/wall/convex/concave scenarios matched the pinned C++ solver within .002 world units/second. Stable precision/tie adaptations and zero/coincident fixes are distinguished from literal spatial-tree ordering.

A real disc obstacle bends their paths; both reach pixel-verified goals and cleanup. Final runs after the pause-notification checks used 113 frames on each backend with the same minimum distances. This proves the tested local Linux hosts; large crowds, foreign hardware and human acceptance remain separate. ## Public use

```csharp
var map = NavigationServer.MapCreate();
var region = NavigationServer.RegionCreate();
using var polygon = new NavigationPolygon();
polygon.SetVertices([new(0, 0), new(64, 0), new(64, 64), new(0, 64)]);
polygon.AddPolygon([0, 1, 2, 3]);
NavigationServer.MapSetActive(map, true);
NavigationServer.RegionSetMap(region, map);
NavigationServer.RegionSetNavigationPolygon(region, polygon);
NavigationServer.Synchronize();
Vector2[] path = NavigationServer.MapGetPath(map, new(4, 4), new(60, 60), true);
NavigationServer.FreeRID(region);
NavigationServer.FreeRID(map);
```
