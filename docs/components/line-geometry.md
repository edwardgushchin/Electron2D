# Line geometry

Last updated: 2026-10-25

[Line](../classes/Line.md) is the editable thick-polyline consumer of retained canvas triangles. Its complete fourteen-property family executes through existing GPU and compatibility backends, inherited transforms, materials, atlas mapping, redraw, resource lifetime and typed scene storage. No new public declaration or backend handle is introduced.

## Strip and attributes

The retained indexed builder omits consecutive duplicate positions and a repeated closing point without changing authored Points. Fewer than two effective points or zero base Width emit nothing. Closed requires at least three effective points and ignores endpoint caps. Finite-segment intersections select sharp miters, bevel fallback or round joints. SharpLimit measures the miter in half-widths. RoundPrecision fixes an angular step of PI/precision and retains the final shorter step; zero-radius arcs emit nothing. Zero-area triangles are omitted and triangle winding is normalized without changing interpolated attributes or overlapping layer order.

WidthCurve multiplies local base width. Gradient replaces DefaultColor. Interior samples use travelled distance including open cap extensions and the closed return segment; endpoint colors use the first/last gradient stops. None supplies zero UVs. Stretch uses travelled/total distance; Tile uses distance/(base width times texture aspect), requiring inherited repeat sampling for actual repetition. Rounded caps preserve both UV components. Closed lines construct the first joint first; varying width need not be seamless at closure. A zero initial width has a finite closure fallback. Nonfinite authored data, curve results, generated attributes or transformed output reject through the existing recording boundary.

The algorithm is adapted from the pinned comparison builder under the MIT notice in [LineBuilder-LICENSE.txt](../../licence/LineBuilder-LICENSE.txt). [Line.Geometry.cs](../../src/Scene/2D/Line.Geometry.cs) retains unique source vertices and indices; [CanvasItem.Polygons.cs](../../src/Scene/Main/CanvasItem.Polygons.cs) validates and copies them before publishing a pooled command. Original vertex IDs survive expanded native triangles and coverage copies. Resource callbacks retain the texture selected for the current build; disposed resources/canvas still fail the recorder's lifetime checks.

## Boundary coverage

Antialiased uses the shared [CanvasPolygon](../classes/CanvasPolygon.md) boundary path after skin/transform/snapping and before authored vertex programs. One framebuffer pixel of outward alpha coverage surrounds sides, caps and joints. Equal local positions share edge cancellation and accumulated normals, while original endpoint color, UV and source vertex IDs remain distinct. Shared strip diagonals, cap diameters and closed seams receive no fringe. Miter reach is bounded to four pixels. PremultAlpha fades RGB with alpha; Mul rejects because it ignores coverage alpha. Custom fragments must preserve coverage alpha and authored vertex displacement may change fringe width. Self-overlapping strips preserve normal triangle blending; there is no shape-union operation.

This follows ADR 0028's meaningful backend adaptation policy: the pinned Line scene producer does not consume its stored antialias flag. Electron2D executes that setting through its existing coverage machinery. SDL's software triangle driver retains the existing fractional-coordinate rasterization gap; a saved software-driver test gives 0.25098 instead of the analytical 0.125 edge sample. The OpenGL compatibility and software Vulkan profiles pass that same assertion. This limits raster equivalence, not public property execution.

## Verification and boundaries

[LineTests](../../tests/Electron2D.Tests/LineTests.cs) and [LineGeometryTests](../../tests/Electron2D.Tests/LineGeometryTests.cs) exercise defaults, edits, resource invalidation/lifetime, caps, UVs, width-zero closure, attribute identity and scene state. The [independent oracle](../../tools/line/check_reference.py) compiles unchanged C++ builder sources from `ed1daf0bf001b61586d9930840f2f1394092c079`, verifies their SHA-256 hashes and compares actual triangle coverage plus ordered UV/RGBA samples. Minimal adapters supply containers and the same analytical curve/gradient fixtures; the segment intersection function is extracted unchanged from that pin. This verifies sampled geometry/attributes, not identical vertex ordering or every floating-point input.

The 3888 combinations cover six paths, three joint modes, both independent three-mode caps, three UV modes, open/closed, uniform/variable width and uniform/gradient color, with precision1/3/8 and miter limits1/2. There are 329340 compared samples, 208779 covered samples, at least14 covered samples per case, maximum attribute difference0.000035858 and no mismatches at tolerance0.001. The 6462 shared-edge ambiguous samples are excluded explicitly. Zero-width/duplicate cases have separate managed checks.

[LineGeometryRenderingTests](../../tests/Electron2D.Tests/LineGeometryRenderingTests.cs) checks real cap/joint/side, translucent interior/seam, atlas alpha, reflected/nonuniform scaling and snap pixels; GPU profiles also check source vertex IDs, HDR and MSAA. Linux Wayland/X11 each exercise OpenGL compatibility and Vulkan GPU with built-in, HLSL and GLSL fragments. Each profile measures64 warmed active redraws while toggling smoothing/round precision, reporting zero owner managed bytes. Existing Polygon smoothing and legacy Line pixel tests guard the shared path. The [public-only consumer](../../tests/Line.Consumer/Program.cs) links the same pixel checks and verifies all fourteen settings and bundled resources through a fresh scene file; all sixteen ordinary CLR/strict NativeAOT × Wayland/X11 × compatibility or GPU fragment profiles pass, including fresh-file restoration and64 prepared active redraws per profile. NativeAOT uses full trimming, reflection-disabled JSON and linker/compiler warnings as errors; sampled process maps exclude CoreCLR and hardware driver substitution.

Reproduction: build `tests/Electron2D.Tests/Electron2D.Tests.csproj -c Release -r linux-x64` with the current native dependencies. Select `ELECTRON2D_TEST_LINE_GEOMETRY=managed`, an output JSON path for oracle fixtures, or `gpu|compatibility` for pixels. Run `python3 -B tools/line/check_reference.py fixtures.json report.json`. `ELECTRON2D_TEST_POLYGON_AA=managed|gpu|compatibility` selects shared-boundary regression. Build/publish `tests/Line.Consumer/Line.Consumer.csproj` and pass `gpu|compatibility` to repeat the public pixels after file restoration. Native profiles need an actual display and selected backend prerequisites; setting an environment name alone does not prove the driver used.

Local ignored evidence: `bin/line-geometry/2026-10-25/`, including oracle sources/hashes/results, per-profile logs/readbacks/maps, build/regression/consumer results and preserved failed prerequisites. These bounded software-renderer checks do not establish physical GPU performance, native allocator totals, other platforms or owner visual acceptance.
