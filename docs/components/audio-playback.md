# Audio playback and routed buses

Last updated: 2026-10-02

## Scope and types

Implements reusable [AudioStream](../classes/AudioStream.md), caller-owned [AudioStreamPlayback](../classes/AudioStreamPlayback.md), prepared cubic [AudioStreamPlaybackResampled](../classes/AudioStreamPlaybackResampled.md), copied [AudioStreamWAV](../classes/AudioStreamWAV.md), typed [AudioWAVImportOptions](../classes/AudioWAVImportOptions.md), non-spatial [AudioStreamPlayer](../classes/AudioStreamPlayer.md), spatial [AudioStreamPlayer2D](../classes/AudioStreamPlayer2D.md), viewport [AudioListener](../classes/AudioListener.md) and borrowed singleton [AudioServer](../classes/AudioServer.md). Nested format/loop/playback/speaker/mix selectors retain numeric identities.

Internal FAudioContext owns engine/master/submix voices and native volume meters; FAudioStreamVoice owns callback/ring storage and one borrowed playback; AudioPCMCodec owns cold PCM/IMA/QOA encoding/decoding. Backend bindings and codec types are internal to Electron2D.dll. Vendor manifests pin FAudio 26.09 and qoa-fu; their executable algorithms are preserved, with namespace/visibility/diagnostic integration changes only.

## Runtime flow and invariants

WAV import validates RIFF chunks, PCM/IEEE-float dimensions and finite samples, uses the existing SDL WAV/conversion bindings, then performs typed edits and prepares encoded PCM/IMA/QOA. Encoded bytes and tags are copied; resource duplication is independent. Decode publishes an immutable versioned float PCM snapshot. Previously prepared resources refresh on their setter thread; warmed audio callbacks do not decode/allocate. Invalid compressed input fails on consumption. WAV SaveToWAV uses the existing AtomicFile writer; unsupported compressed save leaves an existing file intact.

A player first prepares independent playbacks, fixed Vector2 quantum buffers and pinned stereo float rings. OnVoiceProcessingPassStart fills exactly the next ring quantum using the public playback extension contract; a single infinite native ring submission avoids repeated native submission allocations. Native source voices use NOPITCH/NOSRC because owned cubic mixing implements source/global pitch. Source callbacks are synchronized with graph/configuration through the engine procedure gate. Callback failures silence the ring and are raised at the owner scene frame; failed voices stop before reporting. The copied test PCM observer is internal instrumentation.

The first owner-bound operation claims the audio configuration thread; passive singleton/rate/speed reads and worker resource mixing do not claim it. Foreign configuration rejects thereafter. Buses are real native submix nodes with named sends to earlier indices. Unknown/later/self sends resolve to Master. Live reorder/remove/add/send edits prepare replacement nodes before releasing old ones, redirect existing source sends without replacing playback/cursor/history/pause/polyphony, and apply gains/mute/solo. Errors commit configuration but close all native output coherently for a later retry. Routing refresh attempts all players after individual failures. Queries report actual bus peaks, output devices, rate, channel arrangement and native mix clocks.

Every actual Play prepares exactly one fresh playback; native slots grow lazily to bounded configured polyphony and are reused with oldest replacement. The selected child is therefore fresh for each randomizer Play, while a standalone playback keeps its child across Start. Replacing a slot disposes its previous player-owned playback. Stream factory/start/stop/disposal callbacks reject reentrant player mutation and disposal before changing state. Play supports monophonic policy; Seek restarts one voice. Detached nodes pause/retain playback; disposal releases it. Engine.Run and manual Engine.Stop close native resources even after loop/callback failure. The singleton remains usable for another lifecycle, and borrowed streams are never disposed by the player.

## Example

Partial scene snippet; attach this player to a root Node/Window. Runtime Autoplay starts on entry. Dispose the stream after the owned scene finishes.

```csharp
using var stream = AudioStreamWAV.LoadFromFile("res://audio/click.wav");
var player = new AudioStreamPlayer { Stream = stream, Autoplay = true, VolumeDB = -12 };
window.AddChild(player);
Engine.Instance.Run(window);
```

## Stereo room reverberation

[AudioEffectReverb](../classes/AudioEffectReverb.md) adds a prepared room tail to the same FAudio bus effect chain: one predelay/early-reflection line, eight parallel combs with room feedback and damping, and four serial all-pass diffusion lines per channel. The right channel has a distinct base tuning offset; Spread controls its effective width. Each [internal instance](../classes/AudioEffectReverbInstance.md) borrows a coherent resource snapshot once per block, retains history over live edits, and processes silent input after source completion. Raw finite requests for room/damping/high-pass and dry/wet remain queryable, with bounded effective coefficients; PredelayFeedback stores its 0..0.98 clamp and Spread validates 0..1. Internal overflow clears both channel histories before reporting through the native error path. The pinned source adaptation and MIT notice are recorded in [third-party notices](../../licence/THIRD_PARTY_NOTICES.md).

`AudioReverbTests` compares three profiles and 24576 channel samples against the byte-pinned C++ [oracle](../../tests/Electron2D.Tests/Fixtures/Audio/Reverb/PROVENANCE.md). It checks Resource/scene copies, validation, independent stereo spread, aliased/split blocks, native finite-source tails, bypass, and 64 warmed active/silent CPU blocks plus 64 active/paused native passes without measured managed bytes or custom FAudio allocator calls. Public Linux Wayland GPU and compatibility Window hosts capture processed PCM; 2/4/6/8 logical output-channel profiles pass. Physical listening, SDL/OS allocations, other platforms and broad-scene memory budgets remain unverified.

## Stereo chorus

[AudioEffectChorus](../classes/AudioEffectChorus.md) layers up to four delayed stereo voices over an optional dry signal in the existing FAudio effect chain. Every voice has indexed delay, oscillator rate/depth, decibel level, cutoff and pan controls. The [internal instance](../classes/AudioEffectChorusInstance.md) prepares a bounded ring and separate phase/filter histories at the output rate; it interpolates modulated reads and continues over silent input for tails. Live edits use one coherent block snapshot, and inactive voices retain configuration and history. The resource stores all four voices through typed descriptors and copies them into Resource/scene-local duplicates. The pinned adaptation and MIT notice appear in [third-party notices](../../licence/THIRD_PARTY_NOTICES.md).

`AudioChorusTests` checks defaults and validation, exact static impulse delay, in-place and split processing, pan, gain, cutoff and modulation, Resource/scene copying, native PCM and finite-source tails, bypass, and 64 warmed active/silent CPU and active/paused FAudio passes without measured managed bytes or custom allocator calls. Public Linux Wayland GPU/compatibility hosts capture processed stereo PCM, and 2/4/6/8 logical output profiles pass. Physical listening, actual multichannel devices, SDL/OS allocations, other platforms and broad-scene memory budgets remain unverified.

## Stereo distortion

[AudioEffectDistortion](../classes/AudioEffectDistortion.md) adds five nonlinear curves to the existing FAudio bus chain. A prepared [internal instance](../classes/AudioEffectDistortionInstance.md) keeps independent left/right one-pole histories at the output rate. It curves the low-pass component after pre-gain and adds the untouched high-frequency residual after post-gain. The pinned Overdrive equation is asymmetric in PCM despite its reference prose; the implementation retains the actual transfer and uses an algebraically stable form at extreme finite values. Each block uses one coherent resource snapshot. Copies retain five typed settings without transient histories, and the processor continues on silent input for the filter tail. The pinned source and MIT notice appear in [third-party notices](../../licence/THIRD_PARTY_NOTICES.md).

`AudioDistortionTests` compares all five modes with 2560 channel samples from byte-pinned C++ at the current 44100/48000 Hz profile, with a maximum measured error of 3.5762787e-7 at 44100 Hz. It checks validation, Resource/scene copies, live edits, aliasing, nonlinear endpoints, overflow recovery, native PCM/tail/bypass, and 64 warmed active/silent CPU and active/paused native passes without measured managed bytes or custom FAudio allocator calls. Public Linux Wayland GPU/compatibility hosts capture the processed signal; 2/4/6/8 logical output profiles pass. Physical listening, actual multichannel devices, SDL/OS allocations and other platforms remain unverified.

## Stereo spectrum analysis

[AudioEffectSpectrumAnalyzer](../classes/AudioEffectSpectrumAnalyzer.md) passes PCM through while a public [instance](../classes/AudioEffectSpectrumAnalyzerInstance.md) prepares stereo Hann-windowed FFT magnitudes. Callers borrow a bus instance through `AudioServer.GetBusEffectInstance` and query inclusive frequency ranges in linear average or maximum mode. Five [shared FFT size presets](../classes/AudioFFTSize.md) use the same value contract as the future pitch-shift resource under ADR 0051. Each instance prepares its transform and buffer-length history at creation; later resource edits affect new instances. Audio-thread processing and caller queries synchronize on the instance. Silent input replaces stale magnitudes, and nonfinite transform results reset prepared histories. The pinned source adaptation and FFT attribution appear in [third-party notices](../../licence/THIRD_PARTY_NOTICES.md).

`AudioSpectrumTests` checks all five preset sizes with isolated left/right sine bins, Hann normalization, average/max and reversed/clamped ranges, exact PCM pass-through, aliasing, Resource/scene copies, disposal, overflow recovery, native borrowed queries and 64 warmed active/silent CPU and active/paused FAudio passes without measured managed bytes or custom allocator calls. Public Linux Wayland GPU/compatibility hosts capture unchanged PCM and query live magnitudes; 2/4/6/8 logical output profiles pass. Physical listening, actual multichannel devices, SDL/OS allocations and other platforms remain unverified.
