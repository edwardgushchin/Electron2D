# Audio playback and routed buses

Last updated: 2026-10-02

## Scope and types

Implements reusable [AudioStream](../classes/AudioStream.md), caller-owned [AudioStreamPlayback](../classes/AudioStreamPlayback.md), prepared cubic [AudioStreamPlaybackResampled](../classes/AudioStreamPlaybackResampled.md), copied [AudioStreamWAV](../classes/AudioStreamWAV.md), typed [AudioWAVImportOptions](../classes/AudioWAVImportOptions.md), non-spatial [AudioStreamPlayer](../classes/AudioStreamPlayer.md) and borrowed singleton [AudioServer](../classes/AudioServer.md). Nested format/loop/playback/speaker/mix selectors retain numeric identities.

Internal FAudioContext owns engine/master/submix voices and native volume meters; FAudioStreamVoice owns callback/ring storage and one borrowed playback; AudioPCMCodec owns cold PCM/IMA/QOA encoding/decoding. Backend bindings and codec types are internal to Electron2D.dll. Vendor manifests pin FAudio 26.09 and qoa-fu; their executable algorithms are preserved, with namespace/visibility/diagnostic integration changes only.

## Runtime flow and invariants

WAV import validates RIFF chunks, PCM/IEEE-float dimensions and finite samples, uses the existing SDL WAV/conversion bindings, then performs typed edits and prepares encoded PCM/IMA/QOA. Encoded bytes and tags are copied; resource duplication is independent. Decode publishes an immutable versioned float PCM snapshot. Previously prepared resources refresh on their setter thread; warmed audio callbacks do not decode/allocate. Invalid compressed input fails on consumption. WAV SaveToWAV uses the existing AtomicFile writer; unsupported compressed save leaves an existing file intact.

A player first prepares independent playbacks, fixed Vector2 quantum buffers and pinned stereo float rings. OnVoiceProcessingPassStart fills exactly the next ring quantum using the public playback extension contract; a single infinite native ring submission avoids repeated native submission allocations. Native source voices use NOPITCH/NOSRC because owned cubic mixing implements source/global pitch. Source callbacks are synchronized with graph/configuration through the engine procedure gate. Callback failures silence the ring and are raised at the owner scene frame; failed voices stop before reporting. The copied test PCM observer is internal instrumentation.

The first owner-bound operation claims the audio configuration thread; passive singleton/rate/speed reads and worker resource mixing do not claim it. Foreign configuration rejects thereafter. Buses are real native submix nodes with named sends to earlier indices. Unknown/later/self sends resolve to Master. Live reorder/remove/add/send edits prepare replacement nodes before releasing old ones, redirect existing source sends without replacing playback/cursor/history/pause/polyphony, and apply gains/mute/solo. Errors commit configuration but close all native output coherently for a later retry. Routing refresh attempts all players after individual failures. Queries report actual bus peaks, output devices, rate, channel arrangement and native mix clocks.

Every actual Play prepares exactly one fresh playback; native slots grow lazily to bounded configured polyphony and are reused with oldest replacement. The selected child is therefore fresh for each randomizer Play, while a standalone playback keeps its child across Start. Replacing a slot disposes its previous player-owned playback. Stream factory/start/stop/disposal callbacks reject reentrant player mutation and disposal before changing state. Play supports monophonic policy; Seek restarts one voice. Detached nodes pause/retain playback; disposal releases it. Engine.Run and manual Engine.Stop close native resources even after loop/callback failure. The singleton remains usable for another lifecycle, and borrowed streams are never disposed by the player.

## Example

Partial scene snippet; attach this player to a root Node/Window. Runtime Autoplay starts on entry. Dispose the stream after the owned scene finishes.

```csharp
using var stream = AudioStreamWAV.LoadFromFile("res://audio/click.wav");
var player = new AudioStreamPlayer { Stream = stream, Autoplay = true, VolumeDB = -12 };
window.AddChild(player);
Engine.Instance.Run(window);
```

## Dependencies and limits

[ADR 0047](../decisions/audio.md#adr-0047) selects FAudio/SDL3 and internal managed decoders. WAV plus PCM/IMA/QOA and mono/stereo Ogg Vorbis/MP3 now execute through pinned internal NVorbis 0.10.5/NLayer 3.0.0. Public effects/instances, sample storage/registration, microphone/input ring, bus-layout resource import, output-device switching/latency, composite/music/spatial streams, complete composite parameter surfaces and usage tagging retain precise coverage dependencies. Static WAV file load/save executes; generic ResourceLoader WAV/MP3/Ogg registration executes; fresh-process scene-file authoring remains absent.

Current native start/stop/pause/gain transitions are immediate; reference transition ramps remain Partial with explicit ramp-state/discontinuity tests as the trigger. Runtime Autoplay works; editor-hint suppression requires the editor-hint lifecycle. Stereo is verified. Surround/center matrices retain the source stereo-pair routing and independent unity player-gain LFE route; literal coefficient checks and actual native 2/4/6/8-channel PCM checks pass, while physical multichannel hardware is unverified. Mono device metadata is promoted to the stereo mix profile; unsupported odd layouts and empty quanta reject explicitly. Native audio defaults to Linux x64/ARM64 build profiles; x64 execution is checked. Cross-RID builds require an explicit toolchain or target library. Other audio platform backends/packages and physical listening remain unverified.

## Compressed files and typed parameters

[AudioStreamMP3](../classes/AudioStreamMP3.md), [AudioStreamOggVorbis](../classes/AudioStreamOggVorbis.md), [AudioStreamPlaybackOggVorbis](../classes/AudioStreamPlaybackOggVorbis.md), [OggPacketSequence](../classes/OggPacketSequence.md) and [OggPacketSequencePlayback](../classes/OggPacketSequencePlayback.md) feed the same FAudio source/ring path. Import validates encoded data before committing and prepares full immutable float PCM. MP3 keeps encoded copies and gapless delay/padding; Ogg preserves packet pages, final granules and copied textual comments. Independent captures execute seek, EOF looping and beat-based 256-frame tail fades. Packet/granule writes invalidate old Vorbis cursors and new playback redecodes the current version. Direct sequences are borrowed; imported and retired reload sequences remain stream-owned until disposal. All resource consumers coordinate disposal and per-cursor access; mutable musical metadata uses the resource gate.

AudioStreamPlayback.LoopingOverride and its typed LoopingParameter descriptor represent null/default, true and false without untyped values. AudioStreamPlayer.SetParameter/GetParameter validate the current declared descriptor, apply typed values to prepared voices under the mix gate and retain authored state for future voices. Stream replacement clears parameters. PackedScene stores the supported looping override through a typed descriptor. Parameter authoring, lookup, snapshot storage, construction, resource replacement and full-file decode are cold allocating operations; the warmed PCM/resampling/native quantum path stays prepared.

The shared cubic BeginResample now resets the initial first-silence marker, including short files and restart after EOF, and uses the four-entry history offset when reporting terminal source frames. Native callback failures still silence the ring and report at the owner scene frame. Generic ResourceLoader supports WAV/MP3/Ogg through AudioStream/Resource or exact views: ignore/reuse/replacement, exact path identity, typed extension discovery and malformed rollback. Replace owns independent imported Ogg packet copies after releasing the temporary resource and retains old imported sequences for captured playbacks.

AudioCompressedTests runs CPU/copy/corruption/seek/loop/lifetime/cache checks in the standard suite. `ELECTRON2D_TEST_AUDIO_COMPRESSED=1 SDL_AUDIODRIVER=dummy dotnet run --project tests/Electron2D.Tests/Electron2D.Tests.csproj -c Release` adds actual captured FAudio PCM, parameter propagation and packing, then twenty warmup passes followed by 64 active and 64 paused passes for each codec. CPU tests also measure 64 active and 64 idle spans. PCM vectors match independent MP3 decoding and native libvorbisfile within 0.0001. The retained fixture oracle and hashes are documented beside the fixtures. Native mix measurements cover managed bytes on the audio thread and calls through the custom FAudio allocator; SDL/device, cold import and external allocations remain outside that measurement.

More than two Vorbis channels explicitly reject: the pinned NVorbis submap/residue decoder failed six-channel PCM against libvorbisfile. The retained surround fixture and native oracle define the trigger for a future verified multichannel codec integration; this is Partial coverage, not a permanent exclusion. ## Procedural generator

[AudioStreamGenerator](../classes/AudioStreamGenerator.md) and [AudioStreamGeneratorPlayback](../classes/AudioStreamGeneratorPlayback.md) produce finite copied stereo PCM through a prepared per-playback power-of-two queue and the existing cubic/native stream path. Custom/Output rates execute. The full producer span validates before commit, copies independently and rejects overflow atomically. First Start retains producer frames and begins with 128 silent source-history frames; two cubic-history frames add their usual delay at unit rate. Underruns zero-fill and increment one skip per source block without ending the voice. ClearBuffer is stopped-only and resets queue/time; Stop/Start retain queue/history when generated time is nonzero. Finite seek/fromPosition is ignored. Lifetime, monophony, scene-local configuration copies and live sampling metadata follow the ordinary stream/player contract.

Input mode remains Blocked on the actual SDL3 capture frequency integration. Its setter rejects before commitment; no output-rate fallback is claimed. Input must enter the first capture-device/ring/resampling slice together with AudioServer.GetInputMixRate and AudioStreamMicrophone. Native allocator totals outside the measured FAudio custom allocator, physical listening, other platforms and public scene-file/audio-export capabilities retain separate limits.

[AudioGeneratorTests](../../tests/Electron2D.Tests/AudioGeneratorTests.cs) checks FIFO wrap/overflow/copies, finite and power-of-two/cap boundaries, independent unit/pitch/frequency PCM oracles, active clear rejection, underrun/restart/seek/lifetime, copied/local configuration, producer/mix/BeginResample concurrency and warmed active/idle CPU operations. Native checks observe generated left/right samples in actual FAudio PCM, persistent underrun/recovery, fresh player-owned handles, and 64 active plus 64 paused warmed callbacks with zero measured managed bytes/custom allocator calls. Two successive public Engine.Run producer scenarios execute on each current Linux Wayland renderer with machine-readable cleanup/cursor results.
