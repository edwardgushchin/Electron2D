# Stored polygon paths

Last updated: 2026-10-15

[PolygonPathFinder](../classes/PolygonPathFinder.md) adds closed-area visibility paths without a navigation-server map or native host. AStar/AStarGrid retain their separate directed graph/grid roles. PolygonPathFinder owns authored vertices, canonical boundary edges and an immutable prepared visibility graph, with independent mutable entry penalties and synchronized reusable search workspace.

Half-open ray parity is deterministic. Visibility splits a candidate segment at every boundary crossing and collinear endpoint, then tests every open interval against the closed area. It therefore handles concavity, holes, boundary travel and touching passages without admitting a segment through a hole. The path query projects outside endpoints, links temporary endpoints to visible authored points, and performs A-star relaxation until the goal is popped. Euclidean distance is an admissible lower bound for nonnegative accumulated penalties. Geometry is prepared cold; arrays returned by path/intersection queries belong to the caller. Scalar predicates, bounds, closest point and penalty queries reuse prepared data.

Setup builds and validates before publication. Input arrays are copied; callers coordinate changes while supplying spans. Duplicate reversed edges collapse; zero-length edges and odd-degree/open contours fail. Bounds use double preparation and reject unrepresentable Rect2 dimensions. Segment bounds are checked before orientation tests, and interpolation preserves exact endpoints at zero/one to prevent loss across extreme coordinate scales. A point/edge budget bounds retained graph storage; large-input latency and performance are separate gates. Resource Changed callbacks run outside the data gate after committed changes; inherited exception behavior is preserved.

The `_polygon_path` private stored byte-array descriptor encodes version, authored vertices, canonical edges and penalties. Loading rejects invalid counts/length/version/geometry/penalties before replacing live state and rebuilds visibility. Copies share only immutable geometry and copy penalties; ResetState retires only transient search workspace and preserves stored geometry/penalties. ResourceFileTypes registers a public-only factory, ResourceArchive handles the existing byte-array schema, ResourcePreloader exposes scene ownership and PackedScene preserves the executable resource. The resource borrows no scene or native assets.

PolygonPathFinderTests passes 128 independent weighted shortest-path oracles, closed areas/holes/concavity/islands, projection/intersection order, validation/atomicity, extreme-scale and subnormal geometry, Resource duplication/copy/reset, corrupt typed data, real compressed big-endian resource/scene files, observer failures and synchronized concurrent queries. Prepared 128-cycle scalar queries pass zero managed-byte checks. The extreme-scale endpoint regression was observed RED before exact interpolation endpoints and segment coordinate bounds were corrected.

PolygonPathRenderingTests loads a saved compressed big-endian scene and verifies real pixels for the initial route, penalty-driven replanning around a visible hole and agent arrival on current Linux GPU/compatibility hosts. Each backend passes 64 warmed full rendered movement/query frames at zero managed bytes, from ProcessFrameStarted through FramePostDraw. Input setup, route output allocation, readback/captures and native allocations are outside that interval.

An independent public-only NuGet/NativeAOT consumer passes with reflection-disabled JSON and zero IL warnings. Separate author/render processes save and freshly load the stored polygon scene and execute visible penalty replanning on both backends from /tmp with LD_LIBRARY_PATH unset. Other platforms, native allocations, large-map performance and human owner acceptance remain separate gates. [ADR 0106](../decisions/navigation.md#adr-0106) owns the complete adapted contract.
