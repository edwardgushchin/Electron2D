# Typed scene spawning and replication

Last updated: 2026-10-04

## Public surface and direction

[MultiplayerSpawner](../classes/MultiplayerSpawner.md) and [MultiplayerSynchronizer](../classes/MultiplayerSynchronizer.md) are Node consumers of the existing [SceneMultiplayer](../classes/SceneMultiplayer.md) owner. [SceneReplicationConfig](../classes/SceneReplicationConfig.md) is a copied Resource policy list. [ReplicationProperty](../classes/ReplicationProperty.md) and its [generic descriptor](../classes/ReplicationProperty.Generic.md) identify concrete Node getters/setters and codecs by stable nonzero IDs. [SpawnFactory](../classes/SpawnFactory.md) and its [typed argument form](../classes/SpawnFactory.Generic.md) construct detached nodes from explicitly encoded data. Shared [ReplicationMode](../classes/ReplicationMode.md) and separate [VisibilityUpdateMode](../classes/VisibilityUpdateMode.md) preserve domains under ADR 0051.

No reflection/string property access or universal dynamic value is introduced. Participants agree on property IDs, typed codecs, factory IDs and ordered template indices. Codecs validate complete input and deterministic output. Process-local ElectronObject/Resource/Node and RID property types reject; applications encode portable concrete data. Core values can use explicit application codecs. Configuration tokens, factories and PackedScene templates are borrowed; the scene parent owns inserted instances. Attached mutation/query uses the scene owner. SceneTree interface replacement rebinds existing components, attempts every cleanup/configuration stage, and reports failures after committed replacement.

## Configuration and preparation

New config entries include spawn state and Always updates. AddProperty inserts at the requested index or appends for any negative index; descriptor IDs must be unique. GetProperties returns a copied ordered token array. Membership/index queries use configured immutable token identity; missing index is minus one, while policy access on an absent token throws. Remove missing does nothing. Spawn inclusion is independent of ongoing Never/Always/OnChange. Legacy sync/watch methods project Always/OnChange; disabling one preserves the other mode. Mutations emit Changed after commit. Duplicate/CopyFromResource copy list/policies while retaining immutable tokens; ResetState clears entries.

Synchronizers bind descriptors to compatible nodes at relative NodePath under RootPath. RootPath starts parent (`..`); empty/missing roots stop registration and produce configuration warnings. Config starts null. Rebinding or config revision prepares concrete target/value state and current/previous encoded buffers; maximum combined buffers are 64 MiB, count at most ushort.MaxValue. No universal value boxing is required. Codec budgets are finite and the enclosing consumer applies its aggregate budget. Changes reprepare at the next network frame; mutation during state encoding rejects. Each admitted peer prepares receipt/sequence state, while initial path discovery is cold.

Root/interval/config/visibility settings are typed descriptors with PackedScene storage. Method/codec/factory tokens are authored by ordinary C# constructors/factories. Scene factories return default detached nodes without precreated children; PackedScene restores authored children. In-memory PackedScene instances carry internal template provenance, permitting automatic spawn identification even when ResourcePath is empty. File-backed scene add/get APIs require the typed scene disk-format/loader/saver producer and stay Partial in coverage; this delivery does not claim file/editor authoring.

## Custom and automatic spawn

SpawnPath starts empty. It selects the direct parent under which replicas are inserted. A configured custom factory supports Spawn() with default concrete arguments or Spawn of T with copied encoded data. IDs/codecs match across peers. Factories return a live unparented detached node; invalid roles/lifetimes/null returns and recursive spawn/configuration reject. Validate authority and limit before invoking user codecs/factories. A callback changing scene lifetime/authority rejects before parenting; fresh detached nodes clean up on failed insertion. Default arguments for generic factories are default(T), encoded through the same codec.

SpawnLimit is unsigned, initially zero/unlimited. It counts custom and automatic tracked roots; lowering it preserves existing instances. AddSpawnableScene borrows an ordered in-memory template, up to 255 entries with the custom selector reserved. Instantiate that template and add its root directly beneath SpawnPath for automatic authoritative replication. GetSpawnableScene returns the borrowed resource; ClearSpawnableScenes removes registrations without despawning existing roots. Participants keep matching template indices for replay.

Authority assigns monotonic nonzero wire identity and copied original arguments to each root. Node name and spawner-relative route travel with it. After local insertion/ready, authority sends initial state. Remote factory/template construction validates identity, path, uniqueness, authority and budgets. All configured spawn values apply before entering the tree/Ready. The receiving parent takes ownership; Spawned runs only remotely after insertion/ready. Authority node exit/untracking sends Despawn; remote Despawned executes while the instance is live, then disposal runs even if subscribers fail. Membership/observer failure cannot strand later remote cleanup. Peer loss/reset frees its remote instances while preserving local producer configurations for future admission.

Late admitted peers replay current visible roots and their current configured spawn values, retaining copied original custom arguments. Setting visibility may remove/recreate remote instances; references to old instances become disposed and must be reacquired. Runtime authority/config changes are local and participants agree on them separately. Interface/transport changes commit state and attempt cleanup even after callback failure.

## Visibility and RPC integration

PublicVisibility starts true. GetVisibilityFor queries explicit membership only; peer zero means public. Effective visibility is public OR explicit positive membership, AND every registered predicate. Therefore disabling an individual entry does not hide it while public membership remains enabled. Predicates are unique direct C# peer functions; prepared snapshots make callback changes safe for the current filter iteration. SetVisibilityFor commits membership and reevaluates; UpdateVisibility can target one peer or all and then emits VisibilityChanged. Automatic reevaluation uses the selected Idle/Physics phase only when filters and a valid root exist; None requires explicit refresh. Manual notification without a tree does not register a network producer.

Ongoing synchronization respects the synchronizer's authority and visibility. For a spawned root, authoritative synchronizer visibility combines with OR: any applicable visible synchronizer keeps it spawned; no synchronizers means unrestricted spawning. Hidden peers despawn; visible peers replay current spawn state. RPC sends respect tracked root visibility too: explicit invisible targets reject, broadcasts skip them. Remote spawned roots always permit calls back to their spawning peer; untracked nodes retain ordinary RPC policy. Visibility does not automatically propagate to unrelated Node properties or authority.

## State scheduling, batches and failures

ReplicationInterval and DeltaInterval are finite nonnegative monotonic seconds, initially zero. Zero periodic updates run each network process frame; zero delta interval checks changes each frame. High-resolution Stopwatch ticks preserve fractional intervals. Always getters encode only when due; OnChange compares deterministic encoded bytes each frame, then sends changed IDs once per peer/interval. Never properties have no ongoing capture. Initial change state is sent even when it was also included at spawn. Receipts commit only after a successful packet send, retaining retries for unsent groups; hidden groups do not advance receipts.

MaxSyncPacketSize starts 1350; MaxDeltaPacketSize starts 65535. Both require at least 128 bytes and are bounded to 64 MiB. Actual whole message size is additionally bounded by prepared storage, transport capacity and relay overhead. Complete synchronizer/property groups batch into multiple packets without splitting a group's properties. A group exceeding capacity throws instead of silently omitting state. Always requests Unreliable, OnChange requests Reliable; WS/WSS actually provides reliable/channel-zero delivery as documented by its transport. Mode configuration does not pretend to add unsupported unreliable WS delivery.

Private command 4 carries spawn ID, relative spawner path, scene/factory selector, node name, copied arguments and grouped initial property state; command 5 carries despawn ID. Commands 6 and 22 carry periodic/delta uint32 sequence plus path/property groups. IDs/widths are little-endian, paths UTF8. Each property has stable uint32 ID and a uint32 payload width. This typed private protocol is independent of a foreign engine's dynamic scene protocol. Receivers validate authority, relative branch/subtree, factory/template, property identity/mode/spawn flag, duplicate IDs, counts, widths and complete codecs. Older periodic sequences skip decoder/setter invocation; delta uses reliable delivery. Decoding a complete group succeeds before any setter runs. Setter/callback failures attempt remaining setters/subscribers and restore sender/lifetime scopes; arbitrary external callback effects cannot be rolled back. Error packets cannot poison later valid messages.

Constructors/configuration/first paths/membership/template construction/spawn/despawn/snapshots/errors allocate. Stable state capture/encode/decode, receipts/batching and polling reuse prepared storage; application codec/callback allocations and native backend totals remain separate. Native packet backpressure/transport failure reports typed errors and does not commit unsent delta receipts.

Config defaults/ordering/duplicate/copy/reset/legacy modes and invalid interval/budget boundaries execute.

These are programmatic authoring and headless native network checks.
