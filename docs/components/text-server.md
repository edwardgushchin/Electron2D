# Low-level shaped text buffers

Last updated: 2026-10-29

TextServerManager is a permanent static service registered with Engine. It retains ordered TextServer implementations and a separately selected primary implementation. The initial registry contains Advanced (ICU/HarfBuzz), Fallback (Built-in) and Dummy, with Advanced selected. Discovery does not initialize native fonts. [Concrete implementation profiles](#concrete-implementation-profiles) define their intentionally different capabilities. GetInterfaces returns an independent ordered array. Registration, selection, removal and events follow the [external implementation contract](#external-implementations).

CreateShapedText returns a strongly retained caller-owned buffer identity. FreeRID releases only identities created, duplicated or sliced by that exact interface. TextLine full-buffer and TextParagraph full/dropcap/line identities remain borrowed; their real owners retire them. Public owned buffers belong to their creating thread. Private engine consumer buffers use coordinated implementation admission. Has observes live identities without taking ownership. Invalid or retired IDs fail explicitly. Active layout/draw work rejects mutation, disposal and reentry before publication.

Authoring copies strings, ordered Font lists and OpenType selectors; fonts, typed metadata and TextObjectKey tokens remain borrowed. An internal span font borrows native faces rather than realizing another font or renderer. It preserves source generations, spacing, fallback order and feature policies. Duplicates have separate text/workspaces/identities and share reference-counted internal span adapters; freeing either duplicate cannot invalidate the other. Clear releases content, objects and BIDI overrides, resets the scalar range to zero and preserves direction, orientation, invalid/control preferences and tabs. Empty input succeeds without an added span. Source limits remain 1,048,576 Unicode scalars and 64 MiB UTF-16. A source list contains one to sixty-four live fonts and at most 4096 feature selectors.

Authoring/range/span/object-presence queries do not shape text. Shape and metric/draw consumers prepare the shared native layout; IsReady observes whether content and borrowed generations still match. Width and GetSize ceil the current display dimensions; ascent/descent retain fractional metrics. Borrowed text-object buffers retain their current trim/ellipsis display policy while source ranges, objects and hit geometry remain complete. Direction.Inherited is a consumer policy and is rejected by direct buffer creation/direction setters. Missing and nonprinting character display remain independent policies.

Text and inline-object spans share one source-ordered index. Typed metadata reads retain the exact supplied type without universal conversions. All span getters apply the same buffer-local index, including paragraph slices; source implementations with inconsistent parent-span offsets are deliberately corrected. Inline source ranges use half-open scalar indices, and returned rectangles are baseline-relative. One inline object may represent several source scalars and one advance. BIDI contexts are copied contiguous ranges covering the current buffer; detached ranges retain their scalar origin until Clear.

TextParagraph line IDs initially address their real prepared display layouts. A successful edit detaches only that line's authored slice, updates paragraph line drawing/metrics/objects and preserves the full authored source. Failed first edits discard their temporary slice. A later paragraph reflow retires every previous line ID and detached edit. Full/dropcap aliases update their actual source owners and invalidate paragraph preparation. These lifetime paths use the same weak registry as ordinary text-object drawing.

ShapedTextDraw and ShapedTextDrawOutline record into an existing CanvasItem from a baseline origin. Leading and trailing advance clipping are independent; a negative bound disables that side, and a zero trailing bound removes every positive-width glyph. Horizontal and vertical buffers use their own advance axes. Ordinary coverage and glyph outlines use both existing canvas backends; LCD/MSDF retain their existing capability gates. Returned snapshots, authoring and reflow are cold work; prepared scalar queries and drawing reuse retained storage.

Font-cache RID authoring, complete glyph/run snapshots and independently registered extensions execute through the same typed service. This implementation adds no native font handles, implicit native opening, public Instance accessors or alternate renderer. See [ADR 0107](../decisions/text-objects.md#adr-0107), [native text](text.md) and [retained text objects](text-objects.md).

Ordered source metrics preserve the attempted font prefix through the selected fallback; an unused later source cannot inflate the baseline or underline. Source-specific spacing and feature overrides remain attached to the actual selected native face. Baseline/underline values are captured under the coherent font read scopes, so prepared metadata queries do not reenter virtual font access or read retired faces. Line views retain their surrounding underlying source for global scalar coordinates and BIDI context; typed span indexes are local to the intersecting authored spans. Mutation/clear retains or resets that source context explicitly. Low-level scalar hits interpolate within shaped ligatures; high-level text-object grapheme policies retain their separate contract.

## Caret, selection and navigation

ShapedTextGetCarets returns immutable TextCaretInfo with independent leading and trailing rectangles/directions. Geometry is relative to the supplied buffer baseline: horizontal and vertical layouts exchange advance/cross axes, signed advance sizes preserve direction, and internal cluster boundaries retain split half-height carets. Buffer edges and positions inside ligatures use full-height shapes; inside-cluster directions are Auto. Outside positions return empty shapes. The vertical RTL after-cluster path keeps advance on its own axis, correcting the pinned source's cross-axis displacement.

Composite-character navigation uses retained Unicode character ends, including the buffer end, and merges adjacent spans with equal languages. Different-language span boundaries retain separate contexts. Returned break arrays are independent global-scalar snapshots; closest ties select the preceding boundary. Character navigation clamps to the applicable range, while shaped-cluster next/previous queries preserve an unmatched input position. A ligature may contain several composite characters; a multi-scalar inline object is one shaped cluster. Borrowed paragraph lines and detached/duplicated lines retain their global scalar origin.

Glyph hits return a buffer-local visual record index with half-open advance containment, or -1 outside positive advances. Cluster bounds choose the first eligible visual cluster including both scalar endpoints. Selections normalize reversed logical endpoints and return ordered baseline-advance intervals; inline objects retain gaps. Cluster and selection intervals include complete repeated glyph advances. Nonzero nonvirtual glyph-index visibility remains distinct from painted ink: ordinary spaces and hexadecimal missing placeholders count, while inline objects do not. Dominant direction counts overlapping shaped clusters, including a ligature once, and returns Auto on ties. Full underlying geometry remains available independently of display trimming.

Prepared caret/value/navigation queries reuse retained storage; array snapshots are cold operations. The character-end cache retires on every layout rebuild. Paragraph reflow retires detached line adapters, refreshes its font dependency set and reacquires coherent reads before validating the new result; width- and font-generation-driven reflow cannot retain disposed adapters.

## Line wrapping and owned substrings

ShapedTextGetLineBreaks returns alternating global Unicode scalar start/end offsets for one finite width; ShapedTextGetLineBreaksAdv accepts one to 4096 successive widths. Nonpositive widths suppress width wrapping. Mandatory separators are included unless edge trimming removes them; CRLF is indivisible. WordBound preserves overlong words, Adaptive permits cluster fallback, and GraphemeBound permits every native cluster boundary. Both operations honor the same policies. TrimIndent reserves up to 60% of each subsequent width for the initial indentation. Initial leading and final trailing whitespace are retained; the independent trimming flags act at intervening edges. Start is clamped to the buffer range; empty/exhausted queries retain that global scalar origin. Advanced once stops after a width cycle or mandatory separator; otherwise widths repeat, restarting at mandatory separators. Lists are consumed synchronously and are never retained. Returned arrays are independent cold snapshots.

ShapedTextSubstr returns an owned RID released with FreeRID. It copies complete original clusters rather than reshaping a cut ligature; partial ligatures/inline objects keep their source range and contribute no copied glyph. Whole objects preserve reference-identity keys, metadata and baseline geometry. Selected clusters retain full-source BIDI context and line-ending whitespace direction, while geometry begins at the new baseline origin. A final soft hyphen becomes visible. Parent discovery returns the original root RID; a borrowed unedited paragraph line refers to its full source buffer. A nested substring addresses that root's global range. Sibling substrings share an immutable authored source version and retained font-adapter leases. Borrowed fonts must remain live; source FreeRID, disposal or paragraph reflow does not invalidate the owned child. The parent RID may consequently be retired. Later parent edits do not rewrite existing child content. A first successful child authoring mutation removes the relation and uses its independent authored data; rejected and no-op mutations preserve it. Clear resets the scalar origin; Duplicate produces independent authored data without a parent.

The same retained layout/font owners serve low-level slicing, TextLine and paragraph consumers. Logical glyph lookup is cached in scalar order; line breaking uses original advances and language-specific native opportunities, while substring ordering shares the normal BIDI run resolver. The source-version lease is private to TextLine. Font generation changes rebuild the retained full-source shape before copying the selected clusters. Source text/span queries retain local span indices and original surrounding text.

The executable profiles are `ELECTRON2D_TEST_TEXT_SERVER_WRAPPING=1` and `ELECTRON2D_TEST_TEXT_SERVER_WRAPPING_RENDER=gpu|compatibility`. They cover columns/flags, clamped/extreme ranges, Unicode clusters, BIDI, inline objects, typed metadata, generation changes, parent retirement/reflow, cold range snapshots and warmed substring values. The render profile reconstructs from a saved font in a fresh process, draws actual horizontal lines and vertical columns after freeing their sources, mutates a live substring and measures 64 active plus 64 idle complete frames. ## Fitting, spacing and overrun

ShapedTextFitToWidth adjusts the current raw advances through TextJustificationFlags and returns the ceiled result, which may exceed the target when the line cannot shrink. WordBound adjusts real/virtual word spaces; Kashida uses the selected font size and current Arabic repeat count. AfterLastTab respects the inferred direction; TrimEdgeSpaces zeros edge advances. ConstrainEllipsis fits the retained visible range while preserving its payload. Fitted carets, selection, line wrapping and complete-cluster substrings consume the same raw geometry. A subsequent unconstrained fit retains the existing cut clusters and recomputes displayed advance rather than silently recutting at an old width.

ShapedTextOverrunTrimToWidth chooses an independent display from complete visual clusters. TextOverrunFlags controls trim, word preference, ellipsis, force, short strings and justification-aware minimum-width behavior. NoTrim or a nonpositive width restores raw display. TrimWordOnly retains cluster fallback below six visible records. Without ShortStringEllipsis/EnforceEllipsis, fewer than six retained records suppress the ellipsis. Force requires Trim and AddEllipsis to insert the configured glyph. GetTrimPos/GetEllipsisPos return buffer-local visual glyph boundaries or -1, not scalar positions; raw source ranges, glyph counts, hits and selection remain complete. Metadata getters do not force an unprepared owned buffer to shape.

CustomEllipsis is a valid Unicode scalar, initially U+2026; borrowed paragraph lines expose and retain their paragraph symbol when first overridden, independently of the full source setting. Equal-value comparisons use this actual line value; changes affect subsequent explicit trimming. Missing glyphs fall back to three periods when available, with -1 ellipsis position if neither exists. Vertical glyphs use their actual advance axis. Extra Glyph/Space/Top/Bottom spacing is signed integer logical pixels, initially zero; Max is rejected. Font spacing and buffer spacing add; nonzero total space spacing replaces glyph spacing at spaces. Top/bottom spacing applies even to an empty buffer. Custom punctuation is a copied string (up to 64 MiB UTF-16); nonempty values replace default punctuation classification. Paragraph and service settings share one source owner.

Fit, trim and ellipsis changes retain the substring parent and context. Changed spacing/punctuation is authoring and detaches; equal settings are no-ops. Clear/duplicate retain formatting settings, while authoring/font-generation rebuild resets imperative fit/trim state. Borrowed paragraph line overrides retain prepared raw/display geometry and reach actual paragraph line consumers; reflow retires them. Fitting/trimming reuse two private workspaces under coherent native font reads and publish only on success. Validation, owner thread, disposal and reentry rules remain common to the full buffer family.

## Standalone Unicode utilities

[TextServer](../classes/TextServer.md#unicode-and-locale-utilities) also supplies eleven stateless locale, case, normalization, boundary, identifier and OpenType-tag operations. They have no shaped-buffer RID or buffer thread affinity. Native calls share the private ICU owner lock; returned strings/arrays are cold authoring values. Inputs, language strings and transformed outputs are limited to 33,554,432 UTF-16 units (64 MiB); these standalone operations have no 1,048,576-scalar buffer cap. Null strings throw ArgumentNullException; exceeded budgets throw ArgumentException. Native initialization/data failures propagate explicitly. [Private ICU payloads](../coverage/performance-producers.md#private-icu-allocation-domain-2026-10-29) enter the common native ledger; allocation-failure guards terminate invalid dictionary traversal and retain partial-owner cleanup.

StringToUpper uses the existing managed full-Unicode transform. Lower/title use pinned ICU 78.3 explicit-length calls; empty language samples TranslationServer.GetToolLocale. Titlecase lowers remaining word characters, including Dutch IJ tailoring. StripDiacritics performs NFKD and removes nonzero canonical combining classes; zero-class marks remain. Embedded zeroes and unpaired UTF-16 survive transforms. The decomposition implementation uses bounded per-scalar stack storage; an independent whole-string ICU normalization oracle checks canonical reordering equivalence after removal. Native transforms preflight output size before allocating the returned buffer.

StringGetCharacterBreaks returns independent composite end offsets in Unicode scalar units, including the nonempty source end. StringGetWordBreaks with nonpositive charsPerLine returns alternating lexical start/end ranges, excluding whitespace, punctuation, underscore and the object replacement marker. A positive value limits each line by Unicode scalars, prefers native word/punctuation opportunities and falls back to a scalar cut; it can therefore split a composite character. Soft cuts trim adjacent whitespace, initial/final spaces remain unless cut, hard separators are excluded, and empty hard-line ranges are omitted. CRLF is excluded together. U+200B participates in the specified whitespace policy. Final dictionary boundaries and one-letter lines are retained. These cold string operations are distinct from shaped-cluster-preserving line wrapping.

IsValidIdentifier requires nonempty well-formed NFC, recommended scripts, XID_Start or initial underscore followed by XID_Continue, and complete limited join-control contexts from Unicode 17 UTS #39. Mixed scripts are otherwise accepted. Contextual script checks ignore Common/Inherited; virama contexts use nonspacing marks. A terminal virama-ZWJ is valid, whereas ZWNJ needs its complete following context. Indic dependent vowels after ZWJ are rejected using the required ulayout.icu property data. This is identifier syntax, not confusable/security analysis. IsValidLetter tests letter general categories and rejects surrogate/out-of-range values. IsLocaleRightToLeft uses the case-sensitive language component ar/dv/he/fa/ff/ku/ur, with underscore or hyphen separators and false for empty input.

NameToTag/TagToName share actual shaping aliases. Tags are unsigned 32-bit big-endian values; registered numbered variants resolve canonically, unknown names remove custom_ markers, convert non-ASCII units to spaces, pad/truncate to four bytes and stop at NUL. Unknown reverse tags use custom_ plus Latin-1 bytes up to the first zero. Reverse axis names win over duplicate feature aliases. Known aliases/value queries reuse prepared state.

## Font-free hexadecimal replacement

GetHexCodeBoxSize and DrawHexCodeBox expose the same TextMissingGlyph primitives used by ordinary missing-glyph layout. They require no Font resource or native font initialization. ## Resource sources, glyph snapshots and visual runs

Font.GetRID exposes the actual primary source cache; GetRIDs copies the primary and explicit fallback traversal, retaining duplicates and skipping nulls. Automatic fallback sources are realized lazily and appear in glyph/run results, rather than the authored source list. The weak RID registry contains resource-owned caches as well as service-owned entries. Has recognizes both. Resource RIDs support the complete existing font setting, cache, contour and draw operations; FreeRID rejects their borrowed ownership. Configuration/data replacement preserves a FontFile cache identity, while primary cache removal, clearing, full reset, successful file import and owner disposal retire it. A SystemFont/FontVariation source rebuild retires its private cache; spacing-only variation edits preserve and update that cache.

FontGetResource returns a stable borrowed runtime Font view for a live resource source. Disposing that view preserves the resource and permits another view; Duplicate owns an independent source snapshot. Linked variations may borrow a resource cache and retain the original source independently of intermediate links. Their spacing and baseline stay independent; a zero linked baseline cancels the native source's baseline before applying the link's own value. Source retirement prevents further cache operations while surviving owned links retain Has/FreeRID and independent settings. Authoring preferences on SystemFont/FontVariation remain distinct from runtime raw-cache edits.

ShapedTextGetGlyphs copies complete raw visual records. TextGlyph retains global scalar Start/End, Repeat (including zero inactive opportunities), cluster-leading Count, complete TextGraphemeFlags, baseline Offset, axis Advance, actual FontRID, FontSize, Index and original SpanIndex. Native joining flags survive continuation records; general cluster flags/count belong to the leader. Arrays own no font/native memory. Existing source identities remain live and mutable after a snapshot and can retire later. Objects, missing boxes and synthetic advance-only records use an empty source. Object glyphs have font size zero. ShapedTextGetObjectGlyph returns a buffer-local visual record index, or -1 for an absent or partially sliced object.

ShapedTextSortLogical returns a separate stable scalar-order copy with cluster leaders before continuations and ordinary records before equally ranked virtual opportunities. It preserves visual drawing storage. Substrings retain original scalar coordinates, original span indexes and complete cluster records through the existing source lease; authored detachment regenerates their own span identities. Paragraph line views use their own raw geometry and global span map.

The nine ShapedGetRun queries group adjacent visual cluster leaders by span, actual source, size and resolved direction. Ranges are half-open scalar ranges. GlyphRange is the inclusive pair of first/last cluster-leader indices; use the last leader's Count for its continuations. Text is copied in logical source order; Language and nullable TextObjectKey come from the authored span. Missing indices throw. Prepared scalar/value queries reuse scratch storage; glyph arrays, logical copies and returned run text are cold allocation-capable queries.

ShapedTextGetEllipsisGlyphs/count describe the separate actual display payload; raw glyph/run queries retain the full original text after trimming. Ellipsis records use Start/End/SpanIndex=-1, virtual classification, actual source/index/size and explicit repeats/advance. Borrowed paragraph lines and ordinary lines read their own current display. Reset or font-generation rebuild removes stale ellipsis state. Virtual word/Kashida records retain the exact source identity used for shaping and fitting.

Automatic fallback caches own private FontFile backends, retain active data reads across raw cache replacement, and track child generations even before a notification finishes. Retirement marks lookups unavailable immediately and releases managed owners outside font/native locks. Source projections and owned resource-linked entries keep the owning resource alive until their disposal; the registry stays weak. Native face closure, callback failures and coherent source reads remain distinct from renderer-owned immutable pixels. External TextServerExtension registration, provider replacement/retirement and callback dispatch retain their separate dependency.

Automatic fallback realization keys its cache by the effective four spacing values and baseline, so linked projections sharing a native source retain independent derived font identities. Derived files inherit the source instance's coordinates, embolden, transform, fixed-size policy and raster configuration. Parent spacing/baseline edits invalidate derived caches; direct child cache edits remain real runtime overrides until that invalidation. The existing sixty-four derived-source bound applies to realized parameter sets. Fallback discovery uses each span's language. Apply the effective baseline in the derived native instance, correcting the pinned factory's captured-but-unused baseline field. Keep public virtual GetSpacing policies active while projecting actual source-cache spacing.

Native data reads and managed source disposal have separate endpoints. Retirement marks lookups unavailable immediately, while per-thread deferred owner lists drain managed files after the outermost font read exits. Native cleanup and source-file gates defer delivery; reentrant reads keep independent contexts. Resource projections and owned resource-linked entries retain their original owner until disposal, then release those references. Weak RID lookup alone never retains a resource.

## Unicode security and embedded support data

IsConfusable returns the first dictionary index with an equal case-sensitive Unicode 17 UTS 39 skeleton, or -1. Canonically equivalent strings and multicharacter confusables can match. It does not replace SpoofCheck: that separate query flags invisible/repeated combining sequences, mixed numbering systems, disallowed characters and script combinations under the moderately restrictive policy with recommended/inclusion characters. Identifier syntax remains independent. Explicit UTF-16 lengths retain embedded NUL and malformed units, correcting the pinned security path's zero termination. The ordered dictionary is copied and all entries are validated before returning a match. Combined text/dictionary input and individual output skeletons are bounded to 64 MiB of UTF-16; at most 1,048,576 dictionary entries are accepted.

The private process-owned checker shares the immutable ICU database and serialized boundary gate. Its native temporary work does not retain managed strings. Skeleton arrays are cold returned-work storage; prepared SpoofCheck, locale and repeated initialization queries use no managed owner allocation. Native allocation/performance remains a separate gate.

GetSupportData returns independent exact copies of the embedded 4,811,936-byte TextBreak78.dat database (ICU 78.3 / Unicode 17). GetSupportDataFilename/Info identify this export; SaveSupportData uses FileAccess, writes and flushes the full database, truncates old destinations, and returns false on file access errors. LoadSupportData initializes this embedded profile and returns true when initialization succeeds, regardless of the external filename; later calls have no effect. It never replaces a database borrowed by existing iterators/checkers. IsLocaleUsingSupportData detects my/zh/ja/ko/km/lo/th with case-sensitive language matching and underscore or hyphen separators.

TextServerSecurityTests exercises exact data/hash copies and exports, file failures, skeleton order/canonical/multicharacter cases, malformed/NUL/supplementary input, independent syntax/security results, concurrency, limits and 128 warm zero-managed-byte cycles. Source-built Linux x64 execution and package contract checks do not establish independently repackaged, NativeAOT, foreign-platform, native allocator, hardware or owner acceptance.

## External implementations

[TextServerExtension](../classes/TextServerExtension.md) supplies typed protected callbacks for the complete TextServer operation family. Public methods retain engine admission, source roles, ownership and retirement guards. Override On-prefixed callbacks; inherited callbacks execute the existing native backend. Native fallback suppresses primary-provider recursion only during that native operation. Capability discovery returns the fifteen Feature flags; HasFeature accepts one defined flag. The native implementation advertises its actual text/font/Unicode capabilities. A custom implementation owns its advertised capabilities and callback semantics.

The manager retains registered and selected implementations. Registration appends once; exact ordinal name lookup returns the first matching registration, so duplicate names remain ordered. Selection may use an unregistered implementation and may be cleared explicitly; GetPrimaryInterface then fails until another selection. GetInterfaces remains an independent snapshot. Active consumer reads prevent selection/removal/disposal. InterfaceAdded follows committed registration. Removal first reserves a quiescent registered implementation, calls OnCleanup outside the registry lock while the implementation is still registered, commits removal and delivers InterfaceRemoved. Cleanup/event failures preserve committed state and are reported together. The initial concrete registrations follow the same retained removal rules. Registration/selection does not transfer ownership of an external implementation.

AllocateFontRID requires an independent-source duplication callback. AllocateShapedTextRID allocates a separate shaped-buffer role. Operational factories must return a fresh live identity owned by that implementation, with the expected role; returning an existing or foreign identity fails. Failed factories retire their actual partial allocations, including nested allocations, without freeing unrelated sources. The implementation stores its own opaque data and releases it from OnFreeRID; the engine completes identity retirement even if that callback fails. Caller-created buffers retain their creating-thread policy. Internal consumer buffers admit coordinated queries and reject concurrent mutation/retirement. No native pointer or guessed FontFile state represents an opaque source.

FontGetResource returns the stable borrowed Font projection of an opaque source. It supports ordinary Font metadata, metrics, characters, measurement, drawing, fallbacks and variations. Duplicate owns a fresh independently copied source. FontVariation copies and configures that source lazily, retiring superseded copies after active reads. The projection keeps its creator after primary replacement. A resource-owned variation identity cannot be freed through FreeRID. Ordinary setters publish source generations; NotifyFontChanged publishes a provider-side edit. Font and layout generations detect edits even when a preceding Changed observer fails. Unsupported combinations of opaque font creators fail explicitly before preparation.

Shared layouts author text, ordered fonts/features, languages, typed span metadata, structured BIDI contexts, inline objects, tabs and formatting through the selected implementation. They consume actual producer glyphs, metrics, line/word breaks, runs, carets, navigation, selections and object rectangles. Producer glyph arrays and selections are borrowed only for an admitted call; public array results are independent copies. Contextual substrings preserve surrounding scalar coordinates and source leases, omit partially cut clusters and keep independent formatting/trim state. Reauthoring a detached provider substring resets its new producer origin while preserving the public global range, including axis changes after its paragraph parent retires. Low-level object rectangles are baseline-relative; typed line/paragraph APIs apply their own origins. Signed spacing, both axes, original source/span identities and independent raw/display geometry remain intact.

Font, TextLine, TextParagraph and the shipped text GUI consumers share this boundary. Native defaults continue using actual source resources. Opaque callbacks can draw ordinary canvas commands without a native face. Rich/revealed glyph paths use the same producer and the existing canvas transform, parent clip, material and raster-scale policies. Scoped text clips intersect output bounds and restore the previous bounds after callback failure, including nested scopes with different drawing matrices and hidden animation intervals. Rotated bounds follow the existing axis-aligned canvas scissor policy.

No registry, font, layout or scale monitor spans a user callback. Font changes allocate a retirement snapshot only when dependent provider layouts actually exist; unrelated native configuration changes preserve the warmed zero-allocation contract even while other provider layouts are live. Captured source reads remain valid until the operation completes; source edits prevent new readers from acquiring retired identities. An old native variation remains usable only by its captured callback read, while a query from another thread rejects the retired identity. Failed callback work and failing deferred retirement remain separate inner errors. Private substring snapshots inherit the original consumer admission, so retirement can complete on a different coordinated thread.

Existing CanvasRasterScale reference counts deliver quantized nonbase scale subscriptions to selected/drawing providers. Scale one is permanent. A provider retains its creator subscription after primary replacement; removal/disposal balances it. Owner keys commit before callbacks, every notification recipient is retained, recursive count changes reject before mutation, and other notifications/native cache retirement continue through failures. Native defaults reuse the existing font/texture cache owner.

Layout eviction, source changes, consumer record removal, control/resource disposal, failed preparation and primary replacement explicitly retire private provider buffers. Cleanup completes other resources after a callback failure. Prepared scalar queries and cache hits reuse storage; authoring, copies, array/string snapshots and reflow remain cold work. See [ADR 0107](../decisions/text-objects.md#external-provider-consumer-contract) for the ownership decision.

## Concrete implementation profiles

[TextServerAdvanced](../classes/TextServerAdvanced.md) executes the complete existing direct contextual/bidirectional/vertical native backend, preserving its established font/line/paragraph metrics and caches. [TextServerFallback](../classes/TextServerFallback.md) uses the same font sources, raster caches and admitted consumers with a separate nominal scalar layout kernel. [TextServerDummy](../classes/TextServerDummy.md) deliberately disables text resources, geometry and drawing. Their exact capability/ownership differences are defined by [ADR 0107](../decisions/text-objects.md#concrete-text-implementations-and-project-selection).

Fallback preserves one nominal glyph/cluster per scalar, including combining marks, and logical LTR order. It applies native or authored pair kerning once, shared font advance/baseline/raster policy, inline objects, both advance axes, tabs, word/mandatory wrapping, fitting/overrun and raw selection/caret geometry. Its scalar character boundaries differ intentionally from Advanced composite/contextual clusters. Unicode 17 simple upper/lower mapping ignores locale and performs no expansions; title mapping separates compound identifiers and capitalizes their words. Word utilities split on whitespace/punctuation without dictionary iteration. Script policy uses exact/wildcard overrides and otherwise accepts the script. Contextual feature enumeration and packaged support-data operations are unavailable. Explicit RTL direction/range requests fail before changing a buffer. Automatic Arabic/Hebrew input keeps logical LTR nominal glyphs.

Dummy factories return empty RID, readiness/shaping/add operations return false, source setters/drawing ignore the request and resource queries return typed empty values. It does not resolve or retire foreign identities. Trim, ellipsis and absent-object positions are -1; glyph-count/metrics are zero, and texture images are null. FontGetResource rejects the absent projection. Next/previous shaping-cluster navigation preserves its requested position; character navigation returns the empty range origin. Ordinary Font, TextLine, TextParagraph, Label, RichTextLabel, LineEdit, TextEdit, CodeEdit and Button consume zero text geometry/output; unrelated canvas commands still render. Basic identifier/tag/normalization/parser utilities remain shared; case mapping preserves input, scalar character boundaries remain available and word ranges are empty.

ProjectSettings.TextDriver is the permanent nonbasic restart setting internationalization/rendering/text_driver. Empty preserves the current application selection; otherwise startup resolves the first registered exact-name match before themes and MainLoop initialization, without notifying an uninitialized loop. An absent name rejects startup and restores the engine lifecycle to idle. Feature overrides use the ordinary project registry. Selection changes advance actual font generations, invalidating retained line/paragraph/GUI geometry as well as cached provider state. Service-created buffers and source projections retain their original implementation.
