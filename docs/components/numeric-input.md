# Numeric input fields

Last updated: 2026-10-06

SpinBox : Range combines the existing shared double value model with a required internal LineEdit, stepped arrow drawing, held repeat and accelerated vertical dragging. It supplies numeric editor/channel/property input and the SpinBox prerequisite for ColorPicker. GetLineEdit returns a stable borrowed control: configure it in place and preserve its parent/lifetime. Direct disposal is rejected while its owner remains live.

## Value, editing and input

Defaults are Step=1, vertical Fill, editable, empty affixes, zero CustomArrowStep, false CustomArrowRound/UpdateOnTextChanged/SelectAllOnFocus. All other Range bounds/Page/allow/rounded/sharing behavior stays on Range. The field shows step-dependent decimal precision and optional prefix/suffix with spaces outside editing. Editing displays the number alone, retains scalar caret/selection on formatting and restores affixes afterward. Value and configuration changes refresh the owned field; shared slider updates therefore reach the same numeric value and text before later observers. A failed ValueChanged observer cannot undo committed value or required presentation.

Apply evaluates the current input directly. LineEdit submission/editing changes are delivered through the existing typed deferred queue, preserving captured payloads. Live text-change evaluation is optional and coalesces the latest field state; intermediate numeric punctuation is retained or normalized, malformed input restores the formatted value. Closing SceneTree skips new deferred field work during focus teardown. Parsed values still pass through Range snapping/rounding/Page/bounds. Apply does not fabricate a LineEdit.TextSubmitted event: this follows the actual pinned implementation rather than its contradictory description.

NumericExpression is a private scalar data evaluator, not a gameplay language or general Expression service. It handles case-sensitive constants, integer/floating literals, parentheses, unary/arithmetic/power/comparison/logical/bitwise operators and the current numeric Mathf function family, with typed integer/floating distinctions, source operator precedence, .NET scalar math adaptations under ADR 0032, and existing RNG operations. It has no object instance or member/script invocation. Formula length, nesting, operation and argument budgets are explicit; invalid arity, unknown names, malformed text and invalid integer operations fail without changing the numeric value. General object/string/collection scripting belongs to the separately bounded typed expression host; no universal Variant/object/dynamic runtime is introduced.

Arrow press focuses the field and changes value immediately. CustomArrowStep=0 uses Step; CustomArrowRound snaps the arrow grid through the same Range calculation before the ordinary Step pass. Right-clicking the arrow region chooses its bound. Wheel stepping requires active editing. Holding repeats after 0.6 seconds at 0.075-second intervals while the pointer remains over an arrow. Release, read-only state, hiding, tree exit and focus loss cancel repetition/capture. Relative dragging begins after a two-pixel deadzone, applies signed power-1.8 acceleration and clamps through the existing range. Native capture is acquired only with an active display; headless input simulates the value operation. Native release restores the caller's previous mouse mode. Precise cursor reposition uses an advertised MouseWarp capability; Wayland's absent warp protocol remains an explicit DisplayServer dependency rather than a false physical reposition claim.

## Layout, theme and storage

LineEdit owns text/background/focus styling through the SpinBoxInnerLineEdit variation. SpinBox consumes all current eight arrow state icons/colors, eight button backgrounds, two separators and three sizing constants. Negative buttons_width derives width from current state icons; field/button separation and odd-height vertical splits use integer layout with RTL mirroring. Deprecated updown and set_min_buttons_width_from_icons are excluded under ADR 0004; no inert keys or mirrors are shipped.

Control.LocalizeNumeralSystem defaults true and applies to generated numeric producers, not arbitrary caller-authored text. SpinBox uses the connected TranslationServer FormatNumber/ParseNumber/GetPercentSign family. Nine immutable numeral systems cover the exact 92 pinned locale identities, including supplementary-plane Chakma/Adlam digits, decimal markers and exponent strings. Hyphens are accepted as the existing managed locale spelling; unlisted identifiers preserve text. A global culture change is observed on the next numeric refresh without claiming global localization notifications or CLDR negotiation.

PackedScene and built-in file factories recreate the internal field; concrete defaults and editable/affix/arrow/selection policies persist. Range dependencies restore before Value. ExpEdit is hidden from the concrete stored schema as in the source numeric field. Runtime caret/edit/gesture/repeat/cache state and delegates are not serialized. A bounded 64-state formatted-text cache retains prepared field strings; new states and first-seen shaping/formula evaluation are cold work and allocate. No claim of zero allocation for arbitrary novel numeric text is made.

## Verification and limits

SpinBoxTests drives real routed text/pointer events, expressions and malformed/budget cases, custom arrow rounding, held repeat, headless relative dragging, readonly behavior, borrowed field disposal, shared slider values, failed observers, locale numeral vectors, stored defaults and fresh-process file scenes. Native tests drive SDL arrow clicks, Enter submission, captured relative motion, mode restoration and readback pixels on current Linux Wayland GPU and compatibility. Each backend passes 64 measured prepared value/field/render frames after 64 warmup frames with zero measured owner-thread managed allocation. PNGs are visually inspected. Cold formatting/shaping, pointer event copies, native allocations, physical warp, inherited semantic accessibility/editor facilities, other platforms and owner acceptance remain separate gates.
