# Multiline editing and syntax highlighting

Last updated: 2026-10-07

[TextEdit](../classes/TextEdit.md) provides an executable multiline authoring control on the existing Control, Font/TextLayout and canvas backends. [SyntaxHighlighter](../classes/SyntaxHighlighter.md) is its typed resource extension point; [CodeHighlighter](../classes/CodeHighlighter.md) supplies keyword/category/delimiter parsing. [TextMenuAction](../classes/TextMenuAction.md) is the shared LineEdit/TextEdit command identity under ADR 0051.

The document retains logical lines and scalar caret/selection positions. Buffer edits, multicaret replacement, grouped undo/redo and saved-version tracking feed the same model as native committed text and IME. Layout provides wrapped rows, gutters, viewport fitting, scrolling, pixel/column/grapheme queries and a scalar minimap. Selection/search/current-line/caret/placeholder colors and space/tab theme markers are consumed during real canvas recording. Gutters accept text, borrowed textures, typed metadata and callbacks using the existing drawing scope. Prepared recording reuses color and selection buffers; first shaping/parsing and editing/history are cold operations.

Fonts/icons and explicitly assigned highlighters are borrowed. A highlighter belongs to one live editor; scene restoration creates an independent owned duplicate for every editor, including fresh-process resource loading through registered factories/color dictionary codecs. Required scrollbars and context/direction/Unicode menus are internal owned children with disposal guards. Runtime caret/gutter/history/callback/platform state is omitted from stored scene configuration. Attached notifications coalesce, while observer failures leave completed edits/history available for undo.

TextEditTests verifies document/scalar/grapheme boundaries, multicaret/group/history/version behavior, selection, search, typed gutters, observer failure, borrowed/resource ownership, copied regions/dictionaries, cache invalidation, shaped wrapping, read-only input and fresh-process scenes. Native SDL committed/preedit events and restored clipboard exercise real desktop integration. GPU and compatibility readbacks exercise syntax colors, glyphs, gutters, minimap, selection, scrolling and placeholder. Each backend's 64 prepared selection/render intervals after 64 warm-up frames measures zero managed bytes. Physical IME, native allocators, other OS/RIDs, semantic services and editor authoring remain separate acceptance gates.

Cold undo stores complete document/caret/gutter/background snapshots, limited by the sampled nonnegative TextEditUndoStackMaxSize setting (1024 by default; zero disables committed history). This costs O(document size) per edit. Color-region parsing may revisit earlier lines after invalidation; a delta/state index would reduce that ceiling for large documents. These costs are explicit rather than included in prepared-frame measurements. Minimap is a scalar overview; it does not promise tiny font rasterization.

The [hierarchical cells component](hierarchical-cells.md) now consumes TextEdit as its executable multiline cell host alongside existing LineEdit, HSlider and PopupMenu. TreeItem owns the hierarchy/cell model and Tree supplies column layout, selection and embedded editing. CodeEdit retains its separate code-editor workflows. Native virtual keyboard and native symbol picker require concrete DisplayServer request/session services, so their inert flags are absent and coverage records the target integration trigger.

IME preedit is projected at every active caret, including multiple carets on one logical line. Source/display scalar mapping keeps hit testing and caret layout in the document coordinate space; apply commits one grouped edit. History version identities remain distinct when an undone branch is replaced.

[Code authoring](code-authoring.md) now consumes the same document/highlighter/history/input/storage pipeline through CodeEdit. The shared GetLineRangesFromCarets correctly uses an unselected caret position and excludes a selected final line at column zero; duplication and line commands exercise that correction.
