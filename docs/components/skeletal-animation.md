# Skeletal animation

Last updated: 2026-10-07

## Scope and types

[Skeleton](../classes/Skeleton.md) and [Bone](../classes/Bone.md) author a scene hierarchy, inverse rest and current pose palette. [Polygon](../classes/Polygon.md) retains per-point copied bone paths/weights. [SkeletonModification](../classes/SkeletonModification.md), [SkeletonModificationStack](../classes/SkeletonModificationStack.md) and [SkeletonModificationLookAt](../classes/SkeletonModificationLookAt.md) execute typed phase-aware modification resources. [CanvasSkeletonSkin](../classes/CanvasSkeletonSkin.md) prepares influences and deforms retained triangle vertices; [RenderingSkeletonRegistry](../classes/RenderingSkeletonRegistry.md) supplies weak palette identity. Existing AnimationPlayer/Entity descriptors write ordinary authored bone transforms.

## Runtime and ownership

Only uninterrupted direct Bone chains enter an attached rig in child-order DFS. Rest changes, membership and reordering commit a fresh setup, clear override state and publish BoneSetupChanged. Singular bind poses remain authorable and contribute identity deformation. Nodes remain scene-owned; stacks/modifications/textures/materials remain borrowed. Each attached rig binds one stack, each modifier binds one attached stack. Setup/execute structural reentry rejects, user failures retain committed structure, allow retry and attempt all pose restorations. All transient references are weak or owned scene membership; disposal closes logical identities and detaches borrowed resources.

Idle restores authored animation poses, runs matching modifiers, blends requested overrides and consumes transient requests. Physics stages requests and restores authoring. Persistent=true retains overrides even without a stack. Existing ProcessPhase semantic values are used explicitly: Physics=0, Idle=1. Hidden editor state is not an inert runtime flag. Stack strength is consumed by LookAt, whose constraints/offset/endpoint angle feed an actual bone pose. Disabling it restores the authored pose. Hierarchy/rest edits during execution invalidate setup and reject before applying a mixed palette.

Polygon retains original source indices and triangulation, rebuilds influence bindings on path/rest/weight revisions, keeps the four strongest positive weights with stable equal-weight order and normalizes them with widened accumulation. Missing/mismatched records and zero sums leave points unchanged. It maps actual interpolated Polygon/Skeleton bases, consumes pose multiplied by inverse rest and maps back. Bone TopLevel follows its actual canvas pose. Inversion ignores skin; indexed contours preserve original source-weight indices. One viewport and CanvasLayer are required. Geometry/color/UV edits still follow ordinary copied Polygon semantics. Forced redraws of ordinary contours now use retained point/UV/color/index scratch arrays.

## Storage and adaptations

Exact built-in factories/descriptors persist Bone rest/endpoints, Skeleton stack and concrete modification settings. PackedScene always duplicates a rig's stack/modification graph even in ordinary shallow scene copying; internal resource aliasing survives through the existing duplication session, and encoded graph resources receive ordinary owned lifetime. Palette identity, target caches, overrides and interpolation history are transient. Polygon bone records use a bounded versioned byte archive (4096 records, 65536 weights each, 64 MiB total), fully validated before replacement. Arbitrary custom modifications must supply registered factory/copy/schema contracts.

Pinned Skeleton2D/Bone2D map to dimensionless Skeleton/Bone across the complete family under ADR 0004/0008. The source raw Process=0/Physics=1 integers project by meaning to shared ProcessPhase, avoiding a duplicate enum. The pinned skeleton_2d.cpp lines 800–801 consume the override when persistent is true, opposite to Skeleton2D.xml's persistent contract; the documented persistence is implemented and tested. Source LookAt submits persistent=true to exploit that inversion; Electron2D submits a documented transient request so disabling restores animation. Multi-turn angle normalization terminates using PosMod rather than the source's one-turn conditional adjustment. Stored constraint_in_localspace default true is exposed as a typed property. Finite validation, owner/callback guards, reusable managed storage and unique copied stack ownership follow the accepted resource/runtime rules.

## Executable IK solvers

[SkeletonModificationTwoBoneIK](../classes/SkeletonModificationTwoBoneIK.md) supplies two-segment law-of-cosines distance/side solving. [SkeletonModificationCCDIK](../classes/SkeletonModificationCCDIK.md) supplies one authored-order joint/tip pass with direct aiming and local/global/inverted limits. [SkeletonModificationFABRIK](../classes/SkeletonModificationFABRIK.md) supplies at most ten scratch-based backward/forward iterations, .01 pixel convergence, actual world magnets and final target orientation. [SkeletonIKBinding](../classes/SkeletonIKBinding.md) shares weak revision-aware path/index bindings and finite math; private joint records persist typed configuration.

All three use existing modification phase/enable/strength and transient overrides; no new rendering pass is needed. Bound numeric setters also author paths and keep identity through reordering; missing paths do not retain stale targets. Length solving uses positive metadata times minimum absolute global scale. Mirrors and endpoint angles participate. TwoBoneIK clamps outer/inner reach and handles a coincident equal-length fold; nonpositive segments skip. CCD keeps its documented single-pass/order semantics, including explicit tip and actual stored constraint_in_localspace policy. FABRIK measures convergence against updated scratch rather than unchanged live bones, uses safe coincident-axis fallback and positive reflected lengths, and clears transient strong bone arrays even on failure. Nonuniform/skewed bases use conservative length policy; no exact anisotropic endpoint guarantee is claimed.

Skeleton now snapshots override/strength/persistence arrays into reusable setup-capacity buffers before a pass. On callback/solve failure it restores those arrays as well as authored poses, retaining prior requests and preventing staged partial solver requests from leaking into a later disabled frame. Cold chain authoring/copy/file paths are bounded and may allocate; prepared solver paths reuse scratch and weak caches. Exact registered factories and joint blobs (4096 joints, 64 MiB) persist three concrete resources through independent PackedScene stack graphs. All data is validated before replacement.

SkeletonIKTests verifies actual endpoints, flipped/limited/inner/outer/folded reach, local/global/inverted CCD angles, magnets that change actual bending, oriented tip, three-joint FABRIK, mirrored bases, numeric/path guards, strength/physics staging, duplication and fresh-process .e2dscene execution. ELECTRON2D_TEST_IK=1 selects these checks; ELECTRON2D_TEST_IK_HOST=1 with ELECTRON2D_IK_RENDERER=gpu or compatibility additionally executes three visible weighted polygons, real deformed pixels and 64 prepared intervals with zero managed bytes on current Linux x64. Headless warm checks cover 128 iterations per solver at zero managed allocation. Native allocator behavior, large rigs, foreign platforms and owner acceptance remain unverified.

## Jiggle and nested stacks

[SkeletonModificationJiggle](../classes/SkeletonModificationJiggle.md) stores copied joint configuration and retained spring-like force/velocity/point state, aiming ordinary Bone transforms at the result. [SkeletonModificationStackHolder](../classes/SkeletonModificationStackHolder.md) borrows a child stack and executes only its matching phase with independent child strength. Both exact built-in resource factories participate in the existing nullable modification array codec and forced scene graph copies. Private [Joint](../classes/SkeletonModificationJiggle.Joint.md)/[State](../classes/SkeletonModificationJiggle.State.md) pages distinguish authoring from transient simulation.

Jiggle retains the discrete source update: force=(target-dynamic)*stiffness*delta+optional gravity*delta; acceleration=force/mass; velocity+=acceleration*(1-damping); dynamic+=velocity+force+origin-lastOrigin. Mass is positive, damping is 0..1 and every numeric input/output is finite. Mass-zero division is rejected. Reset/first binding initializes dynamic/last origin/last clear even for bone index zero, correcting incomplete source setup seeding. New joints copy current defaults; default edits/Override=false propagate full defaults. Each successful joint commits history after its pose/request; an earlier successful joint remains advanced if later work fails. Pose/override transaction restoration is still performed by Skeleton. Missing targets freeze; lost/singular/layout-changed bone selections reseed their history. Delta=0 does not erase retained velocity and still compensates origin displacement.

Collider mode executes real World.DirectSpaceState rays only in Physics; wrong-phase use rejects before advancing. Bodies/layer-mask filtering and ordinary hit-from-inside=false behavior apply. Hits revert the dynamic candidate to its prior clear point and clear velocity/acceleration. This does not guarantee whole-bone, skinned mesh or swept-volume exclusion; it preserves the applicable dynamic-point ray contract. The existing world prepares live fixtures and rejects wrong-thread/stepping access. No new backend/native dependency is introduced.

Held graphs track incoming holders weakly, plus direct-root binding. Removing one holder/alias preserves shared children; final release drops child/modification bindings without disposing resources. Graph replacement commits before setup callbacks; failure invalidates the parent for explicit retry and retains cleanup leases. Runtime cleanup hooks run after raw binding removal. Direct child Execute selects that child for an authored-pose transaction; source root siblings are not accidentally executed. Parent/child strength remains independent. Null/disabled/wrong-phase holders skip. Cycles reject in setter traversal or setup/reentry; nesting is bounded to 128 and cold traversal to 16384 stacks. Running reset/disposal/replacement rejects before terminal mutation; depth/running guards clear in finally. Graph structure/copying is a cold allocation boundary.

Exact state persists through versioned 4096-joint/64-MiB blobs and registered resource references; force/velocity, weak leases/targets and prepared history are not serialized. Force-copy child hooks preserve aliases in each independent PackedScene stack graph. SkeletonJiggleTests uses public authoring, same-process and fresh-process .e2dscene loading, actual nested simulation, numeric/path/default/reset/reflection/collision/ownership/callback cases and 128 prepared nested cycles with zero managed bytes. ELECTRON2D_TEST_JIGGLE=1 selects headless checks. ELECTRON2D_TEST_JIGGLE_HOST=1 with ELECTRON2D_JIGGLE_RENDERER=gpu or compatibility runs three visible polygons for spring motion, held half-strength aiming and collision-blocked pose, verifies native pixels and 64 prepared query/solve/render intervals at zero managed allocation. Captures are visually inspected. Native allocator behavior, large graphs/rigs, foreign platforms and owner acceptance remain unverified.

## Verification and limits

ELECTRON2D_TEST_SKELETON=1 runs SkeletonTests through the test host, including actual AnimationPlayer bindings, noncommuting transforms, TopLevel, physics presentation, hierarchy/override/constraint/path cases, callback failures/retry/reentry, resource ownership and fresh-process .e2dscene loading. 128 warm pose/redraw/skin/replay iterations report zero managed allocation. ELECTRON2D_TEST_SKELETON_HOST=1 with ELECTRON2D_SKELETON_RENDERER=gpu or compatibility runs Engine.Run, verifies actual deformed native pixels, borrowed RID protection and 64 prepared intervals with zero managed allocation on current Linux x64. Captures were visually inspected; native allocator behavior, large-rig throughput, foreign platforms and owner acceptance remain unverified.

General MeshSurfaceData skin channels/packed regions and caller-owned server palette attachment are still separate executable producer/consumer slices. Physical bone synchronization and editor gizmo authoring retain member-specific coverage dependencies; this component adds no inert placeholders.
