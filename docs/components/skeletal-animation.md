# Skeletal animation

Last updated: 2026-10-07

## Scope and types

[Skeleton](../classes/Skeleton.md) and [Bone](../classes/Bone.md) author a scene hierarchy, inverse rest and current pose palette. [Polygon](../classes/Polygon.md) retains per-point copied bone paths/weights. [SkeletonModification](../classes/SkeletonModification.md), [SkeletonModificationStack](../classes/SkeletonModificationStack.md) and [SkeletonModificationLookAt](../classes/SkeletonModificationLookAt.md) execute typed phase-aware modification resources. [CanvasSkeletonSkin](../classes/CanvasSkeletonSkin.md) prepares influences and deforms retained triangle vertices; [RenderingSkeletonRegistry](../classes/RenderingSkeletonRegistry.md) supplies weak palette identity. Existing AnimationPlayer/Entity descriptors write ordinary authored bone transforms.

## Runtime and ownership

Only uninterrupted direct Bone chains enter an attached rig in child-order DFS. Rest changes, membership and reordering commit a fresh setup, clear override state and publish BoneSetupChanged. Singular bind poses remain authorable and contribute identity deformation. Nodes remain scene-owned; stacks/modifications/textures/materials remain borrowed. Each attached rig binds one stack, each modifier binds one attached stack. Setup/execute structural reentry rejects, user failures retain committed structure, allow retry and attempt all pose restorations. All transient references are weak or owned scene membership; disposal closes logical identities and detaches borrowed resources.

Idle restores authored animation poses, runs matching modifiers, blends requested overrides and consumes transient requests. Physics stages requests and restores authoring. Persistent=true retains overrides even without a stack. Existing ProcessPhase semantic values are used explicitly: Physics=0, Idle=1. Hidden editor state is not an inert runtime flag. Stack strength is consumed by LookAt, whose constraints/offset/endpoint angle feed an actual bone pose. Disabling it restores the authored pose. Hierarchy/rest edits during execution invalidate setup and reject before applying a mixed palette.

Polygon retains original source indices and triangulation, rebuilds influence bindings on path/rest/weight revisions, keeps the four strongest positive weights with stable equal-weight order and normalizes them with widened accumulation. Missing/mismatched records and zero sums leave points unchanged. It maps actual interpolated Polygon/Skeleton bases, consumes pose multiplied by inverse rest and maps back. Bone TopLevel follows its actual canvas pose. Inversion ignores skin; indexed contours preserve original source-weight indices. One viewport and CanvasLayer are required. Geometry/color/UV edits still follow ordinary copied Polygon semantics. Forced redraws of ordinary contours now use retained point/UV/color/index scratch arrays.

## Storage and adaptations

Exact built-in factories/descriptors persist Bone rest/endpoints, Skeleton stack and concrete modification settings. PackedScene always duplicates a rig's stack/modification graph even in ordinary shallow scene copying; internal resource aliasing survives through the existing duplication session, and encoded graph resources receive ordinary owned lifetime. Palette identity, target caches, overrides and interpolation history are transient. Polygon bone records use a bounded versioned byte archive (4096 records, 65536 weights each, 64 MiB total), fully validated before replacement. Arbitrary custom modifications must supply registered factory/copy/schema contracts.

Pinned Skeleton2D/Bone2D map to dimensionless Skeleton/Bone across the complete family under ADR 0004/0008. The source raw Process=0/Physics=1 integers project by meaning to shared ProcessPhase, avoiding a duplicate enum. The pinned skeleton_2d.cpp lines 800–801 consume the override when persistent is true, opposite to Skeleton2D.xml's persistent contract; the documented persistence is implemented and tested. Source LookAt submits persistent=true to exploit that inversion; Electron2D submits a documented transient request so disabling restores animation. Multi-turn angle normalization terminates using PosMod rather than the source's one-turn conditional adjustment. Stored constraint_in_localspace default true is exposed as a typed property. Finite validation, owner/callback guards, reusable managed storage and unique copied stack ownership follow the accepted resource/runtime rules.

## Verification and limits

ELECTRON2D_TEST_SKELETON=1 runs SkeletonTests through the test host, including actual AnimationPlayer bindings, noncommuting transforms, TopLevel, physics presentation, hierarchy/override/constraint/path cases, callback failures/retry/reentry, resource ownership and fresh-process .e2dscene loading. 128 warm pose/redraw/skin/replay iterations report zero managed allocation. ELECTRON2D_TEST_SKELETON_HOST=1 with ELECTRON2D_SKELETON_RENDERER=gpu or compatibility runs Engine.Run, verifies actual deformed native pixels, borrowed RID protection and 64 prepared intervals with zero managed allocation on current Linux x64. Captures were visually inspected; native allocator behavior, large-rig throughput, foreign platforms and owner acceptance remain unverified.

General MeshSurfaceData skin channels/packed regions and caller-owned server palette attachment are still separate executable producer/consumer slices. Further CCD/FABRIK/TwoBoneIK/jiggle/stack-holder solvers, physical bone synchronization and editor gizmo authoring retain member-specific coverage dependencies; this component adds no inert placeholders. See [ADR 0092](../decisions/mesh.md#adr-0092), [scene](../domains/scene.md), [rendering](../domains/rendering.md) and [resources](../domains/resources.md).
