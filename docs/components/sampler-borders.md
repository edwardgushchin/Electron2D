# Native sampler borders

Last updated: 2026-10-27

[RDSamplerState.BorderColor](../classes/RDSamplerState.md#border-color) and [SamplerBorderColor](../classes/RenderingDevice.SamplerBorderColor.md) connect normalized ClampToBorder U/V addressing to device samplers and copied Shader settings under [ADR 0028](../decisions/rendering.md#adr-0028). The default is FloatOpaqueBlack. Each axis keeps its own addressing mode; a border color contributes only outside a border-clamped axis, including native linear filtering across that edge. Ordinary and array images preserve their existing mip, comparison and lifetime contracts.

Floating-point border variants serve normalized/floating-point/depth sampling; integer variants serve signed/unsigned integer sampling. Integer images still require nearest filtering without effective anisotropy. Mismatched border/image scalar classes reject in high-level authoring, combined device binding or separate image/sampler dispatch validation. Unused border colors do not constrain a binding. Undefined colors reject at the configuration setter. Configurations and getters remain independent copied ElectronObject values; disposing the description cannot mutate an existing RID.

The private Electron2DRender adapter uses the SHA-pinned SDL 3.4.18 declarations and rejects another SDL core/revision or a non-Vulkan driver before opaque native access. It creates a normal SDL sampler, creates the requested Vulkan sampler and replaces its handle before publishing the wrapper. SDL retains wrapper reference counting, command retention and deferred destruction. Failure releases the unpublished wrapper. There are no public native handles, vendored implementation edits or shader source rewrites. Metal and other drivers reject border sampling explicitly; mirror-clamp still requires its native capability/adapter.

Shader sampler archives write metadata version two including the color. Version-one payloads remain readable with the original FloatOpaqueBlack default. Parsing validates a complete replacement before publication; malformed/truncated/duplicate metadata preserves the previous table. Copied shader settings use the existing bounded native sampler cache and its two-epoch retirement.

Unnormalized coordinates remain Blocked: they require constrained sampler state, a single-layer/single-mip image view and validation of explicit-LOD nonprojective sampling operations without offsets or gathers. A stored flag alone cannot satisfy this contract. The Vulkan restrictions are specified by [VkSamplerCreateInfo](https://registry.khronos.org/vulkan/specs/latest/man/html/VkSamplerCreateInfo.html).

## Executable checks

`tests/ShaderSamplers.Consumer` supplies `borders` for all six colors, float/signed/unsigned images, combined and separate bindings, two mip levels, mixed axes and native linear edge blending. It checks copied description lifetime, foreign-device rejection and prepared dispatch allocation. `borders-canvas` checks copied shader cache settings through native drawable blit/readback, with window presentation disabled. The default authoring cohort checks archives, old payloads and atomic malformed-data rejection. `ELECTRON2D_TEST_SAMPLER_CONFIGURATION=1` checks native field projection, descriptors and unsupported-driver guards without opening a device.

Linux x64/Vulkan qualification passed 72 configurations and six depth-comparison cases under both CLR and strict NativeAOT. Each configuration verifies both mip levels and eight prepared zero-allocation dispatches on the owner thread. Both profiles passed authoring/archive checks and four copied GPU blit/readback cases in a private Wayland compositor with window presentation disabled. Five focused root cohorts cover configuration, independent samplers, textures, depth and native memory; the native module also passed 32 allocation/retirement cycles with concurrent snapshots, six sampler colors and unsupported-core rejection. Native layout tests and 26 package producer checks passed. Foreign-platform execution, window presentation, sampler native allocation totals and owner visual acceptance are separate gates.
