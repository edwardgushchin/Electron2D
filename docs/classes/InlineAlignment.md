# InlineAlignment

Last updated: 2026-10-07

**Namespace:** `Electron2D`. **Declaration:** `public enum Electron2D.InlineAlignment`. **Source:** [source](../../src/Scene/GUI/InlineAlignment.cs). **Component:** [Rich text](../components/rich-text.md).

## Description

Namespace-level image/table to text alignment. ImageMask selects the object anchor; TextMask selects top, center, baseline or bottom of the text line. Combined Top, Center and Bottom values preserve their numeric domains; BaselineTo tables use their selected row baseline.
