# ItemList.IconMode

Last updated: 2026-09-30

**Declaration:** `public enum ItemList.IconMode` · **Source:** [ItemList.cs](../../src/Scene/GUI/ItemList.cs) · **Component:** [Scrolling](../components/scrolling.md)

`Top = 0` places icons above text; `Left = 1` places them beside text and is the default. The mode changes item measurement and drawing. See [ItemList](ItemList.md) and [coverage](../coverage/classes/ItemList.md).
