## Description

Places one borrowed [Shape](Shape.md) as a direct child of a [PhysicsBody](PhysicsBody.md) or [Area](Area.md). Only a direct collision-object parent contributes a physics fixture set. Area fixtures are nonresponding sensors; body fixtures participate in collision response and can be one-way. A large convex polygon can contribute several internal fixtures while remaining one borrowed resource. Local position and rotation offset those fixtures; active scale/skew are rejected. The caller owns the Shape resource. Assignment, resource changes, disabling and tree transitions update fixtures before the next physics step. A missing parent or shape is reported through configuration warnings.

## Example

The direct [CollisionPolygon](CollisionPolygon.md) sibling creates and owns its geometry from vertices; this node continues to borrow one reusable Shape resource.

```csharp
using var geometry = new RectangleShape { Size = new Vector2(20, 20) };
var body = new RigidBody();
body.AddChild(new CollisionShape { Shape = geometry });
// Retain geometry while the body borrows it.
```

## Property descriptions

<a id="debugcolor"></a>
### `DebugColor`

Stored finite Color, initially sampled from ProjectSettings.DebugCollisionShapeColor
at construction, with feature overrides. SceneTree.DebugCollisionsHint enables local
shape drawing through the existing canvas. Disabled shapes use gray with half alpha;
one-way shapes include a direction arrow. Setting the color invalidates drawing and
preserves physical geometry/participation. Nonfinite channels reject with
ArgumentException; attached mutation requires the owner thread. PackedScene preserves
an explicit color, including transparent colors.


<a id="shape"></a>
### `Shape`

Accepts a live CircleShape, CapsuleShape, SegmentShape, ConvexPolygonShape, ConcavePolygonShape, RectangleShape or null. A disposed shape throws before assignment. The old resource's disposal listener is removed and the new one's installed; geometry and solver policy use separate revision epochs; the node does not dispose either. Successful assignment marks its parent's fixtures dirty and refreshes configuration warnings. A Changed callback failure from a warning observer may propagate after assignment.

<a id="disabled"></a>
### `Disabled`

Changing it marks the parent fixture set dirty. A disabled child remains in the scene and retains its borrowed resource, but contributes no Box2D geometry. The next fixed step applies the change.

<a id="onewaycollision"></a>
### `OneWayCollision`

When true on a direct physics-body child, the first contact of each fixture pair is accepted only from the side opposite `OneWayCollisionDirection`; that decision persists until the pair separates. The flag applies to all fixtures generated by the child shape, including compound contours. Changing it rebuilds the parent's fixtures before the next fixed step. An Area child keeps the value in PackedScene but remains a sensor: it detects a crossing from either side and reports an inapplicable-setting warning.

<a id="onewaycollisiondirection"></a>
### `OneWayCollisionDirection`

The local pass-through direction defaults to `(0, 1)` and rotates with this child and its parent body. A finite nonzero assignment is normalized, including very large finite components. Zero is accepted and rejects all contacts while one-way mode is enabled. Nonfinite input throws `ArgumentOutOfRangeException` without changing the previous direction. The value is stored in PackedScene; changing it rebuilds the active body fixtures before the next step.

<a id="onewaycollisionmargin"></a>
### `OneWayCollisionMargin`

The default one scene unit bounds how deeply an initially overlapping body may recover against this one-way surface. [PhysicsBody](PhysicsBody.md) motion uses the larger of this value and its own safe margin; deeper one-way overlaps are ignored in the recovery phase. Ordinary fixed-step contacts continue to use the side decision. Negative or nonfinite writes reject before mutation. Changes rebuild active body fixtures before the next motion test or fixed step and survive PackedScene; Area sensors ignore the property.

## Lifecycle, errors and limits

The child registers during tree entry and unregisters before its exit finishes; scene disposal disconnects resource listeners. A disposed borrowed Shape becomes ineligible at the next step. A scale or skew change on an active shape fails before replacing the parent's existing fixtures; correction permits a later step. Owner-thread scene mutation follows Node and Entity. Borrowed geometry revision/disposal checks refresh retained debug drawings even when a Changed subscriber throws. [Physics canvas diagnostics](../components/physics-debug.md) records CPU/GPU and native checks.

[PhysicsBodyTests](../../tests/Electron2D.Tests/PhysicsBodyTests.cs) checks parent/shape diagnostics, live shape edits, disablement, PackedScene restoration and borrowed lifetime. [OneWayCollisionTests](../../tests/Electron2D.Tests/OneWayCollisionTests.cs) checks both contact sides, direction and rotation, live changes, packing, area sensing and warmed allocation. [PhysicsMotionTests](../../tests/Electron2D.Tests/PhysicsMotionTests.cs) checks one-way motion approaches, margin depth and invalid rollback. Other shape-family tests cover their borrowed fixtures. [ADR 0065](../decisions/physics.md#adr-0065) records the one-way body-contact decision.

The [CollisionObject owner registry](CollisionObject.md#createshapeowner) now supplies logical shape slots for both child and manual groups. Query/contact indices identify global slots, while ShapeFindOwner returns the distinct group ID; removal shifts later indices. Motion owner accessors resolve weak configured objects as well as child nodes. See [ADR 0071](../decisions/physics.md#adr-0071).

The complete OneWayCollisionTests now runs on explicitly selected public CPU/GPU worlds: opposite contact sides, child/body rotation, live policy and zero-direction edits, dynamic/kinematic platforms, Area sensor bypass and packing. Existing numerical bounds are unchanged; 64 warm active contact frames require 0/0 owner/all-thread managed bytes. Broader inherited/extension, native/platform and final performance acceptance remains open.


[Moving one-way recovery](../components/gpu-resident-motion-queries.md#moving-one-way-recovery)
now includes kinematic/dynamic linear approach over the last physical step on
both production backends, including private/portable restoration. Static surface,
receding/tangent and angular-only velocities do not enlarge recovery depth.
PhysicsMovingOneWayTests checks raw/scene callers, roles, rotated slots, six finite
source families and eight 128-warmup/128-measured complete-frame brackets at zero
managed allocation. Native/platform/hardware/performance acceptance remains open.

Server data operations freeze the addressed RID's consumer membership before status
or geometry hooks and keep it frozen through rebuild, rollback and rejected-copy
retirement. Incoming enabled/disabled Body/Area slots in unrelated worlds, direct
owner additions and CollisionShape assignments of borrowed views reject before
changing storage. Detached existing consumers also reject edits and release.
The guard is released on supplier/status failure and before committed old-view
retirement, so later ordinary bindings remain available.

Manual Parent/Unparent notifications require the scene owner before inherited canvas callbacks or physical shape-owner metadata can change. A worker failure preserves the existing shape owner and its query identity. Custom notifications and interpolation resets retain inherited own-group delivery.

Changed body one-way slot policies are captured during authoring and reused by
the next numerical preparation. The [one-way input profile](../components/physics-shapes.md#one-way-input-preparation)
checks edits without an intervening query, retained immutable values and strict
zero-allocation physical frames; changed authoring measured 32 bytes per
logical slot on Linux x64. Area sensing policy is unchanged.

The [one-way slot operation audit](../components/physics-shapes.md#one-way-slot-operation-audit)
checks complete per-slot policy delivery, raw rollback and deferred scene retry,
full stored-group reclaim, normalized/default/zero direction and actual selected
motion/recovery. Warm unchanged-policy query/full-frame intervals require 0/0
managed bytes; changed immutable authoring remains a separate measured cost.
Complete registered numerical response and native/platform/network/performance
acceptance retain their independent gates.
