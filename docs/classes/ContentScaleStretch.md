# ContentScaleStretch

Last updated: 2026-10-12

Namespace-level public enum owned by [Window](Window.md#content-scale). Fractional=0 permits fractional fitting; Integer=1 floors factor, clamps it to one and uses whole client-to-content ratios, with clipping for small clients. No extra sentinel is selectable. See the owning page for geometry, target, storage, input and verification contracts.
