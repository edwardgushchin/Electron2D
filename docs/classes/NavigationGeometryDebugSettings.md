# NavigationGeometryDebugSettings

Last updated: 2026-10-27

Immutable internal snapshot of the twenty executable global geometry diagnostic settings. NavigationServer samples typed values with feature overrides on first use and retains them independently of agent-path settings. Restart metadata reflects that lifetime.

Part of [navigation controls and diagnostics](../components/navigation-diagnostics.md), under [ADR 0097](../decisions/navigation.md#global-simulation-and-scene-diagnostics).
