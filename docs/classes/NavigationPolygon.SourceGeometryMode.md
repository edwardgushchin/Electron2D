# NavigationPolygon.SourceGeometryMode

Last updated: 2026-10-10

Public nested enum owned by NavigationPolygon; the Max boundary sentinel is not assignable as an active setting. See [baking](../components/navigation-baking.md).

| Value | Integer | Contract |
| --- | --- | --- |
| GroupsExplicit | 2 | Only grouped nodes. |
| GroupsWithChildren | 1 | Grouped nodes and their descendants. |
| Max | 3 | Invalid boundary sentinel. |
| RootNodeChildren | 0 | The root and its descendants. |
