# OGVMovieWriter

Last updated: 2026-10-15

Internal sealed partial [MovieWriter](MovieWriter.md) in [OGVMovieWriter.cs](../../src/Servers/Movie/OGVMovieWriter.cs). Selected after custom handlers decline a .ogv path; the recording lease owns disposal. It samples rate/channel/video and OGV quality/speed/keyframe settings before scene activation, owns FileAccess, one GC handle and one private native encoder, and borrows only the callback's RGB8 Image/Int32 PCM. Positive even dimensions are required. Internal padded YCbCr420 planes retain the exact visible size. Stereo remains stereo; 5.1/7.1 reorder into Vorbis order; 3.1 retains center/LFE in a six-channel file with silent rears. Zero PCM blocks preserve the rational sample clock without terminating Vorbis. End flushes codec/EOS state for completed scene work, destroys native ownership and frees the GC handle before disposing the file. Native write callbacks contain exceptions; codec/IO failures propagate as IOException, with later cleanup errors aggregated by the host. A physical write failure can leave incomplete output. No native codec API is public. See [movie writing](../components/movie-writing.md) for source/package provenance, short-stream priming, allocation fix, executable checks and unverified gates.

With [save and swap](../components/file-save-and-swap.md) enabled, successful EOS finalization publishes output on close. Codec initialization/frame/finalization or native callback failure cancels staging and preserves the old destination. Scene failures still finalize already submitted valid frames.
