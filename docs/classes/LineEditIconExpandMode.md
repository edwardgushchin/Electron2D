# LineEditIconExpandMode

Last updated: 2026-10-04

**Source:** [LineEdit.cs](../../src/Scene/GUI/LineEdit.cs). **Owner:** [LineEdit](LineEdit.md).

Trailing icon placement modes used by LineEdit.

| Name | Value | Contract |
| --- | ---: | --- |
| `FitToLineEdit` | 2 | Fits the field bounds while preserving aspect ratio, then applies RightIconScale. |
| `FitToText` | 1 | Uses a font-height square. |
| `OriginalSize` | 0 | Uses the icon's natural dimensions. |
