# ItemList.ScrollHintMode

Last updated: 2026-09-30

**Declaration:** `public enum ItemList.ScrollHintMode` · **Source:** [ItemList.cs](../../src/Scene/GUI/ItemList.cs) · **Component:** [Scrolling](../components/scrolling.md)

`Disabled = 0` is the default; `Both = 1`, `Top = 2` and `Bottom = 3` choose which reachable vertical edges may draw the themed hint. The gradient appears only while hidden content remains in that direction. See [ItemList](ItemList.md) and [coverage](../coverage/classes/ItemList.md).
