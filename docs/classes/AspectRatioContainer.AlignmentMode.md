**Declaration:** `public enum AspectRatioContainer.AlignmentMode` · **Source:** [LayoutContainers.cs](../../src/Scene/GUI/LayoutContainers.cs) · **Component:** [Canvas rendering](../components/canvas-rendering.md)

`Begin = 0`, `Center = 1` and `End = 2` choose the remaining-space fraction on one axis. Horizontal offsets mirror under RTL. Both alignment properties default to Center. See [AspectRatioContainer](AspectRatioContainer.md) and [coverage](../coverage/classes/AspectRatioContainer.md).
