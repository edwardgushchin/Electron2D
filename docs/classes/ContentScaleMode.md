# ContentScaleMode

Last updated: 2026-10-12

Namespace-level public enum owned by [Window](Window.md#content-scale). Disabled=0 retains client raster resolution; CanvasItems=1 rasterizes at fitted client resolution; Viewport=2 rasterizes at logical resolution and presents its image. No extra sentinel is selectable. See the owning page for geometry, target, storage, input and verification contracts.
