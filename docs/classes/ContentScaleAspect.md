# ContentScaleAspect

Last updated: 2026-10-12

Namespace-level public enum owned by [Window](Window.md#content-scale). Ignore=0 stretches axes independently; Keep=1 fits with margins; KeepWidth=2 and KeepHeight=3 selectively expand one logical axis; Expand=4 fills the client by expanding the logical area. No extra sentinel is selectable. See the owning page for geometry, target, storage, input and verification contracts.
