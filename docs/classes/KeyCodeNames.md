# KeyCodeNames

Last updated: 2026-10-17

**Namespace:** `Electron2D`. **Declaration:** `internal static class KeyCodeNames`.
**Source:** [KeyCodeNames.cs](../../src/Core/Input/KeyCodeNames.cs).
**Component:** [Input runtime](../components/input-runtime.md).

Shared implementation of [OS keyboard names](OS.md#keyboard-names) and
[InputEventKey](InputEventKey.md) key text. This helper has no public or protected API.

## Description and methods

| Internal declaration | Behavior |
| --- | --- |
| `string Format(Key key)` | Formats masked modifiers and key identity using host platform names; unnamed valid scalars use their character and invalid scalars use the replacement character. |
| `Key Find(string text)` | Uses an immutable ordinal case-insensitive named-key dictionary and span slices to combine recognized modifier prefixes with the final named key. Null throws ArgumentNullException. |
| `bool HasUnicode(int code)` | Classifies the raw integer against noncharacter key identities; does not validate Unicode or remove modifier bits. |

The name dictionary is prepared once on first helper access from existing Key values
and the shared formatter. Concurrent calls only read it. Warmed parsing allocates no
caller bytes; formatting creates a result string and temporary parts. No display,
renderer, native library, keyboard-layout query or translation catalog is required.

## Verification and limits

The fixture was generated by compiling the named-key table and character classifier
from pinned `core/os/keyboard.cpp` and `core/os/keyboard.h` at
`ed1daf0bf001b61586d9930840f2f1394092c079`, once per platform vocabulary.

KeyCodeNamesTests covers all 191 named identities on the exercised Linux host,
37 classifier boundary samples, modifiers, culture, parallel callers and 1024 warmed parser
calls. Fresh-process public JIT and NativeAOT consumers exercise saved settings and
InputMap press/release. Windows/macOS fixture data exists; their runtime execution
and native produced-character behavior remain separate verification gates.

[ADR 0038](../decisions/input.md#adr-0038) owns input semantics;
[ADR 0095](../decisions/singleton-services.md#adr-0095) owns retained static OS access.
